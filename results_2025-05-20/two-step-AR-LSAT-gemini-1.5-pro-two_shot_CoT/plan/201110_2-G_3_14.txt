1. Entities:
    - Riders: Reynaldo (R=0), Seamus (S=1), Theresa (T=2), Yuki (Y=3)
    - Bicycles: F (F=0), G (G=1), H (H=2), J (J=3)
    - Days: Day 1 (0), Day 2 (1)

2. Variables:
    - `assignment = Array('assignment', IntSort(), IntSort(), IntSort())`
        - `assignment[rider][day]` represents the bicycle assigned to the rider on the given day.

3. Constraints:
    - Constraint 1 (Domain):
        - `rider = Int('rider')`
        - `day = Int('day')`
        - `ForAll([rider, day], And(rider >= 0, rider < 4, day >= 0, day < 2, assignment[rider][day] >= 0, assignment[rider][day] < 4))`
    - Constraint 2 (Each rider tests a different bike each day):
        - `rider = Int('rider')`
        - `ForAll([rider], Distinct([assignment[rider][0], assignment[rider][1]]))`
    - Constraint 3 (All bikes are tested each day):
        - `day = Int('day')`
        - `ForAll([day], Distinct([assignment[0][day], assignment[1][day], assignment[2][day], assignment[3][day]]))`
    - Constraint 4 (Reynaldo cannot test F):
        - `ForAll([day], assignment[0][day] != 0)`
    - Constraint 5 (Yuki cannot test J):
        - `ForAll([day], assignment[3][day] != 3)`
    - Constraint 6 (Theresa must test H):
        - `Or(assignment[2][0] == 2, assignment[2][1] == 2)`
    - Constraint 7 (Yuki's day 1 bike is Seamus's day 2 bike):
        - `assignment[1][1] == assignment[3][0]`

4. Answering the Question:
    - Initialize an SMT solver.
    - Add all constraints from step 3 to the solver.
    - Add the specific condition from the question: `assignment[2][1] == 1` (Theresa tests G on day 2).
    - For each answer choice:
        - Push the solver state.
        - Add the constraint corresponding to the negation of the answer choice:
            - Choice 1: "Reynaldo tests H on the first day." Negation: `assignment[0][0] != 2`
            - Choice 2: "Reynaldo tests J on the first day." Negation: `assignment[0][0] != 3`
            - Choice 3: "Theresa tests H on the second day." Negation: `assignment[2][1] != 2`
            - Choice 4: "Theresa tests J on the first day." Negation: `assignment[2][0] != 3`
            - Choice 5: "Yuki tests H on the second day." Negation: `assignment[3][1] != 2`
        - Check `solver.check()`.
        - If the result is `unsat`, the original answer choice must be true. This is the correct answer.
        - Pop the solver state to backtrack and test the next choice.
