1. Entities:
    - Books: F=0, G=1, H=2, I=3, K=4, L=5, M=6, O=7
    - Shelves: Top=0, Middle=1, Bottom=2

2. Variables:
    - `book_shelf = Array('book_shelf', IntSort(), IntSort())` - Maps book ID to shelf ID.

3. Constraints:
    - Constraint 0 (Domain): `ForAll([b], And(book_shelf[b] >= 0, book_shelf[b] <= 2))` where `b = Int('b')`.
    - Constraint 1 (At least two books per shelf):
        `s = Int('s')`
        `ForAll([s], Sum([If(book_shelf[i] == s, 1, 0) for i in range(8)]) >= 2)`
    - Constraint 2 (More books on bottom than top):
        `Sum([If(book_shelf[i] == 2, 1, 0) for i in range(8)]) > Sum([If(book_shelf[i] == 0, 1, 0) for i in range(8)])`
    - Constraint 3 (I on middle shelf): `book_shelf[3] == 1`
    - Constraint 4 (K higher than F): `book_shelf[4] < book_shelf[0]`
    - Constraint 5 (O higher than L): `book_shelf[7] < book_shelf[5]`
    - Constraint 6 (F and M on same shelf): `book_shelf[0] == book_shelf[6]`

4. Answering the Question:
    - Create a base Z3 solver with constraints 0-6.
    - For each answer choice:
        - Push the solver state.
        - Add the constraint corresponding to the answer choice:
            - Choice A: `book_shelf[3] == book_shelf[6]` (I and M on same shelf)
            - Choice B: `book_shelf[4] == book_shelf[1]` (K and G on same shelf)
            - Choice C: `book_shelf[5] == book_shelf[0]` (L and F on same shelf)
            - Choice D: `book_shelf[6] == book_shelf[2]` (M and H on same shelf)
            - Choice E: `book_shelf[2] == book_shelf[7]` (H and O on same shelf)
        - Check if the solver is satisfiable (`solver.check()`). If not, this choice is inconsistent.
        - If satisfiable, get a model (`m = solver.model()`).
        - Add a constraint that negates this specific model, asserting that at least one book is on a different shelf than in the model:
            `negation_of_model = Or([book_shelf[i] != m[book_shelf[i]] for i in range(8)])`
        - Add `negation_of_model` to the solver.
        - Check the solver again (`solver.check()`). If the result is `unsat`, it means the first model was the only possible solution, and the placement is fully determined by this choice. Print the corresponding letter and stop.
        - Pop the solver state to revert for the next choice.
