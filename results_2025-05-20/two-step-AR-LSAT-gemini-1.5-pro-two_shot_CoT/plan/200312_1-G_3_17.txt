1.  Entities:
    -   Cookies: Oatmeal (0), Peanut Butter (1), Sugar (2)
    -   Days: Monday (0), Tuesday (1), Wednesday (2), Thursday (3), Friday (4)
    -   Batches: 1st (0), 2nd (1), 3rd (2)

2.  Variables:
    -   `schedule = Array('schedule', IntSort(), IntSort(), IntSort())` # schedule[cookie][batch] = day

3.  Constraints:
    -   Constraint 1 (Domain of schedule): `And([And(schedule[c][b] >= 0, schedule[c][b] <= 4) for c in range(3) for b in range(3)])`
    -   Constraint 2 (No two batches of same cookie on same day): `And([Distinct([schedule[c][b] for b in range(3)]) for c in range(3)])`
    -   Constraint 3 (At least one batch on Monday): `Or([schedule[c][b] == 0 for c in range(3) for b in range(3)])`
    -   Constraint 4 (Oatmeal 2nd batch and Peanut Butter 1st batch on same day): `schedule[0][1] == schedule[1][0]`
    -   Constraint 5 (Sugar 2nd batch on Thursday): `schedule[2][1] == 3`
    -   Constraint 6 (Exactly one batch on Friday): `Sum([If(schedule[c][b] == 4, 1, 0) for c in range(3) for b in range(3)]) == 1`

4.  Answering the Question:
    -   Create a base Z3 solver with constraints 1-6.
    -   For each answer choice:
        -   Push the solver state.
        -   Add constraints corresponding to the answer choice:
            -   Choice A: `schedule[2][0] == 0`
            -   Choice B: `schedule[0][0] == 1`
            -   Choice C: `schedule[0][2] == 4`
            -   Choice D: `schedule[1][0] == 2`
            -   Choice E: `schedule[1][1] == 1`
        -   Check `solver.check()`. If `sat`, this is a possible correct answer. Store the answer choice letter.
        -   Pop the solver state.
    -   Return the stored answer choice letter.
