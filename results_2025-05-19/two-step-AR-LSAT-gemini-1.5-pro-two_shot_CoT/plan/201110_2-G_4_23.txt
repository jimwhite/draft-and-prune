1. Entities:
- Books: F, G, H, I, K, L, M, O (represented by integers 0 to 7 respectively)
- Shelves: Top (0), Middle (1), Bottom (2)

2. Variables:
- `book_shelf = Array('book_shelf', IntSort(), IntSort())` - Maps book ID (0-7) to shelf ID (0-2).

3. Constraints:
- Constraint 0 (Domain): `ForAll([b], And(book_shelf[b] >= 0, book_shelf[b] <= 2))` where `b = Int('b')`.
- Constraint 1 (At least two books per shelf):
    - `s = Int('s')`
    - `ForAll([s], Implies(And(s >= 0, s <= 2), Sum([If(book_shelf[b] == s, 1, 0) for b in range(8)]) >= 2))`
- Constraint 2 (More books on bottom than top): `Sum([If(book_shelf[b] == 2, 1, 0) for b in range(8)]) > Sum([If(book_shelf[b] == 0, 1, 0) for b in range(8)])`
- Constraint 3 (I on middle shelf): `book_shelf[3] == 1`
- Constraint 4 (K higher than F): `book_shelf[4] < book_shelf[0]`
- Constraint 5 (O higher than L): `book_shelf[7] < book_shelf[5]`
- Constraint 6 (F and M on same shelf): `book_shelf[0] == book_shelf[6]`
- Constraint 7 (L higher than H): `book_shelf[5] < book_shelf[2]`

4. Answering the Question:
- Create a base solver with constraints 0-7.
- For each answer choice:
    - Push the solver state.
    - Add the negation of the constraint corresponding to the answer choice:
        - A: `book_shelf[0] != book_shelf[1]`
        - B: `book_shelf[1] != book_shelf[2]`
        - C: `book_shelf[2] != book_shelf[6]`
        - D: `book_shelf[3] != book_shelf[1]`
        - E: `book_shelf[4] != book_shelf[7]`
    - Check satisfiability.
    - If unsat, store the answer choice letter as a possible "must be true" option.
    - Pop the solver state.
- The correct answer is the only answer choice whose negation led to unsatisfiability.
