4. Answering the Question:
    - Add constraint: `assignment[3] == J` (Julio leads Thursday afternoon).
    - Create a base solver with all constraints.
    - Initialize a counter `determined_count = 0`.
    - For each lab assistant other than Julio (Kevin, Lan, Nessa, Olivia, Rebecca):
        - Initialize `possible_slots` to all session IDs (0-5) excluding 3 (Thursday afternoon).
        - While `possible_slots` is not empty:

            - Push solver state.
            - Add constraint: `assignment[s] == assistant_id`
            - Check satisfiability.
            - If unsat:  Remove `s` from `possible_slots`. Pop solver state.

                - Add constraint: `assignment[s] != assistant_id`
                - Check satisfiability.
                - If unsat: Increment `determined_count`. Pop state. Break inner loop (assistant's session is determined).
                - If sat: Pop state. Remove `s` from `possible_slots`.
    - The final value of `determined_count` is the answer.
