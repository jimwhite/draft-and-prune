1. Entities:
    - Books: F, G, H, I, K, L, M, O (Map to IDs 0-7 respectively)
    - Shelves: Top (0), Middle (1), Bottom (2)

2. Variables:
    - `book_shelf = Array('book_shelf', IntSort(), IntSort())` - Maps book ID to shelf ID.

3. Constraints:
    - Constraint 0 (Domain): `ForAll([b], And(book_shelf[b] >= 0, book_shelf[b] <= 2))` where `b = Int('b')` and ranges from 0 to 7 inclusive.
    - Constraint 1 (At least two books per shelf):
        - `s = Int('s')`
        - `ForAll([s], Sum([If(book_shelf[b] == s, 1, 0) for b in range(8)]) >= 2)` -  where `s` ranges from 0 to 2 inclusive.
    - Constraint 2 (More books on bottom than top): `Sum([If(book_shelf[b] == 2, 1, 0) for b in range(8)]) > Sum([If(book_shelf[b] == 0, 1, 0) for b in range(8)])`
    - Constraint 3 (I on middle shelf): `book_shelf[3] == 1`
    - Constraint 4 (K higher than F): `book_shelf[4] < book_shelf[0]`
    - Constraint 5 (O higher than L): `book_shelf[7] < book_shelf[5]`
    - Constraint 6 (F and M on same shelf): `book_shelf[0] == book_shelf[6]`

4. Answering the Question:
    - Create a base Z3 solver with constraints 0-6.
    - For each answer choice:
        - Push the solver state.
        - Add the constraint corresponding to the answer choice:
            - A: `book_shelf[7] < book_shelf[6]`
            - B: `book_shelf[4] < book_shelf[1]`
            - C: `book_shelf[3] > book_shelf[0]`
            - D: `book_shelf[1] > book_shelf[7]`
            - E: `book_shelf[0] > book_shelf[5]`
        - Check `solver.check()`. If unsat, then the answer choice is not necessarily true. Pop the solver state and continue to the next choice.  If sat, store the choice as a possible answer and pop the solver state.
    - For each possible answer choice stored:
        - Push the solver state.
        - Add the negation of the answer choice constraint.
        - Check `solver.check()`. If unsat, the original constraint *must* be true. This is the correct answer. Print the corresponding letter and stop.
        - If sat, pop the solver state and continue to the next stored choice.
