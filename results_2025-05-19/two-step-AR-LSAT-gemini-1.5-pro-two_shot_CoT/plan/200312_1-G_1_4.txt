1. Entities:
    - Botanists: F, G, H
    - Chemists: K, L, M
    - Zoologists: P, Q, R

2. Variables:
    - `b = [Bool('b_%s' % i) for i in range(3)]` - `b[0]` is true iff F is selected, etc.
    - `c = [Bool('c_%s' % i) for i in range(3)]` - `c[0]` is true iff K is selected, etc.
    - `z = [Bool('z_%s' % i) for i in range(3)]` - `z[0]` is true iff P is selected, etc.

3. Constraints:
    - Constraint 1 (Panel Size): `Sum([If(b[i], 1, 0) for i in range(3)]) + Sum([If(c[i], 1, 0) for i in range(3)]) + Sum([If(z[i], 1, 0) for i in range(3)]) == 5`
    - Constraint 2 (At least one of each type):
        - `Or(b[0], b[1], b[2])`
        - `Or(c[0], c[1], c[2])`
        - `Or(z[0], z[1], z[2])`
    - Constraint 3 (More than one botanist implies at most one zoologist):
        - `Implies(Sum([If(b[i], 1, 0) for i in range(3)]) > 1, Sum([If(z[i], 1, 0) for i in range(3)]) <= 1)`
    - Constraint 4 (F and K mutual exclusion): `Not(And(b[0], c[0]))`
    - Constraint 5 (K and M mutual exclusion): `Not(And(c[0], c[2]))`
    - Constraint 6 (M implies P and R): `Implies(c[2], And(z[0], z[2]))`
    - Constraint 7 (P is the only zoologist): `And(z[0], Not(z[1]), Not(z[2]))`

4. Answering the Question:
    - Create a base Z3 solver with constraints 1-7.
    - For each answer choice:
        - Push the solver state.
        - Add the negation of the answer choice as a constraint.
        - Choice A: Negation: `And(c[0], b[1])`
        - Choice B: Negation: `And(c[1], b[0])`
        - Choice C: Negation: `And(Sum([If(c[i], 1, 0) for i in range(3)]) == 1, Not(c[0]))`
        - Choice D: Negation: `And(Sum([If(c[i], 1, 0) for i in range(3)]) == 2, b[0])`
        - Choice E: Negation: `And(Sum([If(c[i], 1, 0) for i in range(3)]) == 2, b[1])`
        - Check `solver.check()`. If unsat, the original answer choice must be true. Print the corresponding letter and stop.
        - Pop the solver state.
