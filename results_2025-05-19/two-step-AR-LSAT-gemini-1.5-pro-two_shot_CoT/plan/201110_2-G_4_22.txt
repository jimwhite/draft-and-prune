1. Entities:
    - Books: F, G, H, I, K, L, M, O (represented by integers 0 to 7 respectively)
    - Shelves: Top (0), Middle (1), Bottom (2)

2. Variables:
    - `book_shelf = Array('book_shelf', IntSort(), IntSort())` - Maps book ID (0-7) to shelf ID (0-2).

3. Constraints:
    - Constraint 1 (Domain): `ForAll([b], And(book_shelf[b] >= 0, book_shelf[b] <= 2))` where `b = Int('b')`.
    - Constraint 2 (At least two books per shelf):
        - `s = Int('s')`
        - `ForAll([s], Implies(And(s >= 0, s <= 2), Sum([If(book_shelf[b] == s, 1, 0) for b in range(8)]) >= 2))`
    - Constraint 3 (More books on bottom than top):
        - `Sum([If(book_shelf[b] == 2, 1, 0) for b in range(8)]) > Sum([If(book_shelf[b] == 0, 1, 0) for b in range(8)])`
    - Constraint 4 (I on middle shelf): `book_shelf[3] == 1`
    - Constraint 5 (K higher than F): `book_shelf[4] < book_shelf[0]`
    - Constraint 6 (O higher than L): `book_shelf[7] < book_shelf[5]`
    - Constraint 7 (F and M on same shelf): `book_shelf[0] == book_shelf[6]`
    - Constraint 8 (G on top shelf): `book_shelf[1] == 0`


4. Answering the Question:
    - Create a base Z3 solver with constraints 1-8.
    - For each answer choice:
        - Push the solver state.
        - Add constraints for the books listed in the answer choice being on the middle shelf (shelf 1).  For example, for choice "H, I", add `book_shelf[2] == 1`. I is already constrained to be on the middle shelf.
        - Add constraints for the books *not* listed in the answer choice to *not* be on the middle shelf. For example, for choice "H, I", add `book_shelf[b] != 1` for b in [0, 1, 4, 5, 6, 7].
