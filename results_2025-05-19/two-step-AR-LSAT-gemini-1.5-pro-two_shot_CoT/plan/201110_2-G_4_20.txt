1. Entities:
    - Books: F=0, G=1, H=2, I=3, K=4, L=5, M=6, O=7
    - Shelves: Top=0, Middle=1, Bottom=2

2. Variables:
    - `book_shelf = Array('book_shelf', IntSort(), IntSort())` - Maps book ID to shelf ID.

3. Constraints:
    - Constraint 0 (Domain): `ForAll([b], And(book_shelf[b] >= 0, book_shelf[b] <= 2))` where `b = Int('b')`.
    - Constraint 1 (At least two books per shelf):
        - `s = Int('s')`
        - `ForAll([s], Implies(And(s >= 0, s <= 2), Sum([If(book_shelf[i] == s, 1, 0) for i in range(8)]) >= 2))`
    - Constraint 2 (More books on bottom than top):
        - `Sum([If(book_shelf[i] == 2, 1, 0) for i in range(8)]) > Sum([If(book_shelf[i] == 0, 1, 0) for i in range(8)])`
    - Constraint 3 (I on middle shelf): `book_shelf[3] == 1`
    - Constraint 4 (K higher than F): `book_shelf[4] < book_shelf[0]`
    - Constraint 5 (O higher than L): `book_shelf[7] < book_shelf[5]`
    - Constraint 6 (F and M on same shelf): `book_shelf[0] == book_shelf[6]`

4. Answering the Question:
    - Create a base Z3 solver with constraints 0-6.
    - For each answer choice:
        - Push the solver state.
        - Add the constraint corresponding to the answer choice:
            - Choice A: `book_shelf[3] == book_shelf[6]`
            - Choice B: `book_shelf[4] == book_shelf[1]`
            - Choice C: `book_shelf[5] == book_shelf[0]`
            - Choice D: `book_shelf[6] == book_shelf[2]`
            - Choice E: `book_shelf[2] == book_shelf[7]`
        - Check `solver.check()`.
        - If `sat`:
            - Create a new solver with constraints 0-6 and the current answer choice constraint.
            - Assume the answer choice makes the arrangement fully determined.
            - Negate the assumption:  There exist two distinct solutions.
            - Create a second set of variables representing a different book arrangement: `book_shelf2 = Array('book_shelf2', IntSort(), IntSort())`
            - Add constraints 0-6 for `book_shelf2`, mirroring the original constraints.
            - Add the current answer choice constraint for `book_shelf2`.
            - Add a constraint ensuring the two arrangements are different: `Or([book_shelf[i] != book_shelf2[i] for i in range(8)])`
            - Check `solver.check()`.
            - If `unsat`, the original assumption holds, and the current answer choice fully determines the arrangement. Print the corresponding letter and stop.
            - If `sat`, the assumption is false, and the current answer choice does not fully determine the arrangement.
        - Pop the solver state.
