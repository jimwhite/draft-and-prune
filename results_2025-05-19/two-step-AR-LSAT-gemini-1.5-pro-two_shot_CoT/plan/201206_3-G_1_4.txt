    - Lab Assistants: Julio (0), Kevin (1), Lan (2), Nessa (3), Olivia (4), Rebecca (5)

    - Times: Morning (0), Afternoon (1)

3. Constraints:
    - Constraint 0 (Domain): `ForAll([i], And(schedule[i] >= 0, schedule[i] <= 5))` where `i` represents the slot ID and ranges from 0 to 5. Declare `i = Int('i')`.

    - Constraint 2 (Kevin and Rebecca Same Day):
        `Or(

            And(schedule[2] == 1, schedule[3] == 5),
            And(schedule[2] == 5, schedule[3] == 1),

    - Constraint 3 (Lan and Olivia Different Days):

    - Constraint 4 (Nessa Afternoon): `Or(schedule[1] == 3, schedule[3] == 3, schedule[5] == 3)`
    - Constraint 5 (Julio Before Olivia):

            Implies(Or(schedule[0] == 0, schedule[1] == 0), Or(schedule[2] == 4, schedule[3] == 4, schedule[4] == 4, schedule[5] == 4)),

    - Constraint 6 (Julio Morning): `Or(schedule[0] == 0, schedule[2] == 0, schedule[4] == 0)`
    - Constraint 7 (Kevin Morning): `Or(schedule[0] == 1, schedule[2] == 1, schedule[4] == 1)`
