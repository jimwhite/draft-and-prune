1. Entities:
    - Riders: Reynaldo (R=0), Seamus (S=1), Theresa (T=2), Yuki (Y=3)
    - Bicycles: F (F=0), G (G=1), H (H=2), J (J=3)
    - Days: Day 1 (0), Day 2 (1)

2. Variables:
    - `assignment = Array('assignment', IntSort(), IntSort(), IntSort())` - `assignment[day][rider]` represents the bicycle assigned to the rider on that day.

3. Constraints:
    - Constraint 1 (Domain): `ForAll([day, rider], And(assignment[day][rider] >= 0, assignment[day][rider] < 4))` - Each assignment is a valid bicycle.
    - Constraint 2 (Unique Bicycle per Rider per Day): `ForAll([day], Distinct([assignment[day][rider] for rider in range(4)]))` - Each rider tests a different bicycle each day.
    - Constraint 3 (Unique Rider per Bicycle per Day): `ForAll([day], Distinct([assignment[day][0], assignment[day][1], assignment[day][2], assignment[day][3]]))` - All bicycles are tested each day.
    - Constraint 4 (Reynaldo cannot test F): `ForAll([day], assignment[day][0] != 0)`
    - Constraint 5 (Yuki cannot test J): `ForAll([day], assignment[day][3] != 3)`
    - Constraint 6 (Theresa must test H): `Or(assignment[0][2] == 2, assignment[1][2] == 2)`
    - Constraint 7 (Yuki's Day 1 bike is Seamus's Day 2 bike): `assignment[1][1] == assignment[0][3]`
    - Constraint 8 (Theresa tests G on Day 2): `assignment[1][2] == 1`

4. Answering the Question:
    - Create a base Z3 solver with constraints 1-8.
    - For each answer choice:
        - Push the solver state.
        - Negate the answer choice and add it as a constraint:
            - "Reynaldo tests H on the first day.": `assignment[0][0] != 2`
            - "Reynaldo tests J on the first day.": `assignment[0][0] != 3`
            - "Theresa tests H on the second day.": `assignment[1][2] != 2` (This contradicts Constraint 6 and 8. Should be unsat.)
            - "Theresa tests J on the first day.": `assignment[0][2] != 3`
            - "Yuki tests H on the second day.": `assignment[1][3] != 2`
        - Check `solver.check()`. If `unsat`, this answer choice *must* be true.
        - Pop the solver state.
