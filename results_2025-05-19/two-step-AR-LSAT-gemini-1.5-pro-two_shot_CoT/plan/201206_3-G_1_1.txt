2. Variables:
    - `schedule = Array('schedule', IntSort(), IntSort())` - This array maps a composite slot_id to lab assistant ID.  The slot_id is calculated as `day * 2 + time`. So, Wednesday Morning is `0*2 + 0 = 0`, Wednesday Afternoon is `0*2 + 1 = 1`, Thursday Morning is `1*2 + 0 = 2`, and so on.

    - Constraint 3 (Lan and Olivia not on the same day): `Not(Or(And(schedule[0] == 2, schedule[1] == 4), And(schedule[0] == 4, schedule[1] == 2), And(schedule[2] == 2, schedule[3] == 4), And(schedule[2] == 4, schedule[3] == 2), And(schedule[4] == 2, schedule[5] == 4), And(schedule[4] == 4, schedule[5] == 2)))`

4. Answering the Question:
