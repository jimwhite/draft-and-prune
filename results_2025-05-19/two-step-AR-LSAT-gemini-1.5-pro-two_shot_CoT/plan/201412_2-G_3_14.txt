1. Entities:
    - Colors: Forest (F=0), Olive (O=1), Peach (P=2), Turquoise (T=3), White (W=4), Yellow (Y=5)
    - Rugs: Rug1 (R1=0), Rug2 (R2=1), Rug3 (R3=2)

2. Variables:
    - `color_in_rug = Array('color_in_rug', IntSort(), IntSort())`  # Maps color ID to rug ID (0, 1, or 2). -1 indicates the color is not used.

3. Constraints:
    - Constraint 1 (Color Usage): ForAll `c` in range(6), Or(color_in_rug[c] == -1, color_in_rug[c] == 0, color_in_rug[c] == 1, color_in_rug[c] == 2) # Each color is either in a rug or not used.
    - Constraint 2 (Five Colors Used): Sum([If(color_in_rug[c] != -1, 1, 0) for c in range(6)]) == 5 # Exactly five colors are used.
    - Constraint 3 (One Rug per Color): ForAll `c1` in range(6), ForAll `c2` in range(6), Implies(And(c1 != c2, color_in_rug[c1] != -1, color_in_rug[c2] != -1), color_in_rug[c1] != color_in_rug[c2]) # Each used color is in only one rug.
    - Constraint 4 (White Rule): ForAll `r` in range(3), Implies(color_in_rug[W] == r, Sum([If(color_in_rug[c] == r, 1, 0) for c in range(6)]) == 3) # If white is used in a rug, two other colors are also used.
    - Constraint 5 (Olive Rule): Implies(color_in_rug[O] != -1, color_in_rug[P] != -1, color_in_rug[O] == color_in_rug[P]) # If olive is used, peach is also used (and in the same rug).
    - Constraint 6 (Forest/Turquoise Rule): ForAll `r` in range(3), Not(And(color_in_rug[F] == r, color_in_rug[T] == r)) # Forest and turquoise are not used together.
    - Constraint 7 (Peach/Turquoise Rule): ForAll `r` in range(3), Not(And(color_in_rug[P] == r, color_in_rug[T] == r)) # Peach and turquoise are not used together.
    - Constraint 8 (Peach/Yellow Rule): ForAll `r` in range(3), Not(And(color_in_rug[P] == r, color_in_rug[Y] == r)) # Peach and yellow are not used together.
    - Constraint 9 (Two Solid Rugs): Sum([If(Sum([If(color_in_rug[c] == r, 1, 0) for c in range(6)]) == 1, 1, 0) for r in range(3)]) == 2 # Exactly two rugs are solid color.
