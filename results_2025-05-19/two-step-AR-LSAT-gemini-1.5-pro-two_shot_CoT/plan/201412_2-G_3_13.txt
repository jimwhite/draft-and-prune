    - `color_used = Array('color_used', IntSort(), BoolSort())` - True if the color is used.

3. Constraints:

    - Constraint 5 (Forest/Turquoise Rule): `ForAll([r], Not(Exists([c1, c2], And(color_used[c1], color_used[c2], color_in_rug[c1] == r, color_in_rug[c2] == r, c1 == 0, c2 == 3))))` where `r = Int('r')`.
    - Constraint 6 (Peach/Turquoise Rule): `ForAll([r], Not(Exists([c1, c2], And(color_used[c1], color_used[c2], color_in_rug[c1] == r, color_in_rug[c2] == r, c1 == 2, c2 == 3))))` where `r = Int('r')`.
    - Constraint 7 (Peach/Yellow Rule): `ForAll([r], Not(Exists([c1, c2], And(color_used[c1], color_used[c2], color_in_rug[c1] == r, color_in_rug[c2] == r, c1 == 2, c2 == 5))))` where `r = Int('r')`.
    - Constraint 8 (Solid Peach Rug): `Exists([r], And(color_used[2], color_in_rug[2] == r, PbEq([(color_used[c], 1) for c in range(6) if color_in_rug[c] == r], 1)))` where `r = Int('r')`.
