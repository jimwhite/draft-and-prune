1. Entities:
    - Colors: Forest (F=0), Olive (O=1), Peach (P=2), Turquoise (T=3), White (W=4), Yellow (Y=5)
    - Rugs: Rug1 (0), Rug2 (1), Rug3 (2)

2. Variables:
    - `color_in_rug = Array('color_in_rug', IntSort(), IntSort())`  # Maps color ID to rug ID (0, 1, or 2). -1 indicates the color is not used.

3. Constraints:
    - Constraint 0 (Color Usage): Exactly five colors are used. `PbEq([(color_in_rug[c] != -1, 1) for c in range(6)], 5)`
    - Constraint 1 (Unique Color Usage): Each used color is in exactly one rug. `ForAll([c], Implies(color_in_rug[c] != -1, And(color_in_rug[c] >= 0, color_in_rug[c] <= 2)))`
    - Constraint 2 (White Rule): `ForAll([r], Implies(color_in_rug[W] == r, PbEq([(color_in_rug[c] == r, 1) for c in range(6) if c != W], 2)))`
    - Constraint 3 (Olive Rule): `Implies(color_in_rug[O] != -1, color_in_rug[P] == color_in_rug[O])`
    - Constraint 4 (Forest/Turquoise Rule): `color_in_rug[F] != color_in_rug[T]`
    - Constraint 5 (Peach/Turquoise Rule): `color_in_rug[P] != color_in_rug[T]`
    - Constraint 6 (Peach/Yellow Rule): `color_in_rug[P] != color_in_rug[Y]`
    - Constraint 7 (Forest and Peach together): `color_in_rug[F] == color_in_rug[P]`
    - Constraint 8 (Distinct Rugs):  If colors are used, they must be in different rugs if they are different colors. `ForAll([c1, c2], Implies(And(c1 != c2, color_in_rug[c1] != -1, color_in_rug[c2] != -1), color_in_rug[c1] != color_in_rug[c2] ))`

            - Choice C: `color_in_rug[Y] == -1`
            - Choice D: `color_in_rug[T] == color_in_rug[W]` and `color_in_rug[T] != -1`
            - Choice E: `color_in_rug[T] == color_in_rug[Y]` and `color_in_rug[T] != -1`
