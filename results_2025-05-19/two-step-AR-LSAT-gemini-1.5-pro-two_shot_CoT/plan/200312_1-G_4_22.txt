1. Entities:
    - Students: Jiang (0), Kramer (1), Lopez (2), Megregian (3), O'Neill (4)
    - Plays: Sunset (0), Tamerlane (1), Undulation (2)

2. Variables:
    - `reviews = Array('reviews', IntSort(), BoolSort())`  # reviews[student_id][play_id] is True if the student reviews the play.

3. Constraints:
    - Constraint 1 (Review Counts):
        - `kramer_count = Sum([If(reviews[1][i], 1, 0) for i in range(3)])`
        - `lopez_count = Sum([If(reviews[2][i], 1, 0) for i in range(3)])`
        - `megregian_count = Sum([If(reviews[3][i], 1, 0) for i in range(3)])`
        - `And(kramer_count < megregian_count, lopez_count < megregian_count)`
    - Constraint 2 (Jiang Exclusion):
        - `ForAll([i], Implies(reviews[0][i], Not(Or(reviews[2][i], reviews[3][i]))) )`
    - Constraint 3 (Kramer and O'Neill review Tamerlane):
        - `And(reviews[1][1], reviews[4][1])`
    - Constraint 4 (Exactly two students review the same plays):
        - `Exists([s1, s2], And(s1 != s2, s1 < 5, s2 < 5,
                                ForAll([p], Implies(p < 3, reviews[s1][p] == reviews[s2][p])),
                                ForAll([s3], Implies(And(s3 != s1, s3 != s2, s3 < 5),
                                                    Exists([p], Implies(p<3, reviews[s3][p] != reviews[s1][p]))))))`
    - Constraint 5 (Each student reviews at least one play):
        - `ForAll([s], Implies(s < 5, Or(reviews[s][0], reviews[s][1], reviews[s][2])))`


4. Answering the Question:
    - Create a base Z3 solver with constraints 1-5.
    - For each answer choice:
        - Push the solver state.
        - Add constraints for the answer choice.  For example, for "Jiang, Kramer", add `And(reviews[0][1], reviews[1][1])` and `ForAll([s], Implies(And(s != 0, s != 1, s < 5), Not(reviews[s][1])))`.
        - Check satisfiability. If sat, this is a possible solution. Store the answer choice.
        - Pop the solver state.
    - Return the stored answer choice(s).
