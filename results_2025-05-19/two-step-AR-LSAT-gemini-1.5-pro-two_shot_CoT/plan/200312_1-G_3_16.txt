1. Entities:
    - Cookies: Oatmeal (O=0), Peanut Butter (P=1), Sugar (S=2)
    - Days: Monday (M=0), Tuesday (T=1), Wednesday (W=2), Thursday (R=3), Friday (F=4)
    - Batches: 1st (0), 2nd (1), 3rd (2)

2. Variables:
    - `schedule = Array('schedule', IntSort(), IntSort(), IntSort())`  # schedule[cookie][batch] = day. Represents the day a specific batch of a cookie type is made.

3. Constraints:
    - Constraint 1 (Domain): `c = Int('c')`, `b = Int('b')`. `ForAll([c, b], Implies(And(c >= 0, c < 3, b >= 0, b < 3), And(schedule[c][b] >= 0, schedule[c][b] < 5)))`
    - Constraint 2 (No two batches of the same kind on the same day): `c = Int('c')`, `b1 = Int('b1')`, `b2 = Int('b2')`. `ForAll([c, b1, b2], Implies(And(c >= 0, c < 3, b1 >= 0, b1 < 3, b2 >= 0, b2 < 3, b1 != b2), schedule[c][b1] != schedule[c][b2]))`
    - Constraint 3 (At least one batch on Monday): `Exists([c, b], And(c >= 0, c < 3, b >= 0, b < 3, schedule[c][b] == 0))`
    - Constraint 4 (Oatmeal 2nd batch and Peanut Butter 1st batch on same day): `schedule[0][1] == schedule[1][0]`
    - Constraint 5 (Sugar 2nd batch on Thursday): `schedule[2][1] == 3`
    - Constraint 6 (No batches on Wednesday): `c = Int('c')`, `b = Int('b')`. `ForAll([c, b], Implies(And(c >= 0, c < 3, b >= 0, b < 3), schedule[c][b] != 2))`

4. Answering the Question:
    - Create a base Z3 solver and add constraints 1-6.
    - For each answer choice:
        - Push the solver state.
        - Add the negation of the constraints corresponding to the answer choice:
            - Choice A (Exactly three batches on Tuesday): `Or(sum([If(schedule[c][b] == 1, 1, 0) for c in range(3) for b in range(3)]) != 3, Exists([d], And(d >= 0, d < 5, d != 1, sum([If(schedule[c][b] == d, 1, 0) for c in range(3) for b in range(3)]) == 3)))`
            - Choice B (Exactly three batches on Friday): `Or(sum([If(schedule[c][b] == 4, 1, 0) for c in range(3) for b in range(3)]) != 3, Exists([d], And(d >= 0, d < 5, d != 4, sum([If(schedule[c][b] == d, 1, 0) for c in range(3) for b in range(3)]) == 3)))`
            - Choice C (At least two batches on Monday): `sum([If(schedule[c][b] == 0, 1, 0) for c in range(3) for b in range(3)]) < 2`
            - Choice D (At least two batches on Thursday): `sum([If(schedule[c][b] == 3, 1, 0) for c in range(3) for b in range(3)]) < 2`
            - Choice E (Fewer batches on Monday than on Tuesday): `sum([If(schedule[c][b] == 0, 1, 0) for c in range(3) for b in range(3)]) >= sum([If(schedule[c][b] == 1, 1, 0) for c in range(3) for b in range(3)])`
        - Check `solver.check()`. If 'unsat', this is the correct answer.
        - Pop the solver state.
