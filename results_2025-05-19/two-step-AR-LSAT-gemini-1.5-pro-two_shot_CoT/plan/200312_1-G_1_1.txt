1. Entities and Representation:
    - Botanists: F, G, H
    - Chemists: K, L, M
    - Zoologists: P, Q, R
    - Panel: A set of selected scientists

2. Variables:
    -  For each scientist S in {F, G, H, K, L, M, P, Q, R}, a boolean variable `S` representing whether the scientist is on the panel.

3. Constraints:
    - Constraint 1 (Panel Size):  Exactly 5 scientists are selected.  This will be checked per answer choice.
    - Constraint 2 (At least one of each type):
        - `Or(F, G, H)` (Botanist)
        - `Or(K, L, M)` (Chemist)
        - `Or(P, Q, R)` (Zoologist)
    - Constraint 3 (More than one botanist => at most one zoologist):
        - `Implies(And(Or(F,G), Or(F,H), Or(G,H)), Or(Not(P), Not(Q)), Or(Not(P), Not(R)), Or(Not(Q), Not(R)))`
        - *Simplified:* `Implies(And(Or(F,G), Or(F,H), Or(G,H)), Not(And(P,Q)), Not(And(P,R)), Not(And(Q,R)))`
    - Constraint 4 (F and K not both selected): `Not(And(F, K))`
    - Constraint 5 (K and M not both selected): `Not(And(K, M))`
    - Constraint 6 (M selected => P and R selected): `Implies(M, And(P, R))`

4. Answering the Question:
    - For each answer choice:
        - Create a new solver instance.  (Avoid push/pop for clarity).
        - Add constraints 2-6.
        - Add constraints based on the scientists in the choice. For example, for choice "F, G, K, P, Q", add:
            - `F == True`
            - `G == True`
            - `K == True`
            - `P == True`
            - `Q == True`
            - `H == False`
            - `L == False`
            - `M == False`
            - `R == False`
        - Check if exactly 5 scientists are selected (Constraint 1). Add this constraint to the solver.
        - Check `solver.check()`. If `sat`, this is the correct answer. Print the corresponding letter and stop.
