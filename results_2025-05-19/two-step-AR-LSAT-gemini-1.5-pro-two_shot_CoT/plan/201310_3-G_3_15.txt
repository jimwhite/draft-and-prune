1. Entities:
    - Movies: Horror (H=0), Mystery (M=1), Romance (R=2), Sci-Fi (S=3), Western (W=4)
    - Screens: Screen 1 (1), Screen 2 (2), Screen 3 (3)
    - Times: 7 PM (7), 8 PM (8), 9 PM (9)

2. Variables:
    - `movie_screen = Array('movie_screen', IntSort(), IntSort())`  Maps movie ID to screen ID.
    - `movie_time = Array('movie_time', IntSort(), IntSort())` Maps movie ID to time.

3. Constraints:
    - Constraint 1 (Screen Assignment): ForAll `m` in range(5), Or(movie_screen[m] == 1, movie_screen[m] == 2, movie_screen[m] == 3)
    - Constraint 2 (Time Assignment): ForAll `m` in range(5), Or(movie_time[m] == 7, movie_time[m] == 8, movie_time[m] == 9)
    - Constraint 3 (Distinct Movies per Screen/Time):
        - ForAll `m1`, `m2` in range(5), Implies(And(movie_screen[m1] == movie_screen[m2], movie_time[m1] == movie_time[m2]), m1 == m2)
    - Constraint 4 (Screen 3 - One Movie at 8 PM):
        - ForAll `m` in range(5), Implies(movie_screen[m] == 3, movie_time[m] == 8)
    - Constraint 5 (Screens 1 & 2 - Two Movies Each at 7 and 9 PM):
        - ForAll `m` in range(5), Implies(Or(movie_screen[m] == 1, movie_screen[m] == 2), Or(movie_time[m] == 7, movie_time[m] == 9))
    - Constraint 6 (Western before Horror): movie_time[W] < movie_time[H]
    - Constraint 7 (Sci-fi not on Screen 3): movie_screen[S] != 3
    - Constraint 8 (Romance not on Screen 2): movie_screen[R] != 2
    - Constraint 9 (Horror and Mystery on different screens): movie_screen[H] != movie_screen[M]
    - Constraint 10 (Western and Sci-fi on same screen): movie_screen[W] == movie_screen[S]

4. Answering the Question:
    - Create a base Z3 solver with constraints 1-10.
    - For each answer choice (A, B, C, D, E):
        - Push the solver state.
        - Add the constraint corresponding to the answer choice:
            - A: movie_screen[H] == 2
            - B: movie_time[M] == 9
            - C: movie_screen[R] == 3
            - D: movie_time[S] == 7
            - E: movie_time[W] == 8
        - Check `solver.check()`. If sat, this is a possible answer.
        - Pop the solver state.
    - Collect all possible answers.
