2. Encode direct facts using ternary predicates (e.g., is_big("bald_eagle", True), is_green("bear", True), likes("bald_eagle", "bear", True), etc.).
3. For unary properties, use predicate(entity, boolean); for binary relations, use predicate(subject, object, True).
4. Translate conditional rules into PyKe `foreach` + `assert` form:
   • If someone is cold → they are not young: foreach with is_cold(?x, True) → assert is_young(?x, False).
   • All big people are not green: foreach with is_big(?x, True) → assert is_green(?x, False).
   • If lion is big and green → lion chases bald_eagle: foreach with is_big("lion", True), is_green("lion", True) → assert chases("lion", "bald_eagle", True).
   • If someone chases bald_eagle → they like bear: foreach with chases(?x, "bald_eagle", True) → assert likes(?x, "bear", True).
   • If someone is round and visits bald_eagle → bald_eagle likes squirrel: foreach with is_round(?x, True), visits(?x, "bald_eagle", True) → assert likes("bald_eagle", "squirrel", True).
   • If someone visits lion → they like bald_eagle: foreach with visits(?x, "lion", True) → assert likes(?x, "bald_eagle", True).
   • If lion visits squirrel and squirrel chases bear → bear chases bald_eagle: foreach with visits("lion", "squirrel", True), chases("squirrel", "bear", True) → assert chases("bear", "bald_eagle", True).
   • If someone visits lion → they are cold: foreach with visits(?x, "lion", True) → assert is_cold(?x, True).
   • If someone likes bear → they chase bear: foreach with likes(?x, "bear", True) → assert chases(?x, "bear", True).
