1. Identify all entities: Charlie, Dave, Erin, Fiona.
2. Encode all direct facts using ternary predicates:
   - is_cold("Charlie", True)
   - is_young("Charlie", True)
   - is_cold("Dave", True)
   - is_white("Erin", True)
   - is_nice("Fiona", True)
   - is_white("Fiona", True)
   - is_young("Fiona", True)
3. Translate each universal implication into a PyKe rule using `foreach` and `assert`:
   • All blue things are white: foreach X, is_blue(X, True) ⇒ assert is_white(X, True)
   • If something is nice and blue then it is white: foreach X, is_nice(X, True) ∧ is_blue(X, True) ⇒ assert is_white(X, True)
   • All young, blue things are not green: foreach X, is_young(X, True) ∧ is_blue(X, True) ⇒ assert is_green(X, False)
   • All white things are nice: foreach X, is_white(X, True) ⇒ assert is_nice(X, True)
   • All nice things are round: foreach X, is_nice(X, True) ⇒ assert is_round(X, True)
   • If Charlie is round then Charlie is white: is_round("Charlie", True) ⇒ assert is_white("Charlie", True)
   • All blue things are young: foreach X, is_blue(X, True) ⇒ assert is_young(X, True)
   • If something is cold and green then it is young: foreach X, is_cold(X, True) ∧ is_green(X, True) ⇒ assert is_young(X, True)
   • Round things are blue: foreach X, is_round(X, True) ⇒ assert is_blue(X, True)
4. Derive additional facts via backward chaining using the rules above (e.g., from is_white("Fiona", True), derive is_nice("Fiona", True) via rule 4; from is_white, but note Fiona already has is_nice explicitly).
5. Determine whether "Fiona is not cold" holds:
   → Query: facts.is_cold("Fiona", False)
