1. Identify all entities involved: bear, cow, rabbit, tiger.  
2. Define explicit facts using ternary predicates of the form predicate(subject, object, True):  
   - Properties (unary concepts encoded as binary with boolean object): is_blue, is_green, is_red, is_cold, is_nice.  
   - Relations (binary): sees, needs, visits.  
3. Encode directly stated facts as `facts.pred(subject, object, True)` (e.g., `is_blue("bear", True)`, `sees("bear", "rabbit", True)`, `needs("cow", "tiger", True)`, etc.).  
4. Translate each conditional rule into PyKe rules using `foreach` and `assert`:  
   • If something is green → it visits the tiger.  
   • If something sees the bear and is cold → the bear is green.  
   • If the cow needs the rabbit AND the rabbit needs the cow → the rabbit is red.  
   • If something is green → it needs the cow.  
   • If something visits the tiger → the tiger is red.  
   • If something needs the tiger AND the tiger sees the cow → the cow needs the bear.  
   • If something sees the bear AND it needs the bear → it sees the cow.  
   • If something visits the rabbit → the rabbit needs the tiger.  
   • If something needs the bear AND the bear visits the tiger → it sees the bear.  
5. For each rule, write a `foreach` block matching all antecedent conditions (using conjunction via multiple `bind` or nested conditions) and an `assert` block for the consequent.  
6. Query checks whether the cow visits the rabbit: use `facts.visits("cow", "rabbit", True)`.  
7. Determine truth value based on whether the fact can be deduced (true), contradicted (false), or neither (unknown).
