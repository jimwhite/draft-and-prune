1. Identify all entities: Bob, Charlie, Erin, Fiona.
2. Encode explicit facts using ternary predicates:
   - is_green("Bob", True)
   - is_kind("Bob", True)
   - is_green("Charlie", True)
   - is_smart("Charlie", False)
   - is_young("Erin", False)
   - is_nice("Fiona", True)
   - is_young("Fiona", True)
3. Encode implicit facts derived from explicit ones using rules:
   - If something is kind → it is green (Bob and Fiona may begreen by this, but Bob already known green).
   - Smart things are young: is_smart(X, True) ⇒ is_young(X, True)
   - Young things are kind: is_young(X, True) ⇒ is_kind(X, True)
   - Green, smart things are quiet: is_green(X, True) ∧ is_smart(X, True) ⇒ is_quiet(X, True)
   - Quiet things are furry: is_quiet(X, True) ⇒ is_furry(X, True)
   - All quiet, nice things are furry: is_quiet(X, True) ∧ is_nice(X, True) ⇒ is_furry(X, True)
   - Nice, green things are smart: is_nice(X, True) ∧ is_green(X, True) ⇒ is_smart(X, True)
   - If Bob is kind and not green → Bob is furry (but Bob is known green, so antecedent false; can be omitted or added for completeness)
4. Apply forward-chaining reasoning:
   - From Fiona: is_nice("Fiona", True), is_young("Fiona", True)
   - From young ⇒ kind: is_kind("Fiona", True)
   - From green and smart ⇒ quiet, but we do not yet know is_smart("Fiona", True); need to derive it.
   - From Fiona: is_nice("Fiona", True) and we need is_green("Fiona", True). Not directly given.
   - Check if Fiona is green: Bob and Charlie are explicitly green; no rule says nice ⇒ green, nor young ⇒ green (only kind ⇒ green). Fiona is kind (from young), so from kind ⇒ green, we get is_green("Fiona", True).
   - Now: is_nice("Fiona", True) ∧ is_green("Fiona", True) ⇒ from "Nice, green things are smart" we get is_smart("Fiona", True).
   - Now: is_green("Fiona", True) ∧ is_smart("Fiona", True) ⇒ from "Green, smart things are quiet" we get is_quiet("Fiona", True).
5. Query: is_quiet("Fiona", False) — but we need to check whether "Fiona is quiet" is true. So the query should be: facts.is_quiet("Fiona", True) to confirm; or for "Fiona is quiet" as statement, we assert True and check consistency. Since PyKe queries test truth of fact assertions, the query is: facts.is_quiet("Fiona", True).
