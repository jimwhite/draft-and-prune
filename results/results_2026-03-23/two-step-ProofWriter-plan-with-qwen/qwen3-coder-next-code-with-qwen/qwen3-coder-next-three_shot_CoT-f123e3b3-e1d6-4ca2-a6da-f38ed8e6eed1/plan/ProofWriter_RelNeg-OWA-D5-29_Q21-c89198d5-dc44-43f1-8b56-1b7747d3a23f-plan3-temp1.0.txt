1. Identify all entities involved: bald_eagle, bear, rabbit, tiger.
2. Define all explicit properties and relations using ternary predicates: predicate(subject, object, True).
   - Properties like is_big, is_red, needs, visits, sees use objects accordingly (entities for relations, True for unary facts where needed).
   - Explicit negative facts like "the bear does not see the tiger" must be encoded as the negation of a fact.
3. Encode all directly stated facts:
   - is_big("bald_eagle", True), is_red("bald_eagle", True), sees("bald_eagle", "tiger", True), visits("bald_eagle", "bear", True)
   - needs("bear", "bald_eagle", True), sees("bear", "bald_eagle", True), sees("bear", "tiger", False)  // explicit negative
   - is_big("rabbit", True), needs("rabbit", "bald_eagle", True), needs("rabbit", "bear", True), visits("rabbit", "tiger", True)
   - needs("tiger", "bald_eagle", True), needs("tiger", "rabbit", True), visits("tiger", "bear", True)
4. Translate each conditional into PyKe rules using `foreach` and `assert`:
   • If something is big → it needs the tiger: foreach(is_big(X, True)) assert(needs(X, "tiger", True))
   • If something needs the tiger and sees the bald eagle → tiger is big: foreach(needs(X, "tiger", True), sees(X, "bald_eagle", True)) assert(is_big("tiger", True))
   • If something needs the tiger and visits the bear → tiger needs rabbit: foreach(needs(X, "tiger", True), visits(X, "bear", True)) assert(needs("tiger", "rabbit", True))
   • If bald_eagle visits bear and needs tiger → bear needs tiger: foreach(visits("bald_eagle", "bear", True), needs("bald_eagle", "tiger", True)) assert(needs("bear", "tiger", True))
   • If something needs tiger → it is red: foreach(needs(X, "tiger", True)) assert(is_red(X, True))
   • If bear sees rabbit → rabbit sees tiger: foreach(sees("bear", "rabbit", True)) assert(sees("rabbit", "tiger", True))
   • If something is blue → it visits bear: foreach(is_blue(X, True)) assert(visits(X, "bear", True))
   • If something is blue and needs tiger → it does NOT visit bald_eagle: foreach(is_blue(X, True), needs(X, "tiger", True)) assert(visits(X, "bald_eagle", False))
5. Encode the explicit negative fact: sees("bear", "tiger", False) (already done in step 3).
