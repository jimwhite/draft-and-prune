1. Identify all individuals: Charlie, Dave, Erin, Harry.
2. Represent all explicit facts using ternary predicates:
   - is_green("Charlie", True)
   - is_quiet("Dave", True), is_red("Dave", True), is_white("Dave", False)
   - is_big("Erin", False), is_cold("Erin", False), is_green("Erin", True)
   - is_big("Harry", True), is_cold("Harry", True), is_green("Harry", True)
3. Express all contextual implications as rules:
   • If someone is red → they are not white.
   • If Charlie is quiet → Charlie is blue.
   • If someone is quiet and red → they are blue.
   • All white people are cold.
   • All green people are quiet.
   • All blue and green people are red.
   • If someone is red and not white → they are big.
4. For each rule, encode a `foreach` block matching the condition(s) and an `assert` for the conclusion:
   • Rule 1: foreach is_red(x, True) → assert is_white(x, False)
   • Rule 2: foreach is_quiet("Charlie", True) → assert is_blue("Charlie", True)
   • Rule 3: foreach is_quiet(x, True) and is_red(x, True) → assert is_blue(x, True)
   • Rule 4: foreach is_white(x, True) → assert is_cold(x, True)
   • Rule 5: foreach is_green(x, True) → assert is_quiet(x, True)
   • Rule 6: foreach is_blue(x, True) and is_green(x, True) → assert is_red(x, True)
   • Rule 7: foreach is_red(x, True) and is_white(x, False) → assert is_big(x, True)

   → Use facts.is_red("Charlie", False)
