   - Relations like sees, needs, visits take another entity (string) as the object.

4. Translate each conditional sentence into a PyKe rule using `foreach` and `assert`:

   - If something sees bear AND needs bear → it sees cow.
   - If something visits rabbit → rabbit needs tiger.
