     → foreach: chases(X, "lion", True), likes("lion", "dog", True) ⇒ likes("dog", "lion", False)
   • If the bear likes the lion → the lion likes the dog.  
     → foreach: likes("bear", "lion", True) ⇒ likes("lion", "dog", True)
   • If X likes the bear → the bear likes the lion.  
     → foreach: likes(X, "bear", True) ⇒ likes("bear", "lion", True)
   • If X is round → X likes the bear.  
     → foreach: is_round(X, True) ⇒ likes(X, "bear", True)
