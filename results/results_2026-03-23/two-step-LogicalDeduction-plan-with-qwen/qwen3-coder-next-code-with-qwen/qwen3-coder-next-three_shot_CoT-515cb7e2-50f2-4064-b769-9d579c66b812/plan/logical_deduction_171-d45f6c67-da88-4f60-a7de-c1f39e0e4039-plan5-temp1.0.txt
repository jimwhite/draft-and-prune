    * Identify the seven golfers as variables: `"Ana"`, `"Eli"`, `"Mya"`, `"Amy"`, `"Joe"`, `"Mel"`, and `"Ada"`.

    * Add all variables with this domain to the `Problem` instance.

3.  **Translate Rules into Constraints:**
    * Add an `AllDifferentConstraint` to ensure each golfer has a unique rank.
    * Convert each statement into a constraint:
        * "Ada finished above Mel" → `Ada < Mel` (since lower rank number = better/above).
        * "Ada finished third-to-last" → In a field of 7, third-to-last is position **5** (positions from end: 1st-last=7, 2nd-last=6, 3rd-last=5). So `Ada == 5`.
        * "Amy finished above Ana" → `Amy < Ana`.
        * "Mya finished second-to-last" → Position **6** (since 7th is last, 6th is second-to-last). So `Mya == 6`.
        * "Joe finished above Amy" → `Joe < Amy`.
        * "Eli finished below Ana" → `Eli > Ana`.

4.  **Solve for the Ranking Order:**
    * Use `getSolutions()` to find all valid assignments of ranks satisfying the constraints.
    * Since the problem is deterministic, there should be exactly one solution. Retrieve it.
