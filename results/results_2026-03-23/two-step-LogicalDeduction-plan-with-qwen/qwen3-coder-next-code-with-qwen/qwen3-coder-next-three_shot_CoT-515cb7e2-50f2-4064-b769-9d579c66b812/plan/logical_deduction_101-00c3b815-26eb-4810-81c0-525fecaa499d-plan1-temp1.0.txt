1.  **Initialize the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Instantiate a `Problem` object to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**  
    * Define the seven fruits as variables: `"apples"`, `"pears"`, `"mangoes"`, `"oranges"`, `"watermelons"`, `"peaches"`, and `"cantaloupes"`.  
    * Define the domain as integers from 1 to 7, where **1 = cheapest** and **7 = most expensive**, consistent with standard cost-ranking conventions.  
    * Add all seven variables to the problem with the domain {1, 2, 3, 4, 5, 6, 7}.

3.  **Add AllDifferent Constraint:**  
    * Enforce that all fruits have distinct price ranks using `AllDifferentConstraint`.

4.  **Translate Each Statement into a Constraint Using Lambda Functions:**  
    * "The pears are more expensive than the oranges" → `pears > oranges` (higher rank = more expensive).  
    * "The oranges are more expensive than the cantaloupes" → `oranges > cantaloupes`.  
    * "The peaches are less expensive than the cantaloupes" → `peaches < cantaloupes`.  
    * "The apples are the third-cheapest" → `apples == 3`.  
    * "The watermelons are the second-most expensive" → `watermelons == 6` (since most expensive = 7, second-most = 6).  
    * "The mangoes are the fourth-most expensive" → `mangoes == 4`.

5.  **Solve the Constraint Problem:**  
    * Call `getSolutions()` to find all valid assignments of price ranks.  
    * Extract the unique solution (as the constraints fully determine the ordering).

6.  **Map Choice Letters to Fruits:**  
    * Create a mapping dictionary:  
        `'A' → "apples"`,  
        `'B' → "pears"`,  
        `'C' → "mangoes"`,  
        `'D' → "oranges"`,  
        `'E' → "watermelons"`,  
        `'F' → "peaches"`,  
        `'G' → "cantaloupes"`.

7.  **Determine the Second-Cheapest Fruit:**  
    * The second-cheapest corresponds to rank `2`.  
    * Iterate over the solution dictionary: for each fruit, check if its assigned value is `2`.  
    * Identify the matching fruit.

8.  **Output the Correct Choice Letter:**  
    * Using the mapping from step 6, find the choice letter corresponding to the fruit found in step 7.  
    * Return or print this letter as the answer.
