1.  **Initialize the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Create an instance of the `Problem` class to define the constraint satisfaction problem.  

2.  **Define Variables and Domain:**  
    * Identify the seven golfers as variables: `"Mya"`, `"Eli"`, `"Ana"`, `"Amy"`, `"Mel"`, `"Dan"`, and `"Joe"`.  
    * Define the domain as integers from 1 to 7, where **1 = first (best)** and **7 = last (worst)**.  
    * Add all seven variables with this domain to the `Problem` instance.  

3.  **Translate Statements into Constraints:**  
    * Add an `AllDifferentConstraint` to ensure all golfers have distinct finish positions.  
    * Convert each statement into a constraint:  
        * "Amy finished below Joe" → Amy's position number > Joe's position number (`amy > joe`).  
        * "Dan finished above Mya" → Dan's position number < Mya's position number (`dan < mya`).  
        * "Eli finished third" → Eli's position = 3.  
        * "Ana finished first" → Ana's position = 1.  
        * "Amy finished second-to-last" → Amy's position = 6 (since last is 7, second-to-last is 6).  
        * "Mya finished fourth" → Mya's position = 4.  

4.  **Solve the Problem:**  
    * Call `getSolutions()` to obtain all valid arrangements.  
    * Since the constraints are sufficient for a unique solution, extract the first (and only) solution.  

5.  **Determine the Third-to-Last Finisher:**  
    * In a field of seven, third-to-last corresponds to position = 7 − 2 = **5** (positions: 1=first, ..., 5=third-to-last, 6=second-to-last, 7=last).  
    * Create a dictionary mapping choice letters (`"A"` through `"G"`) to the corresponding golfer names from the choices.  
    * Iterate over the solution dictionary to find which golfer has position **5**.  
    * Return the choice letter (e.g., `"E"`) that matches this golfer.
