    * Add an `AllDifferentConstraint` to ensure each golfer has a unique position (no ties).

        - "Ana finished second-to-last" means Ana’s position is **6** (since last = 7, second-to-last = 6).  
        - "Mya finished fourth" means Mya’s position is **4**.  
        - "Dan finished third" means Dan’s position is **3**.  
        - "Ada finished second" means Ada’s position is **2**.  
        - "Eli finished third-to-last" means Eli’s position is **5** (positions from last: 1st-last=7, 2nd-last=6, **3rd-last=5**).  

4.  **Solve for the Arrangement:**  
    * Call `getSolutions()` to find all valid assignments. Given consistency and uniqueness implied by the problem, expect exactly one solution.  
    * Extract the first (and only) solution dictionary.
