3.  **Add Constraints:**

        * "The black book is the third from the left" → `black == 3`  
    * Add each constraint to the problem using `addConstraint(lambda ...: expr, [vars])` or via direct variable assignment where applicable (e.g., for fixed positions).

4.  **Solve the Problem:**

    * Extract the unique solution (since the constraints fully determine positions).
