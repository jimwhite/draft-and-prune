1. **Initialize the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2. **Define Variables and Domain:**  
   * Identify the seven bird types as variables: `"robin"`, `"hummingbird"`, `"raven"`, `"blue_jay"`, `"crow"`, `"cardinal"`, and `"quail"`.  
   * Define the domain for positions as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.  
   * Add all seven variables to the problem with this domain.

3. **Formulate and Add Constraints:**  
   * Add an `AllDifferentConstraint` to enforce uniqueness of positions.  
   * Translate each statement into a constraint using lambda functions:  
     - "The hummingbird is to the left of the crow" → `hummingbird < crow`  
     - "The cardinal is to the right of the quail" → `quail < cardinal`  
     - "The blue jay is the fourth from the left" → `blue_jay == 4`  
     - "The robin is the second from the left" → `robin == 2`  
     - "The quail is to the right of the crow" → `crow < quail`  
     - "The raven is to the left of the robin" → `raven < robin` (and since robin == 2, raven must be in position 1)

4. **Solve the Problem:**  
   * Call `getSolutions()` to retrieve all valid assignments.  
   * Extract the unique solution (or first solution) from the list.

5. **Determine the Correct Answer:**  
   * The question asks which bird is third from the left, i.e., has position 3.  
   * Create a mapping from choice letters to bird names:  
     A → "robin", B → "hummingbird", C → "raven", D → "blue_jay", E → "crow", F → "cardinal", G → "quail".  
   * For the solution dictionary, find which bird has position 3.  
   * Return the corresponding choice letter (e.g., 'C' if raven is at position 3).
