1.  **Set Up the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**
    * Define the variables as the seven fruits: `"oranges"`, `"loquats"`, `"apples"`, `"kiwis"`, `"mangoes"`, `"plums"`, and `"peaches"`.
    * Define the domain as integers from 1 to 7, where **1 represents the cheapest** and **7 represents the most expensive** fruit (to align with statements like "second-cheapest", "fourth-most expensive").
    * Add all variables and their domain (1–7) to the problem instance.

3.  **Add All-Different Constraint:**
    * Add an `AllDifferentConstraint` to ensure each fruit has a unique price rank.

4.  **Translate Each Statement into Constraints:**
    * "The apples are the second-cheapest" → `apples == 2`
    * "The peaches are the cheapest" → `peaches == 1`
    * "The plums are the fourth-most expensive" → Since 7 is most expensive, "fourth-most expensive" means rank = 7 − 4 + 1 = **4**, so `plums == 4`
    * "The loquats are the third-cheapest" → `loquats == 3`
    * "The kiwis are more expensive than the mangoes" → `mangoes < kiwis` (since lower number = cheaper)
    * "The oranges are less expensive than the mangoes" → `oranges < mangoes`

5.  **Solve the Constraint Satisfaction Problem:**
    * Call `getSolutions()` to find all valid assignments of ranks to fruits.
    * Extract the unique solution (since the problem is well-constrained, there should be exactly one).

6.  **Determine the Third-Most-Expensive Fruit:**
    * Since the most expensive is rank 7, the third-most-expensive corresponds to rank = 7 − 3 + 1 = **5**.
    * Retrieve the fruit assigned to rank 5 in the solution dictionary.

7.  **Map the Answer to the Given Choices:**
    * Create a mapping from choice letters ("A" through "G") to the corresponding fruit names in order:
        A → oranges, B → loquats, C → apples, D → kiwis, E → mangoes, F → plums, G → peaches.
    * Find which choice letter corresponds to the fruit found at rank 5.
    * Output that choice letter as the answer.
