1.  **Initialize the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**  
    * Identify the variables: `"watermelons"`, `"apples"`, `"kiwis"`, `"cantaloupes"`, and `"mangoes"`.  
    * Define the domain for prices as integers from 1 to 5, where **1 = cheapest** and **5 = most expensive**.  
    * Add all five variables with domain `{1, 2, 3, 4, 5}` to the `Problem` instance.

3.  **Formulate and Add Constraints:**  
    * Add an `AllDifferentConstraint` to ensure each fruit has a unique price rank.  
    * Translate each statement into a constraint:  
        - "The cantaloupes are the second-cheapest" → `cantaloupes == 2`.  
        - "The mangoes are more expensive than the watermelons" → `watermelons < mangoes`.  
        - "The kiwis are less expensive than the apples" → `kiwis < apples`.  
        - "The kiwis are more expensive than the mangoes" → `mangoes < kiwis`.  
    * Append all four constraints to the problem.

4.  **Solve for Valid Arrangement:**  
    * Call `getSolutions()` to compute all solutions satisfying the constraints.  
    * Extract the first (and unique) solution from the returned list of dictionaries mapping fruit names to price ranks.

5.  **Determine the Correct Answer:**  
    * The question asks which fruit is cheapest (i.e., has rank 1).  
    * Create a mapping from choice letters: `"A" → "watermelons"`, `"B" → "apples"`, `"C" → "kiwis"`, `"D" → "cantaloupes"`, `"E" → "mangoes"`.  
    * Iterate over choices, checking in the solution dictionary which fruit has value 1.  
    * Output the letter corresponding to that fruit as the final answer.
