1.  **Initialize the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**  
    * Identify the seven books as variables: `"brown"`, `"white"`, `"black"`, `"yellow"`, `"orange"`, `"blue"`, `"green"`.  
    * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.  
    * Add all seven variables with domain {1,2,3,4,5,6,7} to the problem.

3.  **Formulate and Add Constraints:**  
    * Add an `AllDifferentConstraint` to ensure each book occupies a unique position.  
    * Convert each statement into a constraint using `addConstraint` with lambda functions:  
        - "The yellow book is the rightmost" → `yellow == 7`  
        - "The blue book is to the left of the orange book" → `blue < orange`  
        - "The green book is to the right of the white book" → `white < green`  
        - "The blue book is to the right of the green book" → `green < blue`  
        - "The black book is the fourth from the left" → `black == 4`  
        - "The brown book is the third from the right" → `brown == 5` (since 7 - 3 + 1 = 5)

4.  **Solve the Problem:**  
    * Use `getSolutions()` to find all valid assignments. Given consistency, expect exactly one solution.

5.  **Determine the Second-from-the-Right Position:**  
    * The "second from the right" corresponds to position **6** (since 7 = rightmost, 6 = second-rightmost).  
    * Create a mapping from choice letters to book names: `{'A':'brown', 'B':'white', 'C':'black', 'D':'yellow', 'E':'orange', 'F':'blue', 'G':'green'}`  
    * Iterate through choices; for each, check if the corresponding book's position in the solution equals 6.
