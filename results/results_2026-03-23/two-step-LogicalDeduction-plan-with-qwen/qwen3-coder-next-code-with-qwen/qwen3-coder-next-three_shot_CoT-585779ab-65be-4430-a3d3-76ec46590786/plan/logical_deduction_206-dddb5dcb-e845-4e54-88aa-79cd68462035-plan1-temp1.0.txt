1.  **Initialize the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Create an instance of the `Problem` class to model the constraints.

2.  **Define Variables and Domain:**  
    * Define the seven fruit variables: `"loquats"`, `"peaches"`, `"watermelons"`, `"plums"`, `"kiwis"`, `"mangoes"`, and `"pears"`.  
    * Assign a numerical domain of integers from 1 to 7, where **1 = cheapest** and **7 = most expensive** (since comparisons like "more/less expensive" imply a total ordering of cost).  
    * Add all variables to the `Problem` with this domain.

3.  **Translate Statements into Constraints:**  
    * Add an `AllDifferentConstraint` to ensure all fruits have distinct price ranks.  
    * Convert each statement into a constraint:  
        - "The pears are more expensive than the kiwis" → `kiwis < pears` (kiwis cheaper ⇒ lower rank).  
        - "The watermelons are less expensive than the peaches" → `watermelons < peaches`.  
        - "The mangoes are the third-cheapest" → `mangoes == 3`.  
        - "The watermelons are the third-most expensive" → With ranks 1–7, third-most expensive means rank = 5 (since most expensive=7 → second-most=6 → third-most=5).  
        - "The plums are the second-most expensive" → `plums == 6`.  
        - "The loquats are the second-cheapest" → `loquats == 2`.  

4.  **Solve the Constraint Satisfaction Problem:**  
    * Call `getSolutions()` to find all valid assignments satisfying every constraint.  
    * Extract the unique solution (as the problem is fully constrained).  

5.  **Identify the Cheapest Fruit (Rank 1):**  
    * The question asks which fruit is the cheapest → find which variable has value 1 in the solution.  
    * Create a mapping from choice letters (A–G) to fruit names as given in the choices.  
    * Iterate through choices; for each, check if its fruit has rank 1 in the solution.  
    * Return the letter corresponding to the correct fruit as the final answer.
