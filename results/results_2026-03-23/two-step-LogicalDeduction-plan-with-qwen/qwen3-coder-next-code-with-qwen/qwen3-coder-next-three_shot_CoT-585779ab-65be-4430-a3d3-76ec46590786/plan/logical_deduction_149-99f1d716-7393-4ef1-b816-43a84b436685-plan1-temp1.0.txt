2. **Define Variables and Their Domain:**  
   * Define the seven variables as the golfers' names: `"Joe"`, `"Mel"`, `"Mya"`, `"Eve"`, `"Rob"`, `"Ada"`, and `"Dan"`.  
   * Define the domain as integers from **1 to 7**, where **1 = first place (highest rank)** and **7 = last place (lowest rank)**.  
   * Add all variables to the problem with this domain.

3. **Formulate and Add Constraints from Statements:**  
   * Add an `AllDifferentConstraint` to ensure each golfer has a unique finishing position.  
   * Add constraints using `addConstraint` with lambda functions (or direct value assignment where applicable):  
     - "Rob finished first" → Rob's position = 1.  
     - "Eve finished last" → Eve's position = 7.  
     - "Dan finished above Ada" → Dan's position number < Ada's position number (since lower number = better rank).  
     - "Mel finished above Mya" → Mel's position number < Mya's position number.  
     - "Joe finished second-to-last" → Joe's position = 6 (since last is 7, second-to-last is 6).  
     - "Mya finished third" → Mya's position = 3.

4. **Solve the Constraint Satisfaction Problem:**  
   * Call `getSolutions()` to enumerate all valid assignments of positions.  
   * Extract the (unique) solution from the returned list.

     - 1st = first,  
     - 2nd = second,  
     - ...,  
     - **5th = third-to-last** (since 7 − 3 + 1 = 5).  
   * So we need the golfer with position **5**.
