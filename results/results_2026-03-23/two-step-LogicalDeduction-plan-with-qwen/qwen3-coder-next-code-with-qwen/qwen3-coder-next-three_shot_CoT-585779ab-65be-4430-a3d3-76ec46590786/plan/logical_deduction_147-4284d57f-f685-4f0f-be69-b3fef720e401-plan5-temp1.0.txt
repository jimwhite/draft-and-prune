1.  **Set Up the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Instantiate a `Problem` object to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**  
    * Identify the seven books as variables: `"brown"`, `"yellow"`, `"black"`, `"white"`, `"green"`, `"orange"`, `"purple"`.  
    * Define the domain as integers 1 through 7, where **1 = leftmost** and **7 = rightmost**.  
    * Add all seven book variables with domain {1,2,3,4,5,6,7} to the problem.

3.  **Add AllDifferentConstraint:**  
    * Ensure that each book occupies a unique position by adding an `AllDifferentConstraint` over all seven variables.

4.  **Translate Statements into Constraints:**  
    * "The purple book is the rightmost" → `purple == 7`.  
    * "The yellow book is the leftmost" → `yellow == 1`.  
    * "The orange book is the second from the right" → `orange == 6`.  
    * "The brown book is to the left of the green book" → `brown < green`.  
    * "The brown book is to the right of the black book" → `black < brown`.  
    * "The white book is the fourth from the left" → `white == 4`.

5.  **Solve the Constraint Satisfaction Problem:**  
    * Call `getSolutions()` to compute all valid assignments. Since the constraints fully determine positions, there will be exactly one solution.

6.  **Determine the Third-from-the-Right Position:**  
    * The third-from-the-right in a 7-position sequence corresponds to position **5** (since rightmost = 7, second-rightmost = 6, third-rightmost = 5).  
    * Extract the solution dictionary and find which book has position value 5.

7.  **Map to the Correct Choice:**  
    * Create a mapping from choice letters (A–G) to the corresponding book names: A→"brown", B→"yellow", C→"black", D→"white", E→"green", F→"orange", G→"purple".  
    * Identify the choice letter whose associated book has position 5 in the solution.  
    * Return that letter as the answer.
