1.  **Initialize the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**
    * Identify the seven books as variables: `"orange"`, `"green"`, `"red"`, `"gray"`, `"purple"`, `"blue"`, `"brown"`.
    * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.
    * Add all seven book variables with the domain {1, 2, 3, 4, 5, 6, 7} to the problem.

3.  **Add AllDifferent Constraint:**
    * Add an `AllDifferentConstraint` to ensure each book occupies a unique position.

4.  **Translate Each Statement into Explicit Constraints:**
    * "The purple book is the fourth from the left" → `purple == 4`
    * "The brown book is the third from the left" → `brown == 3`
    * "The green book is to the left of the blue book" → `green < blue`
    * "The red book is the leftmost" → `red == 1`
    * "The gray book is the third from the right" → Since 7 - 3 + 1 = 5, this means `gray == 5`
    * "The orange book is the rightmost" → `orange == 7`

5.  **Solve the Problem:**
    * Use `getSolutions()` to find all valid assignments.
    * Extract the (unique) solution dictionary mapping books to positions.

6.  **Determine Which Book Is Fourth from the Left:**
    * The fourth position corresponds to index 4.
    * Create a mapping from choice letters ("A" through "G") to the book names in the order of the choices:
        * A → `"orange"`, B → `"green"`, C → `"red"`, D → `"gray"`, E → `"purple"`, F → `"blue"`, G → `"brown"`
    * Find the book in the solution with position == 4.
    * Retrieve and return the corresponding choice letter from the mapping.
