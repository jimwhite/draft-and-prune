2. **Define Variables and Domain:**

   * Define the domain as integers from 1 to 7, where **1 = first place (highest/best)** and **7 = last place (worst)**.
   * Add all variables to the problem with this domain.

3. **Add All-Different Constraint:**
   * Add an `AllDifferentConstraint` to ensure each golfer has a unique finishing position.

4. **Translate Each Statement into Formal Constraints:**
   * "Joe finished above Ana" → Joe’s rank < Ana’s rank (since lower number = better/faster).
   * "Ana finished second-to-last" → Ana’s position = 6 (since last is 7, second-to-last is 6).
   * "Mya finished fourth" → Mya’s position = 4.
   * "Dan finished third" → Dan’s position = 3.
   * "Ada finished second" → Ada’s position = 2.
   * "Eli finished third-to-last" → Eli’s position = 5 (positions from end: last=7, 2nd-to-last=6, 3rd-to-last=5).

5. **Solve the Problem:**
   * Call `getSolutions()` to find all valid assignments.
   * Extract the unique solution (since constraints are sufficient for a single arrangement).
