2.  **Define Variables and Domain:**  
    * Define variables as the five books: `"yellow"`, `"green"`, `"gray"`, `"blue"`, `"orange"`.  
    * Define domain as integers 1 through 5, where position 1 = leftmost and position 5 = rightmost.  
    * Add all variables to the problem with this domain.

3.  **Formulate and Add Constraints:**  
    * Add `AllDifferentConstraint` to enforce uniqueness of positions.  
    * Translate each statement into a constraint:  
        - "The gray book is to the left of the green book" → `gray < green`  
        - "The gray book is the second from the right" → `gray == 4` (since rightmost is 5)  
        - "The yellow book is to the right of the orange book" → `orange < yellow`  
        - "The blue book is the second from the left" → `blue == 2`

4.  **Solve the Problem:**  
    * Call `getSolutions()` to find all valid assignments.  
    * Extract the unique solution (since constraints yield one arrangement).

5.  **Determine Which Choice Is True:**  
    * The question asks which book is third from the left (i.e., position 3).  
    * Create a mapping from choice letters to book names:
