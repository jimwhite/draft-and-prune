1.  **Initialize the Problem Environment:**

2.  **Define Variables and Domain:**  
    * List the seven vehicles as variables: `"minivan"`, `"bus"`, `"limousine"`, `"truck"`, `"convertible"`, `"tractor"`, and `"motorcycle"` (note: fix typo in "motorcyle" → `"motorcycle"` for consistency).  
    * Define the domain as integers 1 to 7, where **1 = oldest** and **7 = newest**, consistent with standard age-ranking conventions implied by "older than"/"newer than".  
    * Add all variables with domain {1,2,3,4,5,6,7} to the problem.

3.  **Add AllDifferent Constraint:**  
    * Enforce that each vehicle has a unique age rank using `AllDifferentConstraint`.

4.  **Translate Each Statement into Constraints:**  
    * "The limousine is older than the minivan" → `limousine < minivan`  
    * "The tractor is older than the limousine" → `tractor < limousine`  
    * "The bus is the newest" → `bus == 7`  
    * "The truck is the third-newest" → Since newest=7, second-newest=6, third-newest=5 ⇒ `truck == 5`  
    * "The motorcycle is the fourth-newest" → fourth-newest = 4th from right in newest→oldest ordering ⇒ position = 7 - 3 = 4 ⇒ `motorcycle == 4`  
    * "The convertible is older than the tractor" → `convertible < tractor`

5.  **Solve the Problem:**  
    * Use `getSolutions()` to find all valid assignments of ranks. Given the constraints, there should be exactly one solution.

6.  **Determine What "Third-Oldest" Means in the Solution:**  
    * In our system (1 = oldest), third-oldest corresponds to rank **3**.  
    * Extract the vehicle that has position/rank 3 from the solution.

7.  **Map the Answer to the Correct Choice Letter:**
