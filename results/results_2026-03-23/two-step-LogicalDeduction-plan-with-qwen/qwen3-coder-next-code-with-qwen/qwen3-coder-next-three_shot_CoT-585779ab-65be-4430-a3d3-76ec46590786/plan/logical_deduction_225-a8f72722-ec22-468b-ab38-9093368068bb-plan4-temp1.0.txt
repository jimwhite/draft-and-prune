1.  **Set Up the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**  
    * Identify the seven variables corresponding to the books: `"purple"`, `"brown"`, `"red"`, `"blue"`, `"gray"`, `"black"`, and `"green"`.  
    * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.  
    * Add all seven variables to the problem with domain `{1, 2, 3, 4, 5, 6, 7}`.

3.  **Formulate and Add Constraints:**  
    * Add an `AllDifferentConstraint` to enforce uniqueness of positions.  
    * Translate each statement into a constraint:  
        - "The brown book is to the left of the green book" → `brown < green`  
        - "The gray book is the second from the left" → `gray == 2`  
        - "The black book is to the left of the gray book" → `black < gray`  
        - "The blue book is to the left of the red book" → `blue < red`  
        - "The blue book is the second from the right" → `blue == 6` (since position 7 is rightmost)  
        - "The green book is to the left of the purple book" → `green < purple`  

4.  **Solve the Problem:**  
    * Call `getSolutions()` to find all valid assignments of positions.  
    * Since the problem is deterministic, extract the unique solution (first element of the solutions list).

5.  **Determine the Correct Answer:**  
    * The question asks: which book is the *third from the right*? In a 7-position sequence, third from the right corresponds to position `7 - 2 = 5`.  
    * Create a dictionary mapping choice letters (`"A"` through `"G"`) to the corresponding book names:  
        `{"A": "purple", "B": "brown", "C": "red", "D": "blue", "E": "gray", "F": "black", "G": "green"}`  
    * Iterate through the choices; for each choice, check if the associated book's position in the solution is equal to `5`.  
    * Output the letter of the first (and only) choice where this condition holds.
