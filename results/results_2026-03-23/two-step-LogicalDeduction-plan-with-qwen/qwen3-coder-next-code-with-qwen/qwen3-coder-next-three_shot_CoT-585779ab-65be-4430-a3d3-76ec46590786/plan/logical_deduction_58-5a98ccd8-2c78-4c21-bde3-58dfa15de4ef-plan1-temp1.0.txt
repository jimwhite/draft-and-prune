    * Define the domain as positions 1 to 5 (1 = leftmost, 5 = rightmost).
    * Add all variables with domain {1,2,3,4,5} to the `Problem` instance.

3.  **Formulate and Add Constraints:**
    * Add an `AllDifferentConstraint` to enforce uniqueness of positions.

        * "The purple book is to the left of the black book" → `purple < black`
        * "The red book is to the right of the brown book" → `brown < red`
        * "The orange book is the second from the left" → `orange == 2`
        * "The black book is the third from the left" → `black == 3`

4.  **Solve for the Arrangement:**
    * Call `getSolutions()` to compute all valid assignments.
    * Extract the unique solution from the list of solutions.

5.  **Determine the Correct Answer:**
    * The question asks which book is second from the left (i.e., at position 2).
    * Map choice letters to book names: "A"→"brown", "B"→"orange", "C"→"red", "D"→"purple", "E"→"black".
