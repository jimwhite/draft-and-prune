1. **Initialize the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Instantiate a `Problem` object to represent the constraint satisfaction problem.

2. **Define Variables and Domain:**  
   * List the seven birds as string variables: `"falcon"`, `"crow"`, `"hawk"`, `"hummingbird"`, `"bluejay"`, `"robin"`, and `"raven"`.  
   * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.  
   * Add all seven variables to the problem with domain `{1, 2, 3, 4, 5, 6, 7}`.

3. **Add Constraints from the Statements:**  
   * Add `AllDifferentConstraint()` to enforce uniqueness of positions.  
   * Translate each statement into a constraint:  
     - "The blue jay is to the right of the robin" → `bluejay > robin`  
     - "The hawk is to the left of the hummingbird" → `hawk < hummingbird`  
     - "The robin is the second from the right" → `robin == 6` (since 7 is rightmost)  
     - "The falcon is the third from the left" → `falcon == 3`  
     - "The crow is to the right of the hummingbird" → `crow > hummingbird`  
     - "The raven is the second from the left" → `raven == 2`

4. **Solve the Problem:**  
   * Call `getSolutions()` to enumerate all valid assignments.  
   * Extract the unique solution (since the problem is deterministic, there should be exactly one solution).  
   * Store the solution as a dictionary mapping each bird to its position.

5. **Identify the Rightmost Bird (Position 7):**  
   * Iterate through the solution dictionary to find which bird has position `7`.  
   * Match that bird name against the choice list:  
     - `"falcon"` → A  
     - `"crow"` → B  
     - `"hawk"` → C  
     - `"hummingbird"` → D  
     - `"bluejay"` → E  
     - `"robin"` → F  
     - `"raven"` → G
