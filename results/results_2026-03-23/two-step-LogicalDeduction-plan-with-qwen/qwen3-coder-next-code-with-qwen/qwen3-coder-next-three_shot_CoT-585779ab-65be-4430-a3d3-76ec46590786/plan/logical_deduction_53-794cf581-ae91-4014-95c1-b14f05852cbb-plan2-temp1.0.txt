1.  **Initialize the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Create an instance of the `Problem` class.

2.  **Define Variables and Domain:**
    * List the five books as variables: `"black"`, `"brown"`, `"yellow"`, `"orange"`, and `"red"`.
    * Define the domain as integers 1 to 5, where **1 = leftmost**, **5 = rightmost**.
    * Add all variables with domain {1,2,3,4,5} to the `Problem` instance.

3.  **Add Constraints:**
    * Add `AllDifferentConstraint()` to ensure each book occupies a unique position.
    * Translate each statement into constraints:
        * "The black book is to the left of the yellow book" → `black < yellow`
        * "The red book is the third from the left" → `red == 3`
        * "The brown book is the second from the left" → `brown == 2`
        * "The yellow book is to the left of the orange book" → `yellow < orange`

4.  **Solve the Problem:**
    * Call `getSolutions()` to retrieve all valid assignments.
    * Extract the first (and only) solution from the list.

5.  **Identify the Rightmost Book:**
    * In the solution, find which book has position value 5 (rightmost).
    * Map the resulting book name to the corresponding choice letter using:
        - `"black"` → "A"
        - `"brown"` → "B"
        - `"yellow"` → "C"
        - `"orange"` → "D"
        - `"red"` → "E"
    * Output the correct choice letter.
