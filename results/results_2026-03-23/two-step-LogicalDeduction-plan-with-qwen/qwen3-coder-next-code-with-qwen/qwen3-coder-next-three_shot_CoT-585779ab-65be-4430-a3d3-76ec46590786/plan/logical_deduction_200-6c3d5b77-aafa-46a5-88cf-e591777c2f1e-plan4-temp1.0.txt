1. **Set Up the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Instantiate a `Problem` object to model the constraint satisfaction problem.

2. **Define Variables and Domain:**  
   * List the seven golfers as variables: `"Dan"`, `"Eve"`, `"Mya"`, `"Amy"`, `"Rob"`, `"Ada"`, and `"Joe"`.  
   * Define the domain of positions as integers from 1 to 7, where **1 = first (best) place** and **7 = last (worst) place**.  
   * Add all seven variables to the problem with their domain {1, 2, ..., 7}.

3. **Add AllDifferent Constraint:**  
   * Enforce that each golfer has a unique finishing position using `AllDifferentConstraint`.

4. **Translate Statements into Constraints:**  
   * Convert each factual statement from the problem into a precise constraint:  
     - "Amy finished third" → ` Amy == 3 `  
     - "Joe finished last" → ` Joe == 7 `  
     - "Mya finished above Dan" → ` Mya < Dan ` (since lower number = better/earlier finish)  
     - "Eve finished fourth" → ` Eve == 4 `  
     - "Amy finished above Rob" → ` Amy < Rob ` (i.e., 3 < Rob ⇒ Rob > 3)  
     - "Ada finished third-to-last" → In a field of 7, third-to-last means position 5 (since last = 7 → second-to-last = 6 → third-to-last = 5), so ` Ada == 5 `

5. **Solve the Problem:**  
   * Use `getSolutions()` to compute all valid assignments of positions to golfers satisfying all constraints.  
   * Extract the unique solution (or any one if multiple exist—though uniqueness is expected here).

6. **Identify Third-to-Last and Match to Choices:**  
   * Determine which golfer occupies position 5 (third-to-last).  
   * Construct a mapping from choice letters to golfer names:  
     A → Dan, B → Eve, C → Mya, D → Amy, E → Rob, F → Ada, G → Joe  
   * Check which choice’s golfer has position 5 in the solution.  
   * Output the corresponding letter as the answer.
