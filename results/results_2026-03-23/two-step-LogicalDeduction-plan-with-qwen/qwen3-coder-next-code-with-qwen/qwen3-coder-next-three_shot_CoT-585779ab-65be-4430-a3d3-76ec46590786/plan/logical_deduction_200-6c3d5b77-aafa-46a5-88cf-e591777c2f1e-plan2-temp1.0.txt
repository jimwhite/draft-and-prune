1.  **Set Up the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Instantiate a `Problem` object to model the golf tournament ranking puzzle.

2.  **Define Variables and Domain:**
    * Identify the seven golfers as variables: `"Dan"`, `"Eve"`, `"Mya"`, `"Amy"`, `"Rob"`, `"Ada"`, and `"Joe"`.
    * Define the domain as integers from 1 to 7, where **1 = first place (best/earliest)** and **7 = last place (worst/latest)**.
    * Add all seven variables with this domain to the `Problem` instance.

3.  **Formulate and Add Constraints:**
    * Add an `AllDifferentConstraint` to ensure no two golfers share the same rank.
    * Translate each clue into a constraint using lambda functions:
        * "Amy finished third" → `amy == 3`
        * "Joe finished last" → `joe == 7`
        * "Mya finished above Dan" → `mya < dan` (lower rank number means better placement)
        * "Eve finished fourth" → `eve == 4`
        * "Amy finished above Rob" → `amy < rob` (i.e., `3 < rob`)
        * "Ada finished third-to-last" → Since last is 7, third-to-last is position `7 - 2 = 5` → `ada == 5`

4.  **Solve the Puzzle:**
    * Call `getSolutions()` to compute all valid solutions.
    * Extract the unique solution (since the puzzle is well-constrained, there should be exactly one).

5.  **Determine the Correct Answer:**
    * Identify which golfer has rank `5` (third-to-last) according to the solved arrangement.
    * Create a dictionary mapping choice letters ("A" through "G") to the corresponding golfer names:
        * "A" → "Dan", "B" → "Eve", "C" → "Mya", "D" → "Amy", "E" → "Rob", "F" → "Ada", "G" → "Joe"
    * Find which choice's golfer has rank `5` in the solution.
    * Return/Print the corresponding letter.
