2.  **Define Variables and Their Domain:**

    * Assign a numerical domain from 1 to 7, where **1 represents the oldest** vehicle and **7 represents the newest**, consistent with standard chronological ranking (smaller number = older).

3.  **Formulate and Add All Constraints:**
    * Add an `AllDifferentConstraint` to ensure each vehicle has a unique age rank.
    * Convert each statement into a constraint using `lambda` functions:
        - "The minivan is the oldest" → `minivan == 1`.
        - "The truck is older than the station wagon" → `truck < station_wagon`.
        - "The truck is newer than the limousine" → `limousine < truck`.
        - "The bus is newer than the convertible" → `convertible < bus`.
        - "The bus is older than the tractor" → `bus < tractor`.
        - "The limousine is newer than the tractor" → `tractor < limousine`.
    * Note: The constraints imply a cycle (`limousine < tractor < bus < convertible < ...` and `tractor < limousine`) — but recheck:  
      From above: `convertible < bus < tractor` and `tractor < limousine < truck`, plus `truck < station_wagon`.  
      Also: `minivan == 1` and `limousine < truck`, `truck < station_wagon`.  
      This yields the full chain: `minivan (1) < ... < tractor < limousine < truck < station_wagon`, and `convertible < bus < tractor`.  
      The constraints are consistent as long as all relative orders hold.

4.  **Solve the Constraint Satisfaction Problem:**
    * Use the `getSolutions()` method to find all valid assignments of ranks to vehicles.
    * Since the problem states the statements are logically consistent, extract the unique (or one of the) solution(s).

5.  **Interpret "third-newest" in Context:**
    * Since ranks are defined with 1 = oldest, 7 = newest, the third-newest corresponds to rank **5** (because: 7=newest, 6=second-newest, 5=third-newest).
    * Verify: position from newest = `7 - rank + 1`. So for third-newest, `7 - rank + 1 = 3` ⇒ `rank = 5`.
