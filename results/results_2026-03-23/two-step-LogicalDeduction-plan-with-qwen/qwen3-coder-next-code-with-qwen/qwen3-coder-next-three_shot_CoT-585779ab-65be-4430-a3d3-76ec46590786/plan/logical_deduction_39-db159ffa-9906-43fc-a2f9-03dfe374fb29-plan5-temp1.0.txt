2.  **Define Variables and Domain:**
    * Define variables as the five books: `"green"`, `"blue"`, `"brown"`, `"gray"`, and `"red"`.
    * Define the domain as integers 1 to 5, where **1 = leftmost**, 2 = second from left, ..., **5 = rightmost**.
    * Add all variables with this domain to the problem.

3.  **Add AllDifferent Constraint:**
    * Add `AllDifferentConstraint()` to ensure each book occupies a unique position.

4.  **Translate Statements into Constraints:**
    * "The green book is to the left of the brown book" → `green < brown`
    * "The gray book is to the left of the blue book" → `gray < blue`
    * "The green book is to the right of the blue book" → `blue < green`
    * "The red book is the leftmost" → `red == 1`

5.  **Solve the Problem:**
    * Call `getSolutions()` to find all valid assignments satisfying all constraints.
    * Extract the first (and only) solution, since the problem is well-constrained.
