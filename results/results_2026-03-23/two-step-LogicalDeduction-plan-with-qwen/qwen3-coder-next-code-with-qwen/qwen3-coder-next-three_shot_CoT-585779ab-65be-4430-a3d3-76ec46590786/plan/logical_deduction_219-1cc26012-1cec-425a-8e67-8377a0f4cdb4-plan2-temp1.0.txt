1. **Initialize the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Create an instance of the `Problem` class to model the constraints.

2. **Define Variables and Domain:**  
   * Define the seven fruits as variables: `"mangoes"`, `"cantaloupes"`, `"apples"`, `"plums"`, `"loquats"`, `"watermelons"`, `"peaches"`.  
   * Define the domain as integers from 1 to 7, where **1 = cheapest** and **7 = most expensive** (higher price rank = more expensive).  
   * Add all variables with this domain to the `Problem` instance.

3. **Formulate and Add Constraints:**  
   * Add an `AllDifferentConstraint` to ensure all fruits have distinct price ranks.  
   * Translate each statement into a constraint using `lambda` functions:  
     - "The plums are more expensive than the mangoes" → `plums < mangoes` (since lower number = cheaper, more expensive means *smaller* rank).  
     - "The watermelons are more expensive than the loquats" → `watermelons < loquats`.  
     - "The loquats are the second-cheapest" → `loquats == 2`.  
     - "The plums are less expensive than the peaches" → `plums > peaches` (plums cheaper ⇒ larger rank).  
     - "The mangoes are the fourth-most expensive" → `mangoes == 4`.  
     - "The peaches are less expensive than the cantaloupes" → `peaches > cantaloupes`.  
   * Note: The apples have no direct constraints, but they will be uniquely determined by elimination.

4. **Solve for the Arrangement:**  
   * Call `getSolutions()` to obtain all valid assignments. Given the constraints, there should be exactly one solution.

5. **Determine the Most Expensive Fruit:**  
   * Identify the fruit with rank 7 (most expensive) in the solution dictionary.  
   * Create a mapping from choice letters to fruit names using the given choices (A→mangoes, B→cantaloupes, C→apples, D→plums, E→loquats, F→watermelons, G→peaches).  
   * Find which fruit has rank 7 and return the corresponding choice letter.
