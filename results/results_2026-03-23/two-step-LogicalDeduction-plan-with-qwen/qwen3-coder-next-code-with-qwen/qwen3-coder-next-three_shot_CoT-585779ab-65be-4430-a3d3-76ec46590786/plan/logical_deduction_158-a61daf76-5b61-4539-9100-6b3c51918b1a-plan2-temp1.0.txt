    * Define the domain for finishing positions as integers from 1 to 7, where **1 = first (best)** and **7 = last**.
    * Add all variables with their domain (1–7) to the `Problem` instance.

3.  **Formulate and Add Constraints:**
    * Add an `AllDifferentConstraint` to ensure each golfer has a unique finishing position.

        * "Ada finished third-to-last" → With 7 golfers, third-to-last is position **5** (positions: 1st=best, 7th=last; last=7, second-last=6, third-last=5), so `Ada == 5`.

4.  **Solve the Problem:**
    * Call `getSolutions()` to find all valid assignments of positions.
    * Extract the unique solution (since constraints are sufficient for a single arrangement).
