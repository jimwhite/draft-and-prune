2. **Define Variables and Domain:**

   * Define the domain for positions as integers 1 through 5, where **1 = leftmost** and **5 = rightmost**.  
   * Add all variables to the problem with this domain.

3. **Formulate and Add Constraints:**

     - "The green book is to the left of the brown book" → `green < brown`  
     - "The gray book is to the left of the blue book" → `gray < blue`  
     - "The green book is to the right of the blue book" → `blue < green`  
     - "The red book is the leftmost" → `red == 1`

4. **Solve for All Valid Arrangements:**  
   * Call `getSolutions()` to find all solutions satisfying the constraints.  
   * Extract the unique solution (since the problem states statements are logically consistent, exactly one solution exists).

   * In our indexing, "third from the left" corresponds to position **3**.
