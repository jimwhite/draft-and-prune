    * Add all seven variables to the problem with this domain.

3.  **Formulate and Add Constraints:**
    * Add an `AllDifferentConstraint` to ensure each book occupies a unique position.
    * Translate each statement into a constraint using `lambda` functions:
        * "The purple book is to the left of the yellow book" → `purple < yellow`
        * "The green book is to the left of the white book" → `green < white`

        * "The white book is the fourth from the left" → `white == 4`
        * "The green book is to the right of the orange book" → `orange < green`
        * "The black book is the second from the left" → `black == 2`

4.  **Solve for Valid Arrangements:**
    * Use `getSolutions()` to find all assignments satisfying all constraints.
    * Since the problem is well-constrained, extract the unique solution from the results.
