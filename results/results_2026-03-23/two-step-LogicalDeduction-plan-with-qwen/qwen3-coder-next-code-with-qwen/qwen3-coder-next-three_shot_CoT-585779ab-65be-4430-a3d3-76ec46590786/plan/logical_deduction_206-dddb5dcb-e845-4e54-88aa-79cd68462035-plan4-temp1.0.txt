1.  **Initialize the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Instantiate a `Problem` object to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**  
    * Define the seven fruit variables: `"loquats"`, `"peaches"`, `"watermelons"`, `"plums"`, `"kiwis"`, `"mangoes"`, and `"pears"`.  
    * Define the domain for each variable as integers from 1 to 7, where **1 = cheapest** and **7 = most expensive**.  
    * Add all variables to the problem with this domain.

3.  **Formulate and Add Constraints:**  
    * Add an `AllDifferentConstraint` to enforce unique price rankings for each fruit.  
    * Translate each statement into a constraint:  
        - "The pears are more expensive than the kiwis" → `kiwis < pears` (kiwis rank is smaller number).  
        - "The watermelons are less expensive than the peaches" → `watermelons < peaches`.  
        - "The mangoes are the third-cheapest" → `mangoes == 3`.  
        - "The watermelons are the third-most expensive" → Since most expensive = 7, third-most expensive = 7 − 2 = **5**, so `watermelons == 5`.  
        - "The plums are the second-most expensive" → 7 − 1 = **6**, so `plums == 6`.  
        - "The loquats are the second-cheapest" → `loquats == 2`.

4.  **Solve the Problem:**  
    * Call `getSolutions()` to compute all satisfying assignments.  
    * Extract the unique solution (a dictionary mapping fruit names to their rank integers).

5.  **Determine the Cheapest Fruit:**  
    * The cheapest fruit corresponds to rank **1**.  
    * Create a mapping from choice letters ("A" through "G") to the corresponding fruit names.  
    * Iterate over the solution dictionary to find the fruit with rank 1.  
    * Return the choice letter associated with that fruit as the answer.
