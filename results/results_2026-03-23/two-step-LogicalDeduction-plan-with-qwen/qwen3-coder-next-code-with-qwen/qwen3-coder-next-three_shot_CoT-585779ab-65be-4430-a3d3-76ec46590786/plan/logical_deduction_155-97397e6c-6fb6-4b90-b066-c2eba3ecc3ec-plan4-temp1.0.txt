1.  **Set Up the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Instantiate a new `Problem` object to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**
    * Identify the seven bird species as variables: `"cardinal"`, `"crow"`, `"hummingbird"`, `"bluejay"`, `"owl"`, `"robin"`, and `"quail"`.
    * Define the position domain as integers from 1 to 7, where 1 = leftmost and 7 = rightmost.
    * Add all seven bird variables with domain {1,2,3,4,5,6,7} to the problem.

3.  **Add AllDifferent Constraint:**
    * Enforce that all birds occupy distinct positions using `AllDifferentConstraint`.

4.  **Translate Each Statement into a Constraint:**
    * "The cardinal is to the right of the crow" → `cardinal > crow`
    * "The quail is the third from the left" → `quail == 3`
    * "The owl is to the right of the robin" → `owl > robin`
    * "The hummingbird is to the right of the blue jay" → `hummingbird > bluejay`
    * "The cardinal is the second from the left" → `cardinal == 2`
    * "The owl is the third from the right" → in a 7-position line, third from the right means position 5 (since positions: left→right = 1,2,3,4,5,6,7; rightmost=7 ⇒ third from right = 7−2=5) → `owl == 5`

5.  **Solve the Problem:**
    * Call `getSolutions()` to find all valid assignments of positions to birds satisfying all constraints.
    * Since the problem is deterministic, there will be exactly one solution; retrieve it.

6.  **Identify the Leftmost Bird:**
    * The leftmost bird has position value 1.
    * Examine the solution dictionary to find which bird is assigned position 1.

7.  **Map the Result to the Correct Choice:**
    * Create a mapping from choice letters ("A" through "G") to the corresponding birds:
        - A → cardinal
        - B → crow
        - C → hummingbird
        - D → blue jay
        - E → owl
        - F → robin
        - G → quail
    * Identify which choice corresponds to the bird found in position 1 and output that letter.
