1. **Initialize the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Create an instance of the `Problem` class to model the golf tournament rankings.

2. **Define Variables and Domain:**  
   * Identify the seven golfers as variables: `"Eve"`, `"Ana"`, `"Amy"`, `"Dan"`, `"Eli"`, `"Rob"`, and `"Mya"`.  
   * Define the domain for each variable as integers from **1 to 7**, where **1 represents first place (top)** and **7 represents last place**.  
   * Add all golfers as variables with domain `{1, 2, 3, 4, 5, 6, 7}` to the `Problem` instance.

3. **Formulate and Add Constraints:**  
   * Add an `AllDifferentConstraint` to ensure all golfers have distinct rankings.  
   * Translate each statement into a constraint using `addConstraint` with a lambda function:  
     - *"Mya finished above Eli"* means Mya’s rank < Eli’s rank (`lambda m, e: m < e`).  
     - *"Eve finished below Rob"* means Eve’s rank > Rob’s rank (`lambda e, r: e > r`).  
     - *"Amy finished second"* means Amy’s rank = 2 (`lambda a: a == 2`).  
     - *"Rob finished below Dan"* means Rob’s rank > Dan’s rank (`lambda r, d: r > d`).  
     - *"Ana finished second-to-last"* means Ana’s rank = 6 (since last is 7, second-to-last is 6) (`lambda a: a == 6`).  
     - *"Dan finished fourth"* means Dan’s rank = 4 (`lambda d: d == 4`).  

4. **Solve the Problem:**  
   * Call `getSolutions()` to obtain all valid ranking assignments.  
   * Since the problem is fully constrained, there should be exactly one solution; extract it (e.g., `solutions[0]`).

5. **Determine the Correct Answer:**  
   * The question asks who finished last — i.e., the golfer with rank **7**.  
   * Build a mapping from choice letters to golfer names: `{'A': 'Eve', 'B': 'Ana', 'C': 'Amy', 'D': 'Dan', 'E': 'Eli', 'F': 'Rob', 'G': 'Mya'}`.
