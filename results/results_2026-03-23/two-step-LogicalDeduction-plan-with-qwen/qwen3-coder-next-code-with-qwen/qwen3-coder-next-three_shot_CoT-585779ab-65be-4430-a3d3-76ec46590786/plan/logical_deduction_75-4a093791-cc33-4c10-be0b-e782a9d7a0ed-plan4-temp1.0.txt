1.  **Set Up the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Create an instance of `Problem()` to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**  
    * Identify the five books as variables: `"blue"`, `"red"`, `"brown"`, `"yellow"`, `"orange"`.  
    * Define the domain as integers `1` to `5`, where `1 = leftmost` and `5 = rightmost`.  
    * Add all variables to the problem with their domain using `addVariable()`.

3.  **Formulate and Add Constraints:**  
    * Add an `AllDifferentConstraint()` to ensure each book occupies a unique position.  
    * Translate the remaining statements into constraints:  
        - `"The red book is to the left of the brown book"` → `red < brown` (using a lambda: `lambda r, b: r < b`).  
        - `"The yellow book is to the right of the orange book"` → `orange < yellow`.  
        - `"The brown book is the second from the left"` → `brown == 2`.  
        - `"The yellow book is to the left of the blue book"` → `yellow < blue`.

4.  **Solve for Valid Arrangements:**  
    * Call `getSolutions()` to enumerate all solutions that satisfy the constraints.  
    * Extract the unique solution (expected to be a single dictionary mapping each book name to its position).

5.  **Determine the Correct Answer:**  
    * The question asks which book is the **second from the right**, i.e., position `4` (since rightmost = 5, second-right = 4).  
    * Create a mapping from choice letters (`"A"` through `"E"`) to the corresponding book names in the choices:  
        `"A": "blue"`, `"B": "red"`, `"C": "brown"`, `"D": "yellow"`, `"E": "orange"`.  
    * For each choice, check if the book's position in the solution equals `4`.  
    * Output (or return) the letter of the first (and correct) matching choice.
