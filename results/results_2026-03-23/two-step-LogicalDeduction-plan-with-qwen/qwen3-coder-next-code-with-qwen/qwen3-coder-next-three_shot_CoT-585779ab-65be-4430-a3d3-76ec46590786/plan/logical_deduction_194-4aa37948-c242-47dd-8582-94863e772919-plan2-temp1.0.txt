1.  **Set Up the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**
    * Identify the seven variables representing the books: `"black"`, `"orange"`, `"yellow"`, `"white"`, `"blue"`, `"red"`, and `"green"`.
    * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.
    * Add all variables with this domain to the problem.

3.  **Formulate and Add Constraints:**
    * Add an `AllDifferentConstraint` to ensure all books occupy distinct positions.
    * Add the following constraints using `addConstraint()` with lambda functions:
        * "The red book is to the right of the yellow book" → `lambda r, y: r > y`
        * "The white book is the second from the right" → `lambda w: w == 6`
        * "The red book is to the left of the green book" → `lambda r, g: r < g`
        * "The blue book is to the right of the black book" → `lambda b, k: b > k`
        * "The black book is the third from the right" → `lambda k: k == 5`
        * "The orange book is the leftmost" → `lambda o: o == 1`

4.  **Solve for the Arrangement:**
    * Call `getSolutions()` to find all valid assignments.
    * Since the problem is well-constrained, there should be exactly one solution; extract it from the list.

5.  **Determine Which Book Is Third from the Left:**
    * The third-from-left position corresponds to index 3 in our 1–7 scale.
    * Iterate through the solution dictionary and find which book has position value 3.

6.  **Match to the Correct Choice:**
    * Create a mapping from choice letters ('A' through 'G') to the corresponding book names:  
        A → "black", B → "orange", C → "yellow", D → "white", E → "blue", F → "red", G → "green".
    * Use the identified book (position 3) to look up the correct choice letter.
    * Output the matching letter as the answer.
