2.  **Define Variables and Domain:**  
    * Define the five fruits as variables: `"watermelons"`, `"apples"`, `"kiwis"`, `"cantaloupes"`, and `"mangoes"`.  
    * Assign a numerical domain of integers from 1 to 5, where **1 represents the cheapest** and **5 represents the most expensive** (ascending cost order).  
    * Add all variables to the problem with this domain using `addVariable()`.

3.  **Translate Statements into Constraints:**  
    * Add an `AllDifferentConstraint` to ensure all fruits have distinct prices (i.e., unique rank values).  
    * Convert each statement into a lambda constraint:  
        - "The cantaloupes are the second-cheapest" → `cantaloupes == 2`.  
        - "The mangoes are more expensive than the watermelons" → `watermelons < mangoes`.  
        - "The kiwis are less expensive than the apples" → `kiwis < apples`.  
        - "The kiwis are more expensive than the mangoes" → `mangoes < kiwis`.

4.  **Solve the Problem:**  
    * Call `getSolutions()` to find all valid assignments of price ranks.  
    * Since the constraints should yield a unique solution, extract the first (and only) solution from the list.

5.  **Identify the Correct Answer:**  
    * The question asks which fruit is the cheapest (i.e., has rank **1**).  
    * Create a mapping from choice letters to fruit names: `"A"` → `"watermelons"`, `"B"` → `"apples"`, `"C"` → `"kiwis"`, `"D"` → `"cantaloupes"`, `"E"` → `"mangoes"`.  
    * Iterate through the solution dictionary to find the fruit with value 1.
