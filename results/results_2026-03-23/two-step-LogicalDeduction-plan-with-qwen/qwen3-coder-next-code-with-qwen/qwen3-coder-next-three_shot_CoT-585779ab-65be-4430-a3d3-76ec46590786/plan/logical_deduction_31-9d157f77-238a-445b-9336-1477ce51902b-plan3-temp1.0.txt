1.  **Initialize the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**  
    * Define the five birds as string variables: `"owl"`, `"cardinal"`, `"robin"`, `"hummingbird"`, and `"crow"`.  
    * Define the domain for positions as integers from 1 to 5, where **1 = leftmost** and **5 = rightmost**.  
    * Add all five variables to the problem with the domain {1, 2, 3, 4, 5}.

3.  **Add Constraints:**  
    * Add an `AllDifferentConstraint` to enforce uniqueness of positions.  
    * Translate each statement into a constraint:  
        - "The hummingbird is to the left of the owl" → `hummingbird < owl`  
        - "The hummingbird is to the right of the cardinal" → `cardinal < hummingbird`  
        - "The crow is to the left of the robin" → `crow < robin`  
        - "The owl is to the left of the crow" → `owl < crow`  

4.  **Solve the Problem:**  
    * Call `getSolutions()` to find all valid arrangements satisfying all constraints.  
    * Extract the solution (the problem has a unique ordering), and store it as a dictionary mapping bird names to positions.

5.  **Determine the Leftmost Bird and Match to Choice:**  
    * Identify the bird with position 1 (leftmost) from the solution.  
    * Map each choice letter to its respective bird: A→"owl", B→"cardinal", C→"robin", D→"hummingbird", E→"crow".  
    * Find the choice letter corresponding to the bird that is at position 1.  
    * Output the correct letter as the final answer.
