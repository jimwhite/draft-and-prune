1.  **Initialize the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Instantiate a `Problem` object to hold the constraint satisfaction problem.

2.  **Define Variables and Domain:**
    * Create a list of the seven books as string variables: `"black"`, `"orange"`, `"yellow"`, `"white"`, `"blue"`, `"red"`, and `"green"`.
    * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.
    * Add all seven variables to the problem with their domain.

3.  **Add All-Different Constraint:**
    * Add an `AllDifferentConstraint` to ensure each book occupies a unique position.

4.  **Translate Statements into Constraints:**
    * "The orange book is the leftmost" → constraint: `orange == 1`.
    * "The black book is the third from the right" → in a 7-position sequence, position 5 = third from the right (positions: 1,2,3,4,**5**,6,7) → constraint: `black == 5`.
    * "The white book is the second from the right" → position 6 → constraint: `white == 6`.
    * "The red book is to the right of the yellow book" → `yellow < red`.
    * "The red book is to the left of the green book" → `red < green`.
    * "The blue book is to the right of the black book" → `black < blue`.

5.  **Solve the Problem:**
    * Call `getSolutions()` to find all valid assignments satisfying all constraints.
    * Since the problem is fully constrained, expect a unique solution; extract it (e.g., `solutions[0]`).

6.  **Determine the Third-from-the-Left Book:**
    * The question asks which book is in position 3.
    * Iterate through the solved assignment dictionary (mapping book names → positions).
    * Find the key (book name) whose assigned value is **3**.

7.  **Map to Correct Choice:**
    * Create a mapping from choice letters (A–G) to book names:
        A → "black", B → "orange", C → "yellow", D → "white", E → "blue", F → "red", G → "green".
    * Retrieve the choice letter corresponding to the book found in position 3.
    * Output that letter as the answer.
