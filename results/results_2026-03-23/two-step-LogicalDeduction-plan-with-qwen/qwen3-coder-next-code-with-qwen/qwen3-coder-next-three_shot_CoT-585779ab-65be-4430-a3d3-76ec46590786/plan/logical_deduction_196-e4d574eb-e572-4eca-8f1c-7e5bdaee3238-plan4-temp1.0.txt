1. **Initialize the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2. **Define Variables and Domain:**  
   * Define the seven fruits as variables: `"oranges"`, `"loquats"`, `"apples"`, `"kiwis"`, `"mangoes"`, `"plums"`, `"peaches"`.  
   * Define the domain as integers from 1 to 7, where **1 = cheapest** and **7 = most expensive**.  
   * Add all variables to the problem with this domain.

3. **Add AllDifferent Constraint:**  
   * Enforce that each fruit has a unique price rank by adding `AllDifferentConstraint`.

4. **Translate Statements to Constraints:**  
   * "The apples are the second-cheapest" → `apples == 2`  
   * "The peaches are the cheapest" → `peaches == 1`  
   * "The plums are the fourth-most expensive" → Since most expensive is 7, fourth-most expensive = position `7 - 4 + 1 = 4` → `plums == 4`  
   * "The loquats are the third-cheapest" → `loquats == 3`  
   * "The kiwis are more expensive than the mangoes" → `kiwis > mangoes`  
   * "The oranges are less expensive than the mangoes" → `oranges < mangoes`  

5. **Solve the Problem:**  
   * Call `getSolutions()` to find all valid assignments. Given consistency and uniqueness implied by the problem, expect exactly one solution.  
   * Extract the sole (or first) solution dictionary.

6. **Determine the Third-Most-Expensive Position:**  
   * Since most expensive = 7, third-most expensive = position `7 - 3 + 1 = 5`.  
   * So we need to find which fruit has rank `5`.

7. **Map Choices and Identify the Correct Answer:**  
   * Build a dictionary mapping choice letters (A–G) to fruit names:  
     `'A': 'oranges', 'B': 'loquats', 'C': 'apples', 'D': 'kiwis', 'E': 'mangoes', 'F': 'plums', 'G': 'peaches'`  
   * Iterate over choices; for each choice, check if the corresponding fruit’s rank in the solution equals `5`.
