1.  **Set Up the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Instantiate a `Problem` object to define and solve the constraint satisfaction problem.

2.  **Define Variables and Domain:**
    * Identify the five fruits as variables: `"loquats"`, `"pears"`, `"watermelons"`, `"kiwis"`, and `"plums"`.
    * Define a domain of integers from 1 to 5 representing price ranking, where **1 = least expensive (lowest rank)** and **5 = most expensive (highest rank)**. Note: Higher numeric value means *more* expensive.
    * Add these variables and domain to the problem.

3.  **Formulate Constraints from Statements:**
    * Add an `AllDifferentConstraint` so that no two fruits share the same price rank.
    * Translate each statement into a constraint using `lambda`:
        * "The loquats are the third-most expensive" → In a 5-item ranking where 5 is *most* expensive, third-most expensive corresponds to rank **3** (since ranks 5,4,3 are most→least: 1st=most expensive=rank5, 2nd=rank4, **3rd=rank3**, etc.). So: `loquats == 3`.
        * "The loquats are more expensive than the watermelons" → loquats rank > watermelons rank (since higher number = more expensive): `loquats > watermelons`.
        * "The plums are less expensive than the watermelons" → plums rank < watermelons rank: `plums < watermelons`.
        * "The kiwis are more expensive than the pears" → kiwis rank > pears rank: `kiwis > pears`.

4.  **Solve the Constraint Satisfaction Problem:**
    * Use `getSolutions()` to compute all valid assignments of ranks to fruits.
    * Since the problem is fully constrained, expect a unique solution; extract it from the list.

5.  **Identify the Second-Most Expensive Fruit:**
    * The question asks which fruit is second-most expensive. In our ranking system (5 = most, 1 = least), **second-most expensive corresponds to rank 4**.
    * Create a mapping from choice letters (A–E) to fruit names (as given in the choices).
    * In the solved assignment, find which fruit has rank **4**.
