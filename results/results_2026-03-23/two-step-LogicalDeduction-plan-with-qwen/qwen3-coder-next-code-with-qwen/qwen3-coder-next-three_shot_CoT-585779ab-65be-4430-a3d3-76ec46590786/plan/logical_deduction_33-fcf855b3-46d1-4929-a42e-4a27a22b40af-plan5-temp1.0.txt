   * Add constraint for "The blue book is the rightmost": `blue == 5`.
   * Add constraint for "The gray book is to the left of the red book": `gray < red`.

4. **Solve for the Arrangement:**
   * Use `getSolutions()` to find all satisfying assignments.
   * Extract the unique solution (expected to be a single dictionary mapping book names to positions).

5. **Determine the Correct Answer:**
   * Identify the leftmost book (position 1) from the solution dictionary.

     - A) gray → 'A'
     - B) red → 'B'
     - C) yellow → 'C'
     - D) blue → 'D'
