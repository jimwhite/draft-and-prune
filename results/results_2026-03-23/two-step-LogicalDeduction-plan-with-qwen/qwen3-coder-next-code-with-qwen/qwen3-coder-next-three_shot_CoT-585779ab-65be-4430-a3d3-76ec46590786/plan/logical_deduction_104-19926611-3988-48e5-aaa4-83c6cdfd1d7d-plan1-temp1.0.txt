1.  **Initialize the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.

2.  **Define Variables and Domain:**
    * Identify the seven birds as variables: `"hawk"`, `"hummingbird"`, `"falcon"`, `"cardinal"`, `"owl"`, `"robin"`, and `"blue jay"`.
    * Define the domain as integers from 1 to 7, where position 1 = leftmost and position 7 = rightmost.
    * Add all variables to the problem with their domain using `addVariable`.

3.  **Add Constraints:**
    * Add an `AllDifferentConstraint` to ensure all birds occupy distinct positions.
    * Translate each statement into a constraint:
        * "The hummingbird is to the left of the owl" → `hummingbird < owl`
        * "The robin is the rightmost" → `robin == 7`
        * "The blue jay is to the left of the hawk" → `blue jay < hawk`
        * "The blue jay is the third from the left" → `blue jay == 3`
        * "The falcon is the fourth from the left" → `falcon == 4`
        * "The cardinal is the second from the right" → `cardinal == 6` (since rightmost is 7, second from right is 6)

4.  **Solve the Problem:**
    * Call `getSolutions()` to find all valid assignments.
    * Extract the unique solution (assumed, as problem states statements are consistent).
