1.  **Initialize the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**
    * List the seven books as variables: `"black"`, `"yellow"`, `"white"`, `"gray"`, `"purple"`, `"orange"`, and `"green"`.
    * Define the domain as integers from 1 to 7 (inclusive), where position 1 is the leftmost and position 7 is the rightmost.
    * Add all variables to the problem with their domain (1–7).

3.  **Add All Different Constraint:**
    * Add an `AllDifferentConstraint` to ensure each book occupies a unique position.

4.  **Translate Each Statement into Explicit Constraints:**
    * "The green book is to the left of the gray book" → `green < gray`
    * "The gray book is the third from the right" → In a 7-position shelf, third from the right means position = 7 − 2 = 5 ⇒ `gray == 5`
    * "The white book is the rightmost" → `white == 7`
    * "The orange book is the second from the left" → `orange == 2`
    * "The black book is to the right of the yellow book" → `yellow < black`
    * "The black book is the third from the left" → `black == 3`

5.  **Solve the Constraint Satisfaction Problem:**
    * Call `getSolutions()` to obtain all valid assignments.
    * Extract the single solution (since the constraints uniquely determine positions).

6.  **Determine the Fourth-from-Left Book:**
    * Identify which book has position value 4 in the solved assignment.
    * Note: "fourth from the left" corresponds to position index 4.

7.  **Map Answer to Choice Letter:**
    * Create a dictionary mapping choice letters (A–G) to book names as listed in the options.
    * Compare the book found at position 4 against each choice’s book name.
    * Output the corresponding choice letter for which the book matches the one at position 4.
