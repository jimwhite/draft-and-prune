1. **Set Up the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.

2. **Define Variables and Domain:**  
   * Define the seven variables corresponding to the fruits: `"loquats"`, `"peaches"`, `"watermelons"`, `"plums"`, `"kiwis"`, `"mangoes"`, and `"pears"`.  
   * Define the domain as integers 1 through 7, where **1 = cheapest** and **7 = most expensive**, reflecting increasing cost order (i.e., lower number means cheaper, higher number means more expensive).  
   * Add all seven fruit variables to the problem with domain {1,2,3,4,5,6,7}.

3. **Translate Statements into Constraints:**  
   * Add an `AllDifferentConstraint` to enforce uniqueness of price ranks.  
   * Convert each sentence into a constraint:  
     - "The pears are more expensive than the kiwis" → `kiwis < pears` (since cheaper = smaller number).  
     - "The watermelons are less expensive than the peaches" → `watermelons < peaches`.  
     - "The mangoes are the third-cheapest" → `mangoes == 3`.  
     - "The watermelons are the third-most expensive" → Since most expensive is 7, third-most expensive = position 5 (because: 7 = 1st most exp., 6 = 2nd, 5 = 3rd), so `watermelons == 5`.  
     - "The plums are the second-most expensive" → `plums == 6`.  
     - "The loquats are the second-cheapest" → `loquats == 2`.

4. **Solve the Constraint Satisfaction Problem:**  
   * Call `getSolutions()` to find all valid assignments of ranks to fruits.  
   * Extract the (unique) solution from the returned list.

5. **Identify the True Statement:**  
   * The question asks: "Which of the following is true?" and all choices refer to "second-most expensive", which corresponds to rank **6**.  
   * Create a dictionary mapping choice letters (`"A"` through `"G"`) to fruit names as per the given options.  
   * In the solved solution, locate which fruit has rank `6`.
