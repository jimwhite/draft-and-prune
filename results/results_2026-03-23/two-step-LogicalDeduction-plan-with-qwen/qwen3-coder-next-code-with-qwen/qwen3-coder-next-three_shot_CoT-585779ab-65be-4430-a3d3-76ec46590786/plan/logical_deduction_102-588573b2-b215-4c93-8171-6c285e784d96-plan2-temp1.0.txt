1. **Set Up the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Create an instance of the `Problem` class to hold variables and constraints.

2. **Define Variables and Domain:**  
   * Identify the seven books as variables: `"black"`, `"yellow"`, `"white"`, `"gray"`, `"purple"`, `"orange"`, `"green"`.  
   * Define the domain as integers from 1 to 7, where **1 = leftmost**, **7 = rightmost**.  
   * Add all seven variables with domain `{1, 2, 3, 4, 5, 6, 7}` to the problem.

3. **Formulate and Add Constraints:**  
   * Add an `AllDifferentConstraint` to ensure each book occupies a unique position.  
   * Translate each statement into a constraint:  
     - "The green book is to the left of the gray book" → `green < gray`  
     - "The gray book is the third from the right" → since 7 is rightmost, third from right = position `7 - 2 = 5`, so `gray == 5`  
     - "The white book is the rightmost" → `white == 7`  
     - "The orange book is the second from the left" → `orange == 2`  
     - "The black book is to the right of the yellow book" → `black > yellow`  
     - "The black book is the third from the left" → `black == 3`  

4. **Solve for the Arrangement:**  
   * Call `getSolutions()` to find all valid assignments.  
   * Extract the (unique) solution from the returned list.

5. **Determine the Fourth-from-Left Book:**  
   * The question asks: "Which book is in position 4?" (since fourth from left = index 4).  
   * Create a dictionary mapping choice letters (`'A'` through `'G'`) to the corresponding book names from the options:  
     `{'A': 'black', 'B': 'yellow', 'C': 'white', 'D': 'gray', 'E': 'purple', 'F': 'orange', 'G': 'green'}`  
   * Iterate through the choices; for each choice letter, check if the book assigned to that choice has position 4 in the solution.  
   * Return the letter corresponding to the book whose position value equals 4.
