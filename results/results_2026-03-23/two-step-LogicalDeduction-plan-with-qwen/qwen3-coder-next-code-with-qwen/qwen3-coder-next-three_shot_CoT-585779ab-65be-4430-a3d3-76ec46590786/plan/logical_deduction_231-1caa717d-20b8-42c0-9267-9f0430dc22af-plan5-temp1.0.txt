    * Add all variables to the problem with this domain.

3.  **Add AllDifferent Constraint:**  
    * Add an `AllDifferentConstraint` to ensure each vehicle has a unique age rank (position).

4.  **Translate Statements into Formal Constraints Using Lambda Functions:**  
    * "The sedan is the third-oldest" → `sedan == 3`  
    * "The tractor is newer than the motorcycle" → `motorcycle < tractor` (since smaller number = older)  
    * "The bus is older than the motorcycle" → `bus < motorcycle`  
    * "The bus is newer than the hatchback" → `hatchback < bus`  
    * "The minivan is the newest" → `minivan == 7`  
    * "The station wagon is the oldest" → `station_wagon == 1`

5.  **Solve the Constraint Satisfaction Problem:**  
    * Call `getSolutions()` to retrieve all valid assignments.  
    * Extract the unique solution (since the problem is fully constrained and consistent).

6.  **Identify the Second-Oldest Vehicle:**  
    * The second-oldest corresponds to rank **2** in our numbering (1 = oldest, 2 = second-oldest).  
    * Iterate through the solution dictionary to find which vehicle has value `2`.
