1. **Initialize the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Create an instance of the `Problem` class to hold the variables and constraints.

2. **Define Variables and Their Domain:**  
   * Define the seven vehicles as variables: `"sedan"`, `"truck"`, `"bus"`, `"station_wagon"`, `"tractor"`, `"convertible"`, and `"limousine"`.  
   * Define the domain as integers from **1 to 7**, where **1 represents the oldest** vehicle and **7 represents the newest**.  
   * Add all variables with domain `{1, 2, 3, 4, 5, 6, 7}` to the `Problem` instance.

3. **Formulate and Add Constraints:**  
   * Add an `AllDifferentConstraint` to enforce uniqueness of age ranks.  
   * Translate each statement into constraints:  
     - "The truck is the oldest" → `truck == 1`  
     - "The tractor is the newest" → `tractor == 7`  
     - "The sedan is older than the station wagon" → `sedan < station_wagon`  
     - "The station wagon is the third-newest" → Since 7 is newest, third-newest = position **5** (newest=7, 2nd-newest=6, 3rd-newest=5) → `station_wagon == 5`  
     - "The bus is older than the convertible" → `bus < convertible`  
     - "The sedan is newer than the convertible" → `convertible < sedan`

4. **Solve for Valid Arrangements:**  
   * Use `getSolutions()` to find all solutions satisfying the constraints.  
   * Extract the unique solution (since the problem is fully constrained).

5. **Determine the Third-Oldest Vehicle:**  
   * Identify the vehicle with rank **3**, as "third-oldest" corresponds to position 3 in our system (1=oldest).  
   * Create a dictionary mapping choice letters (`'A'` through `'G'`) to their respective vehicle names:  
     - `'A'`: `"sedan"`, `'B'`: `"truck"`, `'C'`: `"bus"`, `'D'`: `"station_wagon"`, `'E'`: `"tractor"`, `'F'`: `"convertible"`, `'G'`: `"limousine"`  
   * Iterate through the choice dictionary, checking which vehicle's position in the solution equals 3.  
   * Return the corresponding choice letter as the answer.
