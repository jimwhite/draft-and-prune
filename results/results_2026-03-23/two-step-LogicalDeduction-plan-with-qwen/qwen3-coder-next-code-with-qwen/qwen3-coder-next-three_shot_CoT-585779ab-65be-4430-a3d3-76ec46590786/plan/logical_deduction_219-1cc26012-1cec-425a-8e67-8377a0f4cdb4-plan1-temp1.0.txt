1.  **Set Up the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Instantiate a `Problem` object to model the constraint satisfaction problem.

2.  **Define Variables and Their Domain:**
    * Identify the seven fruits as variables: `"mangoes"`, `"cantaloupes"`, `"apples"`, `"plums"`, `"loquats"`, `"watermelons"`, and `"peaches"`.
    * Define the domain as integers from 1 to 7, where **1 represents the cheapest** and **7 represents the most expensive**, as price rankings increase with cost.
    * Add all seven fruit variables and the domain {1, 2, 3, 4, 5, 6, 7} to the `Problem` instance.

3.  **Formulate and Add Constraints:**
    * Add an `AllDifferentConstraint` to enforce uniqueness of price ranks (no two fruits share the same rank).
    * Translate each statement into a constraint using `lambda` functions:
        - "The plums are more expensive than the mangoes" → `plums > mangoes`.
        - "The watermelons are more expensive than the loquats" → `watermelons > loquats`.
        - "The loquats are the second-cheapest" → `loquats == 2`.
        - "The plums are less expensive than the peaches" → `plums < peaches`.
        - "The mangoes are the fourth-most expensive" → `mangoes == 4`.
        - "The peaches are less expensive than the cantaloupes" → `peaches < cantaloupes`.

4.  **Solve the Constraint Satisfaction Problem:**
    * Call `getSolutions()` to compute all valid assignments of ranks to fruits satisfying all constraints.
    * Extract the unique solution (since the problem is well-constrained, only one solution will exist).

5.  **Identify the Most Expensive Fruit (Rank 7) and Match to Choices:**
    * Scan the solved assignment to find which fruit has rank 7 (most expensive).
    * Create a mapping from choice letters ('A' through 'G') to the corresponding fruit names in the order given in the choices list:  
        `{'A': 'mangoes', 'B': 'cantaloupes', 'C': 'apples', 'D': 'plums', 'E': 'loquats', 'F': 'watermelons', 'G': 'peaches'}`.
    * Determine which choice corresponds to the fruit with rank 7 and output that letter as the answer.
