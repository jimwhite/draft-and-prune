   * Define the domain for these variables as integers from **1 to 7**, where:
     - **1 = cheapest**
     - **7 = most expensive**
   - Add all variables to the problem with this domain.

3. **Translate Rules into Constraints:**
   * Add an `AllDifferentConstraint` to ensure each fruit has a unique price rank.

     - "The plums are the second-most expensive" → `plums == 6` (7−1).
     - "The loquats are the second-cheapest" → `loquats == 2`.

4. **Solve the Problem:**
   * Use `getSolutions()` to find all valid assignments.
   * Extract the unique solution (since constraints fix most positions, only 2 variables may vary but constraints should fully determine all).
