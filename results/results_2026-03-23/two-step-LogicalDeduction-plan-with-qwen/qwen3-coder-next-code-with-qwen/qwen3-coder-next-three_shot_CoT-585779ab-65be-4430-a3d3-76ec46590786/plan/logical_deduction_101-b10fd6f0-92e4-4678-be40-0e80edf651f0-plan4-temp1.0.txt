2.  **Define Variables and Domain:**

    * Define the domain as integers from 1 to 7, where **1 represents the cheapest** and **7 represents the most expensive**.  
    * Add all seven variables with domain {1, 2, ..., 7} to the `Problem` instance.

3.  **Formulate and Add Constraints:**  
    * Add an `AllDifferentConstraint` to ensure each fruit has a unique price rank.  
    * Translate each statement into a constraint using `lambda` functions:  
        * "The pears are more expensive than the oranges" → `pears > oranges`  
        * "The oranges are more expensive than the cantaloupes" → `oranges > cantaloupes`  
        * "The peaches are less expensive than the cantaloupes" → `peaches < cantaloupes`  
        * "The apples are the third-cheapest" → `apples == 3`  
        * "The watermelons are the second-most expensive" → `watermelons == 6` (since most expensive = 7, second-most = 6)  
        * "The mangoes are the fourth-most expensive" → `mangoes == 4` (since most expensive = 7, fourth-most = 7−3 = 4)

4.  **Solve for the Arrangement:**  
    * Call `getSolutions()` to find all valid assignments satisfying the constraints.  
    * Extract the unique solution (the problem is well-constrained, so only one solution exists).
