1.  **Set Up the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Instantiate the `Problem` class to begin building the constraint satisfaction problem.

2.  **Define Variables and Domain:**
    * Define the seven fruits as variables: `"loquats"`, `"peaches"`, `"watermelons"`, `"plums"`, `"kiwis"`, `"mangoes"`, and `"pears"`.
    * Define the domain for positions as integers from 1 to 7, where **1 represents the cheapest** and **7 represents the most expensive**.
    * Add all seven variables to the problem with domain {1, 2, 3, 4, 5, 6, 7}.

3.  **Add AllDifferent Constraint:**
    * Add an `AllDifferentConstraint` to ensure all fruits have distinct price ranks.

4.  **Translate Each Statement into Constraints:**
    * "The pears are more expensive than the kiwis" → `kiwis < pears`
    * "The watermelons are less expensive than the peaches" → `watermelons < peaches`
    * "The mangoes are the third-cheapest" → `mangoes == 3`
    * "The watermelons are the third-most expensive" → Since most expensive is highest rank (7), third-most expensive = 7 - 2 = 5 → `watermelons == 5`
    * "The plums are the second-most expensive" → Second-most expensive = 7 - 1 = 6 → `plums == 6`
    * "The loquats are the second-cheapest" → `loquats == 2`

5.  **Solve the Problem:**
    * Call `getSolutions()` to compute all valid assignments.
    * Extract the unique solution (only one should exist given the constraints).

6.  **Identify the Most Expensive Fruit:**
    * The most expensive fruit corresponds to position value 7.
    * From the solution, find which fruit has rank 7.

7.  **Map to Correct Choice:**
    * Create a mapping from choice letters (A–G) to fruit names:
        A: "loquats", B: "peaches", C: "watermelons", D: "plums", E: "kiwis", F: "mangoes", G: "pears"
    * Identify the choice letter whose fruit has rank 7 in the solution.
