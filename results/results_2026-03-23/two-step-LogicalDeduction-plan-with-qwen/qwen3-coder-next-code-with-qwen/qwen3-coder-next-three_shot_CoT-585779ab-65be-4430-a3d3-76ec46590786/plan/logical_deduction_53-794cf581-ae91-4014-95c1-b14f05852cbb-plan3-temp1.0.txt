1.  **Initialize the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Instantiate a `Problem` object to model the constraint satisfaction problem.

2.  **Define Variables and Their Domain:**
    * Define the five books as variables: `"black"`, `"brown"`, `"yellow"`, `"orange"`, and `"red"`.
    * Assign the domain of integer positions from 1 to 5 (inclusive), where **1 = leftmost** and **5 = rightmost**.
    * Add all five variables with this domain to the `Problem` instance.

3.  **Add All Different Constraint:**
    * Enforce that all books occupy distinct positions using `AllDifferentConstraint`.

4.  **Encode Each Statement as a Constraint:**
    * "The black book is to the left of the yellow book" → `black < yellow`
    * "The red book is the third from the left" → `red == 3`
    * "The brown book is the second from the left" → `brown == 2`
    * "The yellow book is to the left of the orange book" → `yellow < orange`

5.  **Solve the Problem:**
    * Call `getSolutions()` to retrieve all valid assignments.
    * Extract the unique solution from the list (since constraints are consistent and sufficient to yield one arrangement).

6.  **Determine Which Book Is Rightmost (Position 5):**
    * Examine the solution dictionary to find which book has value 5.
    * Map that book name to the corresponding choice letter using the provided options:
        - A) black → check if solution["black"] == 5
        - B) brown → check if solution["brown"] == 5
        - C) yellow → check if solution["yellow"] == 5
        - D) orange → check if solution["orange"] == 5
        - E) red → check if solution["red"] == 5
    * Return the letter (e.g., "D") corresponding to the book found at position 5.
