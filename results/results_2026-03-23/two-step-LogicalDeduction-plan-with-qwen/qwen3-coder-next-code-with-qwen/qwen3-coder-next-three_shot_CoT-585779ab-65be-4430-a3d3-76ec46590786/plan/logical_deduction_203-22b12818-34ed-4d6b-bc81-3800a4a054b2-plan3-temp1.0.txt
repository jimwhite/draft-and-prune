1. **Set Up the Problem Environment:**
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
   * Instantiate a `Problem` object to model the golf tournament ranking constraints.

2. **Define Variables and Domain:**
   * Define the seven golfers as variables: `"Eli"`, `"Eve"`, `"Mel"`, `"Joe"`, `"Mya"`, `"Rob"`, and `"Ada"`.
   * Define the domain as integers 1 through 7, where **1 = first place (highest/most left)** and **7 = last place (lowest/most right)**.
   * Add all variables with domain `{1,2,3,4,5,6,7}` to the problem.

3. **Translate Statements into Constraints:**
   * Add an `AllDifferentConstraint` to ensure each golfer has a unique rank.
   * Add constraints using lambda functions:
        * "Ada finished above Mya" → Ada's rank < Mya's rank (`lambda a, m: a < m`)
        * "Eli finished below Joe" → Eli's rank > Joe's rank (`lambda e, j: e > j`)
        * "Eli finished above Eve" → Eli's rank < Eve's rank (`lambda e, ev: e < ev`)
        * "Ada finished second-to-last" → Ada's rank = 6 (since last is 7)
        * "Mel finished third" → Mel's rank = 3
        * "Rob finished fourth" → Rob's rank = 4

4. **Solve the Constraint Satisfaction Problem:**
   * Call `getSolutions()` to compute all valid rank assignments.
   * Extract the unique solution (or one of the solutions, as there should be only one consistent assignment).

5. **Identify the Correct Answer:**
   * The question asks: who finished second? i.e., which golfer has rank = 2?
   * Create a mapping from choice letters to golfer names: 
        `{'A': 'Eli', 'B': 'Eve', 'C': 'Mel', 'D': 'Joe', 'E': 'Mya', 'F': 'Rob', 'G': 'Ada'}`
   * Iterate through the choices; for each choice letter, check if the corresponding golfer’s rank in the solution equals 2.
