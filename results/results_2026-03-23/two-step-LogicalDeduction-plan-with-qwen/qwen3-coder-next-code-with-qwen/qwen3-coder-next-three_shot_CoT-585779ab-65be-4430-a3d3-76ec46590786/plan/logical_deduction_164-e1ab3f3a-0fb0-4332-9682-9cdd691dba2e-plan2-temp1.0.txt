1.  **Set Up the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Instantiate a `Problem` object to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**
    * Define the variables as the seven fruits: `"mangoes"`, `"kiwis"`, `"oranges"`, `"watermelons"`, `"apples"`, `"pears"`, and `"loquats"`.
    * Define the domain as integers from 1 to 7, where **1 represents the cheapest** and **7 represents the most expensive** fruit.
    * Add all variables to the problem with this domain.

3.  **Add All-Different Constraint:**
    * Add an `AllDifferentConstraint` to ensure each fruit has a unique price rank (no ties).

4.  **Translate Each Statement into Constraints:**
    * "The loquats are less expensive than the oranges" → `loquats < oranges`
    * "The oranges are the third-most expensive" → Since 7 is most expensive, third-most expensive = rank 5 (because: 7=1st-most-expensive, 6=2nd-most, 5=3rd-most)
    * "The apples are the cheapest" → `apples == 1`
    * "The kiwis are more expensive than the pears" → `kiwis > pears`
    * "The mangoes are more expensive than the watermelons" → `mangoes > watermelons`
    * "The loquats are more expensive than the kiwis" → `loquats > kiwis`

5.  **Solve the Problem:**
    * Call `getSolutions()` to obtain all valid solutions.
    * Extract the (unique) solution dictionary from the returned list.

6.  **Identify the Most Expensive Fruit:**
    * The question asks which fruit is the most expensive → find the fruit with rank 7.
    * Create a mapping from choice letters (A through G) to their corresponding fruit names:  
        A→"mangoes", B→"kiwis", C→"oranges", D→"watermelons", E→"apples", F→"pears", G→"loquats"
    * Iterate through the choices, check which fruit in the solution has rank 7.
    * Return the corresponding choice letter as the answer.
