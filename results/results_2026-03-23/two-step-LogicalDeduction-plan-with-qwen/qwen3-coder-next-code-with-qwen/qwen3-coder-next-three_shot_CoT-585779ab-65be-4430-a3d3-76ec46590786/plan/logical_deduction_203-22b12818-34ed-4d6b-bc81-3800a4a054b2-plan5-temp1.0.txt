    * Define the domain for each variable as integers from 1 to 7, where **1 = first place (highest finish)** and **7 = last place (lowest finish)** — i.e., *smaller number means better (earlier) finish*.
    * Add all seven golfers as variables with domain {1, 2, ..., 7} to the `Problem` instance.

3.  **Formulate Constraints from Statements:**

        * "Eli finished below Joe" → Eli's position > Joe's position (`lambda e, j: e > j`).
        * "Eli finished above Eve" → Eli's position < Eve's position (`lambda e, v: e < v`).
        * "Ada finished second-to-last" → Ada's position = 6 (since last is 7, second-to-last is 6).
        * "Mel finished third" → Mel's position = 3.
        * "Rob finished fourth" → Rob's position = 4.

4.  **Solve the Constraint Satisfaction Problem:**
    * Call `getSolutions()` to obtain all valid assignments of positions to golfers.
    * Extract the unique solution (or any one solution, since uniqueness is implied by problem consistency).
