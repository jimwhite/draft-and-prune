1. **Set Up the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.

2. **Define Variables and Domain:**  
   * Define the five books as variables: `"white"`, `"green"`, `"brown"`, `"gray"`, `"orange"`.  
   * Assign a position domain of integers 1 to 5, where **1 = leftmost**, **2 = second from left**, ..., **5 = rightmost**.  
   * Add all variables to the problem with this domain using `addVariable`.

3. **Formulate and Add Constraints:**  
   * Add an `AllDifferentConstraint` to enforce uniqueness of positions.  
   * Translate each statement into a constraint:  
     - "The gray book is to the right of the orange book" → `gray > orange` (position value greater).  
     - "The green book is the second from the right" → `green == 4` (since rightmost = 5, second-right = 4).  
     - "The brown book is to the right of the white book" → `brown > white`.  
     - "The brown book is to the left of the orange book" → `brown < orange`.  
   * Add all four constraints using `addConstraint` with appropriate lambda functions or direct relational constraints (e.g., `lambda g, o: g > o` for gray > orange).

4. **Solve the Problem:**  
   * Call `getSolutions()` to retrieve all valid assignments.  
   * Extract the unique solution (a dictionary mapping book names to positions) from the solutions list.

5. **Determine the Correct Answer:**  
   * The question asks which book is the **second from the left**, i.e., position 2.  
   * Map the answer choices:  
     - A → white, B → green, C → brown, D → gray, E → orange.  
   * Iterate over the solution to find which book has position 2.  
   * Return the corresponding choice letter (A–E) as the answer.
