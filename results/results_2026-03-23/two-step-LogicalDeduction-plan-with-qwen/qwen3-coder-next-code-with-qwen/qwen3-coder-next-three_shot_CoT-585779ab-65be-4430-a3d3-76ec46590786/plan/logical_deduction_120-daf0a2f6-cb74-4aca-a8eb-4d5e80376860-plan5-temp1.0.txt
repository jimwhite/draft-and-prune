1.  **Initialize the Constraint Satisfaction Problem:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Instantiate a `Problem` object to model the pricing ranking of the seven fruits.

2.  **Define Variables and Domain:**
    * Create a list of strings representing the seven fruits as variables: `"loquats"`, `"peaches"`, `"watermelons"`, `"plums"`, `"kiwis"`, `"mangoes"`, and `"pears"`.
    * Define the domain as integers from 1 to 7, where **1 represents the cheapest** and **7 represents the most expensive** fruit.
    * Add all variables with their domain (1–7) to the `Problem` instance.

3.  **Add All-Different Constraint:**
    * Add an `AllDifferentConstraint` to ensure each fruit has a unique price rank (no ties).

4.  **Translate Each Statement into Constraints:**
    * "The pears are more expensive than the kiwis" → `pears > kiwis` (using a lambda constraint: `lambda pears, kiwis: pears > kiwis`)
    * "The watermelons are less expensive than the peaches" → `watermelons < peaches`
    * "The mangoes are the third-cheapest" → `mangoes == 3`
    * "The watermelons are the third-most expensive" → Since 7 is most expensive, third-most expensive = position `7 - 3 + 1 = 5`, so `watermelons == 5`
    * "The plums are the second-most expensive" → `plums == 7 - 2 + 1 = 6`, so `plums == 6`
    * "The loquats are the second-cheapest" → `loquats == 2`

5.  **Solve the Problem:**
    * Call `getSolutions()` to find all valid assignments of ranks satisfying all constraints.
    * Extract the unique solution (the problem is deterministic).

6.  **Identify the Fourth-Most-Expensive Fruit:**
    * In our system (1=cheapest, 7=most expensive), the fourth-most-expensive fruit corresponds to rank = `7 - 4 + 1 = 4`.
    * So find the fruit with rank value `4` in the solution dictionary.

7.  **Map to Answer Choices:**
    * Create a mapping from choice letters (A–G) to the corresponding fruit names:
        A → `"loquats"`, B → `"peaches"`, C → `"watermelons"`, D → `"plums"`, E → `"kiwis"`, F → `"mangoes"`, G → `"pears"`
    * Iterate through the choices; for each choice, check if its fruit's rank in the solution equals `4`.
