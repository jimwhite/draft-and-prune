1.  **Initialize the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Instantiate a `Problem` object to encapsulate the constraints and variables.

2.  **Define Variables and Domain:**
    * Define the seven birds as string variables: `"blue jay"`, `"owl"`, `"hawk"`, `"falcon"`, `"hummingbird"`, `"robin"`, and `"quail"`.
    * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.
    * Add all variables to the `Problem` instance with this domain.

3.  **Formulate and Add Constraints:**
    * Add an `AllDifferentConstraint` to ensure all birds occupy distinct positions.
    * Translate each statement into a constraint:
        - "The hummingbird is to the left of the falcon" → `hummingbird < falcon`.
        - "The owl is the second from the left" → `owl == 2`.
        - "The robin is to the left of the hummingbird" → `robin < hummingbird`.
        - "The quail is to the right of the falcon" → `quail > falcon`.
        - "The robin is to the right of the owl" → `robin > owl`.
        - "The blue jay is the third from the right" → `blue jay == 5` (since positions: 1=leftmost, 7=rightmost ⇒ third from right is position 5).

4.  **Solve the Constraint Problem:**
    * Use `getSolutions()` to compute all valid assignments.
    * Extract the unique solution (the list will contain one dictionary mapping bird names to positions).

5.  **Determine the Leftmost Bird and Match to Choices:**
    * The leftmost position is 1; identify which bird has position value 1 in the solution.
    * Create a mapping from choice letters (`'A'` through `'G'`) to the corresponding bird names in the order given in the choices:
        `{'A': 'blue jay', 'B': 'owl', 'C': 'hawk', 'D': 'falcon', 'E': 'hummingbird', 'F': 'robin', 'G': 'quail'}`.
    * Find the choice letter whose bird name matches the one at position 1.
    * Output that choice letter as the answer.
