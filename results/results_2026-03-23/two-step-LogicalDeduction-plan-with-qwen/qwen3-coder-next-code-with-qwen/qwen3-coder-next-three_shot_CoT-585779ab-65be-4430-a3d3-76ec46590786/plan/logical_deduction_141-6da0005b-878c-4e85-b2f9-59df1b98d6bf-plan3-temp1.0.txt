1.  **Initialize the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Create an instance of the `Problem` class to represent the constraint satisfaction problem.

2.  **Define Variables and Their Domain:**  
    * Identify the variables: the seven golfers as strings: `"Joe"`, `"Rob"`, `"Eli"`, `"Dan"`, `"Mya"`, `"Ada"`, `"Ana"`.  
    * Define the domain: integers from 1 to 7, where **1 = first place (highest)** and **7 = last place (lowest)**.  
    * Add all variables with this domain to the `Problem` instance.

3.  **Translate Statements into Constraints:**  
    * Add an `AllDifferentConstraint` to ensure each golfer has a unique finishing position.  
    * Convert each statement into a constraint using `addConstraint` with lambda functions:  
        * "Joe finished above Ana" → Joe’s position < Ana’s position (`lambda j, a: j < a`).  
        * "Ana finished second-to-last" → Ana’s position = 6 (since last is 7, second-to-last is 6).  
        * "Mya finished fourth" → Mya’s position = 4.  
        * "Dan finished third" → Dan’s position = 3.  
        * "Ada finished second" → Ada’s position = 2.  
        * "Eli finished third-to-last" → third-to-last in a 7-golfer race is position 5 (positions: 1st,2nd,3rd,4th,5th,6th,7th → 3rd-from-last = 5th). So Eli’s position = 5.

4.  **Solve the Problem:**  
    * Call `getSolutions()` to obtain all valid assignments.  
    * Extract the unique solution (a dictionary mapping golfers → positions) since the constraints fully determine the ordering.

5.  **Identify the Correct Answer:**  
    * The question asks: which golfer finished last? → position = 7.  
    * Create a mapping from choice letters to golfer names: `{"A":"Joe", "B":"Rob", "C":"Eli", "D":"Dan", "E":"Mya", "F":"Ada", "G":"Ana"}`.  
    * In the solved solution, find which golfer has position 7.  
    * Return the choice letter corresponding to that golfer.
