1.  **Initialize the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Instantiate a `Problem` object to define the constraint satisfaction problem.

2.  **Define Variables and Domain:**  
    * Identify the seven fruits as variables: `"oranges"`, `"loquats"`, `"apples"`, `"kiwis"`, `"mangoes"`, `"plums"`, `"peaches"`.  
    * Define the domain as integers from 1 to 7, where **1 = cheapest** and **7 = most expensive** (standard price ranking from lowest to highest cost).  
    * Add all variables with domain {1,2,3,4,5,6,7} to the problem.

3.  **Formulate and Add Constraints:**  
    * Add an `AllDifferentConstraint` to ensure all fruits have distinct price ranks.  
    * Translate each statement into a constraint using lambda functions:  
        - "The apples are the second-cheapest" → `apples == 2`.  
        - "The peaches are the cheapest" → `peaches == 1`.  
        - "The plums are the fourth-most expensive" → Since there are 7 items, *fourth-most expensive* = 4th from the top (most expensive), which corresponds to rank **4** in descending price. But since our domain is ascending (1=cheapest), *fourth-most expensive* = 7 - 4 + 1 = **4** (same as fourth-cheapest in this symmetric case). Verify: positions from most expensive (7) to cheapest (1): 7=most, 6=2nd-most, 5=3rd-most, **4=4th-most** → so `plums == 4`.  
        - "The loquats are the third-cheapest" → `loquats == 3`.  
        - "The kiwis are more expensive than the mangoes" → `mangoes < kiwis` (since lower rank = cheaper).  
        - "The oranges are less expensive than the mangoes" → `oranges < mangoes` (since oranges are cheaper).  

4.  **Solve the Problem:**  
    * Call `getSolutions()` to find all valid assignments.  
    * Extract the unique solution (as the problem is well-constrained).

5.  **Determine the Third-Most-Expensive Fruit:**  
    * In our domain (1=cheapest, 7=most expensive), the **third-most expensive** corresponds to rank = 7 - 3 + 1 = **5**.  
    * Create a mapping from choice letters to fruit names (A→"oranges", B→"loquats", ..., G→"peaches").  
    * Iterate through choices: for each choice, check if the fruit’s rank in the solution equals 5.  
    * Return the letter of the choice where this condition holds.
