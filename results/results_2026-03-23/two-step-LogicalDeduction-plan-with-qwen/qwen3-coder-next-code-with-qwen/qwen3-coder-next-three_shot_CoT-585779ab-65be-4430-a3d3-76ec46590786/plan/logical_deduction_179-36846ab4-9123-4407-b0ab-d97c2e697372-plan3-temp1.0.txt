1. **Set Up the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Instantiate a `Problem` object to model the constraint satisfaction problem.

2. **Define Variables and Domain:**  
   * Define the seven birds as string variables: `"hawk"`, `"raven"`, `"hummingbird"`, `"falcon"`, `"owl"`, `"quail"`, and `"cardinal"`.  
   * Define the domain of positions as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.  
   * Add all seven variables with domain `{1, 2, 3, 4, 5, 6, 7}` to the problem.

3. **Add Constraints from Statements:**  
   * Add an `AllDifferentConstraint` to enforce uniqueness of positions.  
   * Translate each logical statement into a constraint:  
     - "The quail is to the left of the hummingbird" → `quail < hummingbird`  
     - "The raven is to the right of the hummingbird" → `hummingbird < raven`  
     - "The cardinal is the second from the left" → `cardinal == 2`  
     - "The owl is to the left of the cardinal" → `owl < cardinal`  
     - "The raven is the third from the right" → Since rightmost is 7, third from right = 7 − 2 = **5**, so `raven == 5`  
     - "The falcon is the rightmost" → `falcon == 7`

4. **Solve the Constraint Satisfaction Problem:**  
   * Use `getSolutions()` to retrieve all valid assignments. Given the problem’s uniqueness, expect exactly one solution.  
   * Extract the first (and only) solution dictionary.

5. **Determine Which Bird Is Third from the Left:**  
   * The question asks: which bird occupies position **3**? (since third from left = index 3 in 1-based left-to-right).  
   * Build a mapping from choice letters to bird names:  
     - `'A' → 'hawk'`, `'B' → 'raven'`, `'C' → 'hummingbird'`, `'D' → 'falcon'`, `'E' → 'owl'`, `'F' → 'quail'`, `'G' → 'cardinal'`  
   * For each choice letter in order, check if the corresponding bird's position in the solution equals `3`.  
   * Return (or output) the first matching choice letter as the answer.
