1. **Set Up the Problem Environment:**
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
   * Instantiate a `Problem` object to model the constraint satisfaction problem.

2. **Define Variables and Domain:**
   * Identify the seven books as variables: `"purple"`, `"brown"`, `"red"`, `"blue"`, `"gray"`, `"black"`, `"green"`.
   * Define the domain as integers 1 to 7, where **1 = leftmost** and **7 = rightmost**.
   * Add all seven variables to the problem with their domain.

3. **Formulate and Add Constraints:**
   * Add an `AllDifferentConstraint` to ensure uniqueness of positions.
   * Convert each statement into a precise constraint:
     * "The brown book is to the left of the green book" → `brown < green`
     * "The gray book is the second from the left" → `gray == 2`
     * "The black book is to the left of the gray book" → `black < gray`
     * "The blue book is to the left of the red book" → `blue < red`
     * "The blue book is the second from the right" → `blue == 6` (since position 7 is rightmost, second from right = 6)
     * "The green book is to the left of the purple book" → `green < purple`

4. **Solve for All Valid Arrangements:**
   * Use `getSolutions()` to find all solutions that satisfy the constraints.
   * Extract the unique solution (since the problem states logical consistency and implies uniqueness).

5. **Determine the Third-from-Left Position:**
   * In our scheme, third from left = position 3.
   * Create a mapping from choice letters to book names: `'A' → 'purple'`, `'B' → 'brown'`, `'C' → 'red'`, `'D' → 'blue'`, `'E' → 'gray'`, `'F' → 'black'`, `'G' → 'green'`.
