1.  **Initialize the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Instantiate a `Problem` object to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**  
    * Define the seven books as variables: `"orange"`, `"green"`, `"red"`, `"gray"`, `"purple"`, `"blue"`, and `"brown"`.  
    * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.  
    * Add all seven variables to the problem with this domain.

3.  **Add All-Different Constraint:**  
    * Enforce that each book occupies a unique position using `AllDifferentConstraint`.

4.  **Translate Each Statement into Explicit Positional Constraints:**  
    * "The purple book is the fourth from the left" → `purple == 4`  
    * "The brown book is the third from the left" → `brown == 3`  
    * "The green book is to the left of the blue book" → `green < blue`  
    * "The red book is the leftmost" → `red == 1`  
    * "The gray book is the third from the right" → Since there are 7 positions, 3rd from the right = position `7 - 2 = 5`, so `gray == 5`  
    * "The orange book is the rightmost" → `orange == 7`

5.  **Solve the Constraint Satisfaction Problem:**  
    * Call `getSolutions()` to find all valid assignments. Given the fixed positions and constraints, there should be exactly one solution.

6.  **Identify the Third-from-the-Right Book:**  
    * Note that "third from the right" corresponds to position `7 - 3 + 1 = 5`. (Alternatively: positions from right: 1st=7, 2nd=6, **3rd=5**.)  
    * In the solution dictionary, find which book has position value `5`.

7.  **Map to the Correct Choice Letter:**  
    * Create a mapping from choice letters (`['A', 'B', 'C', 'D', 'E', 'F', 'G']`) to the corresponding book names:  
        A → orange, B → green, C → red, D → gray, E → purple, F → blue, G → brown  
    * Retrieve the book at position 5 from the solution.  
    * Find which choice letter corresponds to that book and output it as the answer.
