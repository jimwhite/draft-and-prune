1.  **Set Up the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Instantiate a `Problem` object to model the constraint satisfaction problem for seven birds.

2.  **Define Variables and Domain:**  
    * Define the set of variables as the seven birds: `"quail"`, `"raven"`, `"hummingbird"`, `"robin"`, `"falcon"`, `"owl"`, and `"blue jay"`.  
    * Define the domain as integer positions from 1 to 7 (inclusive), where position 1 is leftmost and position 7 is rightmost.  
    * Add all seven bird variables to the problem with domain {1, 2, 3, 4, 5, 6, 7}.

3.  **Add Global Constraint:**  
    * Add an `AllDifferentConstraint` to ensure that each bird occupies a unique position.

4.  **Translate Each Statement into Constraints:**  
    * "The blue jay is to the left of the falcon" → `blue_jay < falcon`.  
    * "The blue jay is the second from the right" → Since positions are 1 (leftmost) to 7 (rightmost), second from the right is position 6 → `blue_jay == 6`.  
    * "The raven is to the left of the robin" → `raven < robin`.  
    * "The owl is the third from the right" → Positions from right: 1st=7, 2nd=6, 3rd=5 → `owl == 5`.  
    * "The hummingbird is to the left of the quail" → `hummingbird < quail`.  
    * "The raven is the third from the left" → Position 3 → `raven == 3`.

5.  **Solve the Problem:**  
    * Call `getSolutions()` on the problem instance to obtain all valid assignments of positions to birds.  
    * Extract the (unique) solution dictionary mapping each bird name to its position.

6.  **Identify the Rightmost Bird:**  
    * Determine which bird has position 7 (rightmost) in the solution.  
    * Create a mapping from choice letters ('A' to 'G') to bird names:  
        A → "quail", B → "raven", C → "hummingbird", D → "robin", E → "falcon", F → "owl", G → "blue jay".  
    * Find the choice whose corresponding bird has position 7, and return its letter as the answer.
