1. **Initialize the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Instantiate a `Problem` object to model the golf tournament ordering.

2. **Define Variables and Domain:**  
   * Define variables as the seven golfers: `"Joe"`, `"Dan"`, `"Ada"`, `"Amy"`, `"Rob"`, `"Mya"`, and `"Mel"`.  
   * Use integer positions from 1 to 7, where **1 = first place (best / highest finish)** and **7 = last place**.  
   * Add all seven variables with domain `{1, 2, 3, 4, 5, 6, 7}` to the problem.

3. **Formulate and Add Constraints:**  
   * Add `AllDifferentConstraint` to ensure each golfer has a unique finishing position.  
   * Translate each relative-order statement into a constraint using `lambda` functions:  
     - "Ada finished below Amy" → Amy’s position is better (smaller number) than Ada’s: `amy < ada`.  
     - "Joe finished below Dan" → Dan’s position is better than Joe’s: `dan < joe`.  
     - "Dan finished below Ada" → Ada’s position is better than Dan’s: `ada < dan`.  
     - "Mel finished third-to-last" → In a 7-golfer field, third-to-last means position `7 - 2 = 5` (since last is 7, second-to-last is 6, third-to-last is 5): `mel == 5`.  
     - "Amy finished third" → `amy == 3`.  
     - "Rob finished below Mya" → Mya’s position is better (smaller) than Rob’s: `mya < rob`.

4. **Solve the Problem:**  
   * Call `getSolutions()` to obtain all valid orderings.  
   * Extract the unique solution (since constraints are consistent and complete, only one solution exists).  

5. **Identify the Correct Answer:**  
   * The question asks who finished **first**, i.e., whose position value is `1`.  
   * Create a dictionary mapping choice letters (`'A'` to `'G'`) to golfer names: `{'A': 'Joe', 'B': 'Dan', 'C': 'Ada', 'D': 'Amy', 'E': 'Rob', 'F': 'Mya', 'G': 'Mel'}`.  
   * In the solution dictionary, find which golfer has value `1`.  
   * Return the corresponding choice letter.
