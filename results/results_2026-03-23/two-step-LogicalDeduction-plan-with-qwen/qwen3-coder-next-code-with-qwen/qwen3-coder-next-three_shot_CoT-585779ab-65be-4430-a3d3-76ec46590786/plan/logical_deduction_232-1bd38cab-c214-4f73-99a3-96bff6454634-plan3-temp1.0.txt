2.  **Define Variables and Domain:**
    * Define the seven books as variables: `"red"`, `"purple"`, `"green"`, `"white"`, `"orange"`, `"blue"`, and `"gray"`.
    * Define the domain as integers 1 through 7, where **1 = leftmost** and **7 = rightmost**.
    * Add all variables to the `Problem` with the domain [1, 2, 3, 4, 5, 6, 7].

3.  **Add AllDifferentConstraint:**
    * Add an `AllDifferentConstraint` to ensure each book occupies a unique position.

4.  **Translate Statements into Constraints:**
    * "The green book is to the left of the white book" → `green < white`
    * "The red book is to the left of the purple book" → `red < purple`
    * "The red book is to the right of the orange book" → `orange < red`
    * "The gray book is the second from the left" → `gray == 2`
    * "The purple book is to the left of the green book" → `purple < green`
    * "The blue book is the fourth from the left" → `blue == 4`

5.  **Solve the Problem:**
    * Call `getSolutions()` to obtain all valid arrangements.
    * Since the constraints are sufficient, there will be exactly one solution; retrieve it.

6.  **Identify the Rightmost Book (position 7):**
    * For each solution, examine the position value of each book.
    * Find which book has position 7 (rightmost).
    * Map this book to the corresponding choice letter using the provided choices:
        - A) red → if `solution['red'] == 7`
        - B) purple → if `solution['purple'] == 7`
        - C) green → if `solution['green'] == 7`
        - D) white → if `solution['white'] == 7`
        - E) orange → if `solution['orange'] == 7`
