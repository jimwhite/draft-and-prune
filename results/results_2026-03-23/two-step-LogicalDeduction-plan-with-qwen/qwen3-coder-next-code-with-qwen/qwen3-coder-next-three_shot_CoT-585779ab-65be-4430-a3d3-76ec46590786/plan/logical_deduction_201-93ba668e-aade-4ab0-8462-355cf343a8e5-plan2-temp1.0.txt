2. **Define Variables and Domain:**

   * Define the domain as integers from 1 to 7, where **1 = leftmost**, **2 = second from left**, ..., **7 = rightmost**.  
   * Add all variables to the problem with this domain.

3. **Add All-Different Constraint:**  
   * Enforce that each book occupies a unique position using `AllDifferentConstraint`.

4. **Translate Each Statement into Formal Constraints Using Lambda Functions:**  
   * "The brown book is to the left of the green book" → `brown < green`  
   * "The gray book is the second from the left" → `gray == 2`  
   * "The black book is to the left of the gray book" → `black < gray`  
   * "The blue book is to the left of the red book" → `blue < red`  
   * "The blue book is the second from the right" → `blue == 6` (since rightmost = 7, second-rightmost = 6)  
   * "The green book is to the left of the purple book" → `green < purple`

5. **Solve the Problem:**  
   * Call `getSolutions()` to compute all satisfying assignments.  
   * Extract the unique solution from the list of solutions.
