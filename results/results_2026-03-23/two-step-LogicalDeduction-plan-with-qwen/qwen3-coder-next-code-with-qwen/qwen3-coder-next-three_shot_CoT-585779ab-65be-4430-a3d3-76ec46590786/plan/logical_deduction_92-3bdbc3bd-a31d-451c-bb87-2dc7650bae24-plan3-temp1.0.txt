1.  **Set Up the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Instantiate the `Problem` class to create the constraint satisfaction problem.

2.  **Define Variables and Their Domain:**
    * Define the variables as the five books: `"white"`, `"green"`, `"brown"`, `"gray"`, and `"orange"`.
    * Assign a domain of integers from 1 to 5, where **1 = leftmost** and **5 = rightmost**.
    * Add all variables with their domain to the `Problem` instance.

3.  **Formulate and Add Constraints:**
    * Add an `AllDifferentConstraint` to ensure each book occupies a unique position.
    * Translate each statement into a constraint using `lambda` functions:
        - "The gray book is to the right of the orange book" → `gray > orange`
        - "The green book is the second from the right" → `green == 4` (since position 5 is rightmost, 4 is second-rightmost)
        - "The brown book is to the right of the white book" → `brown > white`
        - "The brown book is to the left of the orange book" → `brown < orange`

4.  **Solve for the Arrangement:**
    * Call `getSolutions()` to compute all valid assignments satisfying the constraints.
    * Extract the unique solution from the returned list of solutions.

5.  **Determine the Correct Answer:**
    * Identify which book is in position 2 (second from the left).
    * Map choice letters to books: A→"white", B→"green", C→"brown", D→"gray", E→"orange".
    * Find which book in the solution has position 2 and return its corresponding choice letter.
