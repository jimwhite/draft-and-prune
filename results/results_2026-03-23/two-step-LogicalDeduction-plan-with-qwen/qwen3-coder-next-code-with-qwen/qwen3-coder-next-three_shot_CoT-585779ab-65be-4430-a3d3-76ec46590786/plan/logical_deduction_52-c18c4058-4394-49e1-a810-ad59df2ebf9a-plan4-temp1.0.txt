1.  **Initialize the Constraint Satisfaction Problem:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Create an instance of the `Problem` class.

2.  **Define Variables and Domain:**  
    * Define the variables as the five birds: `"cardinal"`, `"hawk"`, `"hummingbird"`, `"raven"`, and `"owl"`.  
    * Define the domain for each variable as integers 1 through 5, where **1 = leftmost** and **5 = rightmost**.  
    * Add all variables with their domain to the `Problem` instance.

3.  **Add Constraints from Statements:**  
    * Add an `AllDifferentConstraint` to ensure all birds occupy distinct positions.  
    * Translate each statement into a constraint:  
        - "The raven is to the left of the hummingbird" → `raven < hummingbird`  
        - "The hawk is to the left of the owl" → `hawk < owl`  
        - "The cardinal is to the left of the hawk" → `cardinal < hawk`  
        - "The raven is the second from the right" → `raven == 4` (since position 5 is rightmost, second from right = 4).

4.  **Solve the Problem:**  
    * Call `getSolutions()` to find all valid assignments.  
    * Extract the (unique) solution dictionary from the results.

5.  **Determine Which Bird is Leftmost (Position 1):**  
    * Iterate through the solution dictionary to find which bird has position value `1`.  
    * Map this bird to the corresponding choice letter using the provided choices:  
        - `'A'` → `"cardinal"`  
        - `'B'` → `"hawk"`  
        - `'C'` → `"hummingbird"`  
        - `'D'` → `"raven"`  
        - `'E'` → `"owl"`  
    * Output the choice letter corresponding to the bird at position 1.
