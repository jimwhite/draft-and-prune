2.  **Define Variables and Domain:**
    * Identify the five books as variables: `"brown"`, `"orange"`, `"red"`, `"purple"`, and `"black"`.
    * Define the domain as integers 1 to 5, where **1 = leftmost** and **5 = rightmost**.
    * Add all variables with the domain to the problem.

3.  **Formulate and Add Constraints:**
    * Add an `AllDifferentConstraint` to ensure each book occupies a unique position.
    * Add constraint: `"purple"` is left of `"black"` → `purple < black`.
    * Add constraint: `"red"` is right of `"brown"` → `"brown" < "red"`.
    * Add constraint: `"orange"` is second from left → `orange == 2`.
    * Add constraint: `"black"` is third from left → `black == 3`.

4.  **Solve the Problem:**
    * Call `getSolutions()` to find all valid assignments.
    * Extract the first (unique) solution from the list of solutions.

5.  **Determine Which Book Is Second From the Right:**
    * The second-from-right position corresponds to **position 4** (since positions are 1=leftmost, 5=rightmost).
    * Create a mapping from choice letters to book names as given in the choices.
    * Iterate through the solution dictionary, find which book has position 4.
    * Return the corresponding choice letter (e.g., "A" if brown book is at position 4, etc.).
