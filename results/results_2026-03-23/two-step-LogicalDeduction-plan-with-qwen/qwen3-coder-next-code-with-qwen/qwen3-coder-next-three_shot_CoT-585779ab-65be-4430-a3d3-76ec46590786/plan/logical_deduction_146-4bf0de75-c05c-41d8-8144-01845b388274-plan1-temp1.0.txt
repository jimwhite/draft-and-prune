1.  **Set Up the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Instantiate the `Problem` class to begin building the constraint satisfaction model.

2.  **Define Variables and Domain:**  
    * Identify the seven birds as variables: `"falcon"`, `"crow"`, `"hawk"`, `"hummingbird"`, `"bluejay"`, `"robin"`, and `"raven"` (note: "blue jay" becomes `"bluejay"` for simplicity in naming).  
    * Define the position domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.  
    * Add all seven bird variables with domain {1, 2, ..., 7} to the `Problem` instance.

3.  **Formulate and Add Constraints:**  
    * Add an `AllDifferentConstraint` to enforce uniqueness of positions.  
    * Translate each statement into a constraint:  
        - "The blue jay is to the right of the robin" → `bluejay > robin`  
        - "The hawk is to the left of the hummingbird" → `hawk < hummingbird`  
        - "The robin is the second from the right" → `robin == 6`  
        - "The falcon is the third from the left" → `falcon == 3`  
        - "The crow is to the right of the hummingbird" → `crow > hummingbird`  
        - "The raven is the second from the left" → `raven == 2`

4.  **Solve for the Arrangement:**  
    * Call `getSolutions()` to compute all valid assignments.  
    * Extract the unique solution from the returned list (the problem guarantees consistency and uniqueness of the ordering).

5.  **Determine the Rightmost Bird (Position 7):**  
    * Extract the position value for each bird from the solution dictionary.  
    * Identify which bird has position 7 (rightmost).  
    * Map that bird to the correct choice letter from the given list (`'A)' falcon`, `'B)' crow`, ..., `'G)' raven`).  
    * Return the letter (e.g., `"B"` if crow is rightmost) as the answer.
