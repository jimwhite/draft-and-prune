1.  **Initialize the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Create an instance of the `Problem` class to model the golf tournament ordering constraints.

2.  **Define Variables and Domain:**
    * List the seven golfers as string variables: `"amy"`, `"eve"`, `"ada"`, `"rob"`, `"dan"`, `"mel"`, `"joe"`.
    * Define the domain as integers from 1 to 7, where **1 = first place** (highest rank) and **7 = last place** (lowest rank).
    * Add all seven variables to the `Problem` instance with this domain.

3.  **Translate Each Statement into Constraints:**
    * Add an `AllDifferentConstraint` to ensure each golfer has a unique finishing position.
    * Add constraints using lambda functions for each clue:
        * "Joe finished third" → `joe == 3`
        * "Dan finished last" → `dan == 7`
        * "Eve finished first" → `eve == 1`
        * "Mel finished below Rob" → `rob < mel` (Rob's position number is smaller, meaning he placed higher)
        * "Ada finished above Joe" → `ada < joe` (i.e., `ada < 3`)
        * "Rob finished third-to-last" → third-to-last among 7 finishers is position **5** (since 7 - 3 + 1 = 5), so `rob == 5`

4.  **Solve the Constraint Satisfaction Problem:**
    * Call `getSolutions()` to find all valid permutations satisfying the constraints.
    * Extract the unique solution from the list (the problem has exactly one solution).

5.  **Analyze the Solution to Answer the Question:**
    * The question asks which golfer finished in **fourth place**, i.e., position 4.
    * Create a mapping from choice letters (`'A'` through `'G'`) to the corresponding golfer names (e.g., `'A': 'amy'`, `'B': 'eve'`, ..., `'G': 'joe'`).
    * For each choice, check if the golfer’s position in the solution equals 4.
    * Return (or print) the letter of the first choice that satisfies this condition — that is the correct answer.
