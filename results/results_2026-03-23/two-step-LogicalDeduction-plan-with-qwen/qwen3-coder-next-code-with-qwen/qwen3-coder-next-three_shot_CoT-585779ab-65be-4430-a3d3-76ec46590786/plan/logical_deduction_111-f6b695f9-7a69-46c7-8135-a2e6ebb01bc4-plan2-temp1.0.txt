   * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.
   * Add all seven variables with domain `{1, 2, 3, 4, 5, 6, 7}` to the problem.

3. **Add Constraints:**
   * Add an `AllDifferentConstraint` to enforce unique positions.
   * Add constraints using lambda functions based on the statements:
     * `"The yellow book is the rightmost"` → `yellow == 7`
     * `"The blue book is to the left of the orange book"` → `blue < orange`
     * `"The green book is to the right of the white book"` → `white < green`
     * `"The blue book is to the right of the green book"` → `green < blue`
     * `"The black book is the fourth from the left"` → `black == 4`
     * `"The brown book is the third from the right"` → since rightmost is 7, third from right = 7 - 2 = **5**, so `brown == 5`

4. **Solve the Problem:**
   * Call `getSolutions()` to obtain all valid assignments.
   * Since the constraints uniquely determine the arrangement (as stated), extract the first (and only) solution dictionary.
