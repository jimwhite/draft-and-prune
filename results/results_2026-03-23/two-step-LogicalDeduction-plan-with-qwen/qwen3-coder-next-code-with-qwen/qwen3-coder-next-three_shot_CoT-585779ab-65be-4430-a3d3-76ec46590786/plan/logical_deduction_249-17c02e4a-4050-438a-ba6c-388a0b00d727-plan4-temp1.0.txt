        * "Rob finished above Joe" → Rob’s position number is **less than** Joe’s (`Rob < Joe`).  
    * These two inequalities together imply the strict ordering: `Rob < Joe < Ana`.

4.  **Solve for the Finishing Order:**  
    * Call `getSolutions()` to compute all valid assignments satisfying the constraints.  
    * Extract the unique solution (since the ordering is fully constrained).

5.  **Determine Who Finished Second:**  
    * The second place corresponds to position number **2**.  
    * Examine the solution dictionary to find which golfer has a value of 2.

        - If `"Ana"` is in position 2 → Choice A.
