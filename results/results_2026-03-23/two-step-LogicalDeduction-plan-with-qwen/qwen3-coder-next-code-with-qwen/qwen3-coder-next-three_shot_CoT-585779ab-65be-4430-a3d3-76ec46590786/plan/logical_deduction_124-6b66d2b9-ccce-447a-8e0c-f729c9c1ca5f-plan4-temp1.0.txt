1.  **Initialize the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**  
    * Identify the seven books as variables: `"black"`, `"orange"`, `"yellow"`, `"white"`, `"blue"`, `"red"`, and `"green"`.  
    * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.  
    * Add all seven variables to the problem with domain `{1, 2, 3, 4, 5, 6, 7}`.

3.  **Formulate and Add Constraints:**  
    * Add an `AllDifferentConstraint` to ensure all books occupy distinct positions.  
    * Translate each statement into constraints:  
        * "The orange book is the leftmost" → `orange == 1`.  
        * "The black book is the third from the right" → `black == 5` (since positions: leftmost=1, ..., third from right = 7−2=5).  
        * "The white book is the second from the right" → `white == 6` (7−1=6).  
        * "The red book is to the right of the yellow book" → `yellow < red`.  
        * "The red book is to the left of the green book" → `red < green`.  
        * "The blue book is to the right of the black book" → `black < blue`.

4.  **Solve the Problem:**  
    * Call `getSolutions()` to retrieve all valid assignments of positions to books.  
    * Extract the unique solution (since the problem is deterministic and consistent).

5.  **Determine the Rightmost Book:**  
    * Identify the book assigned to position 7 (rightmost) using the solution dictionary.  
    * Map the book name to the corresponding choice letter:  
        - `"black"` → "A", `"orange"` → "B", `"yellow"` → "C", `"white"` → "D", `"blue"` → "E", `"red"` → "F", `"green"` → "G".  
    * Output the letter corresponding to the book in position 7 as the answer.
