   * Identify the seven golfers as variables: `"Eve"`, `"Ana"`, `"Amy"`, `"Dan"`, `"Eli"`, `"Rob"`, and `"Mya"`.  
   * Define the domain as integers from 1 to 7, where **1 = highest rank (finishes first/above)** and **7 = lowest rank (finishes last/below)**.

3. **Translate Statements into Constraints:**  
   * Add an `AllDifferentConstraint` to enforce unique rankings for each golfer.  
   * Convert each statement into a formal constraint:  
     - "Mya finished above Eli" → `Mya`'s rank < `Eli`'s rank (`lambda m, e: m < e`).  
     - "Eve finished below Rob" → `Rob`'s rank < `Eve`'s rank (`lambda r, ev: r < ev`).  
     - "Amy finished second" → `Amy`'s rank = 2 (`lambda a: a == 2`).  
     - "Rob finished below Dan" → `Dan`'s rank < `Rob`'s rank (`lambda d, r: d < r`).  
     - "Ana finished second-to-last" → position 6 (since last = 7, second-to-last = 6) → `Ana`'s rank = 6 (`lambda an: an == 6`).  
     - "Dan finished fourth" → `Dan`'s rank = 4 (`lambda d: d == 4`).

4. **Solve for the Complete Ranking:**  
   * Call `getSolutions()` to compute all valid assignments satisfying every constraint.  
   * Extract the unique solution (or first solution if multiple exist, though uniqueness is implied).
