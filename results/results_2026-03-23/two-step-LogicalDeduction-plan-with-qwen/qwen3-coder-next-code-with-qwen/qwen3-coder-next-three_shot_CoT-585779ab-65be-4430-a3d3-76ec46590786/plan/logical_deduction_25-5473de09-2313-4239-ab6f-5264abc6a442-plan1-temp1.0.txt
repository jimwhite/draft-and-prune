2.  **Define Variables and Domain:**  
    * Identify the five books as variables: `"blue"`, `"purple"`, `"yellow"`, `"black"`, and `"green"`.  
    * Define the domain as integers 1 to 5, where **1 = leftmost** and **5 = rightmost** position.  
    * Add all five variables to the problem with the domain {1, 2, 3, 4, 5}.

3.  **Add Constraints Based on Statements:**  
    * Add an `AllDifferentConstraint` to ensure each book occupies a unique position.  
    * Translate each statement into a constraint:  
        - "The purple book is the third from the left" → `purple == 3`  
        - "The green book is to the left of the purple book" → `green < 3` (since purple = 3)  
        - "The blue book is to the left of the green book" → `blue < green`  
        - "The yellow book is to the left of the black book" → `yellow < black`

4.  **Solve the Problem:**  
    * Call `getSolutions()` to find all valid assignments of positions to books.  
    * Extract the unique solution (there should be exactly one given consistency and uniqueness implied by the problem).

5.  **Determine Which Book Is Second From the Right:**  
    * The second-from-right position corresponds to index **4** (since rightmost = 5, so 5 − 1 = 4).  
    * Map the answer choices to books: A → blue, B → purple, C → yellow, D → black, E → green.  
    * In the solution dictionary, locate which book has position value = 4.
