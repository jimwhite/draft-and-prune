2.  **Define Variables and Domain:**

    * Define the domain as integers from 1 to 5, where **1 = leftmost** and **5 = rightmost**.
    * Add all variables with the domain [1, 2, 3, 4, 5] to the problem instance.

3.  **Formulate and Add Constraints:**
    * Add an `AllDifferentConstraint` to enforce uniqueness of positions.
    * Translate each statement into a lambda constraint:
        * "The red book is to the left of the brown book" → `lambda r, b: r < b` (red position < brown position).
        * "The yellow book is to the right of the orange book" → `lambda o, y: o < y` (orange position < yellow position).
        * "The brown book is the second from the left" → `lambda br: br == 2` (brown position = 2).
        * "The yellow book is to the left of the blue book" → `lambda y, bl: y < bl` (yellow position < blue position).

4.  **Solve for the Arrangement:**
    * Call `getSolutions()` to retrieve all valid assignments.
    * Extract the sole solution from the list (since the constraints yield a unique arrangement).
