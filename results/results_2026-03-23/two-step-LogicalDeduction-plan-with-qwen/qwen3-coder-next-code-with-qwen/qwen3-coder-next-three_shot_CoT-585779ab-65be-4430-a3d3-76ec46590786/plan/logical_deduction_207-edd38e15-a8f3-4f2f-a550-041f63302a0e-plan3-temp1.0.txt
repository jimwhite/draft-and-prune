1.  **Set Up the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Create an instance of the `Problem` class to model the golf tournament ranking puzzle.

2.  **Define Variables and Domain:**  
    * Identify the seven variables: `"Eli"`, `"Eve"`, `"Mel"`, `"Joe"`, `"Mya"`, `"Rob"`, and `"Ada"`.  
    * Define the domain as integers from 1 to 7, where **1 = best (highest/earliest) rank** and **7 = worst (lowest/latest) rank**.  
    * Add all seven variables with this domain to the `Problem` instance.

3.  **Translate Statements into Constraints:**  
    * Add an `AllDifferentConstraint` to enforce unique rankings for all golfers.  
    * Convert each verbal statement into a numeric constraint:  
        - "Ada finished above Mya" → Ada’s rank < Mya’s rank (`Ada < Mya`).  
        - "Eli finished below Joe" → Eli’s rank > Joe’s rank (`Eli > Joe`).  
        - "Eli finished above Eve" → Eli’s rank < Eve’s rank (`Eli < Eve`).  
        - "Ada finished second-to-last" → Ada’s rank = 6 (since last is 7, second-to-last is position 6).  
        - "Mel finished third" → Mel’s rank = 3.  
        - "Rob finished fourth" → Rob’s rank = 4.

4.  **Solve the Constraint Satisfaction Problem:**  
    * Call `getSolutions()` to find all valid assignments of ranks satisfying the constraints.  
    * Extract the unique solution from the resulting list (the problem guarantees consistency and uniqueness).

5.  **Determine Which Golfer is Second-to-Last:**  
    * The question asks which golfer finished in second-to-last place (i.e., rank 6).  
    * Construct a dictionary mapping the choice letters ("A" through "G") to the corresponding golfer names:  
        `"A"` → `"Eli"`, `"B"` → `"Eve"`, `"C"` → `"Mel"`, `"D"` → `"Joe"`, `"E"` → `"Mya"`, `"F"` → `"Rob"`, `"G"` → `"Ada"`.  
    * Inspect the solution dictionary for which golfer has rank 6.  
    * Return (or print) the choice letter whose associated golfer matches rank 6.
