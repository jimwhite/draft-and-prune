1. **Initialize the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Instantiate a `Problem` object to model the constraint satisfaction problem.

2. **Define Variables and Domain:**  
   * Define the seven birds as variables: `"hawk"`, `"raven"`, `"hummingbird"`, `"falcon"`, `"owl"`, `"quail"`, and `"cardinal"`.  
   * Define the domain for each variable as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.  
   * Add all variables to the problem with this domain.

3. **Add Constraints Based on Statements:**  
   * Add an `AllDifferentConstraint` to enforce uniqueness of positions.  
   * Translate each statement into a constraint:  
     - "The quail is to the left of the hummingbird" → `quail < hummingbird`  
     - "The raven is to the right of the hummingbird" → `hummingbird < raven`  
     - "The cardinal is the second from the left" → `cardinal == 2`  
     - "The owl is to the left of the cardinal" → `owl < cardinal` (i.e., `owl < 2`)  
     - "The raven is the third from the right" → `raven == 5` (since positions: left-to-right = [1,2,3,4,5,6,7]; rightmost=7 ⇒ third from right = 7−2=5)  
     - "The falcon is the rightmost" → `falcon == 7`  

4. **Solve the Problem:**  
   * Use `getSolutions()` to find all valid assignments satisfying all constraints.  
   * Since the problem is fully constrained, extract the unique solution (first and only element from the returned list).

5. **Determine Which Statement Is True:**  
   * The question asks: which bird is the **fourth from the left**? This corresponds to position **4**.  
   * Create a mapping dictionary: `{'A': 'hawk', 'B': 'raven', 'C': 'hummingbird', 'D': 'falcon', 'E': 'owl', 'F': 'quail', 'G': 'cardinal'}`.  
   * Iterate over the choices: for each choice letter, check if the corresponding bird’s position in the solution equals 4.  
   * Return (or record) the correct choice letter where this condition holds.
