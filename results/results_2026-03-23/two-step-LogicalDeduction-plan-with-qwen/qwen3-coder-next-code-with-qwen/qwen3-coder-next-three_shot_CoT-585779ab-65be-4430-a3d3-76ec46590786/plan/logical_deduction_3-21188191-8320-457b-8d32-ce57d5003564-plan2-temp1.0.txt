1.  **Initialize the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.

2.  **Define Variables and Their Domain:**
    * Identify the five fruits as variables: `"watermelons"`, `"plums"`, `"apples"`, `"peaches"`, and `"kiwis"`.
    * Define a numerical domain of integers from 1 to 5, where **1 represents the cheapest** and **5 represents the most expensive**.
    * Add all five fruit variables to the problem, each with domain `{1, 2, 3, 4, 5}`.

3.  **Translate Rules into Constraints:**
    * Add an `AllDifferentConstraint` to enforce that each fruit has a unique price rank.
    * Convert each statement into a constraint using lambda functions:
        * "The apples are less expensive than the peaches" → `apples < peaches`
        * "The plums are the cheapest" → `plums == 1`
        * "The kiwis are the second-cheapest" → `kiwis == 2`
        * "The watermelons are more expensive than the peaches" → `peaches < watermelons`

4.  **Solve for the Arrangement:**
    * Use `getSolutions()` to find all valid assignments satisfying all constraints.
    * Extract the unique solution from the returned list of solutions.

5.  **Identify the Correct Answer:**
    * The question asks which fruit is the most expensive, i.e., has rank **5**.
    * Create a mapping from choice letters (A–E) to fruit names: `{"A": "watermelons", "B": "plums", "C": "apples", "D": "peaches", "E": "kiwis"}`.
    * Iterate through the solution dictionary to find which fruit has position 5.
    * Return (or output) the choice letter corresponding to that fruit.
