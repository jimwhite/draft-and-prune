2.  **Define Variables and Domain:**
    * Define the five birds as variables: `"cardinal"`, `"hawk"`, `"hummingbird"`, `"raven"`, and `"owl"`.
    * Set the domain for each variable as integers 1 through 5, where **1 = leftmost position** and **5 = rightmost position**.
    * Add all variables with their domain to the problem instance.

3.  **Add Constraints:**
    * Add `AllDifferentConstraint()` to enforce that each bird occupies a unique position.
    * Translate each statement into constraints using `addConstraint` with lambda functions:
        * "The raven is to the left of the hummingbird" → `lambda r, h: r < h`
        * "The hawk is to the left of the owl" → `lambda hk, ow: hk < ow`
        * "The cardinal is to the left of the hawk" → `lambda c, hk: c < hk`
        * "The raven is the second from the right" → position 4 (since positions are 1 to 5 left-to-right), so `lambda r: r == 4`

4.  **Solve the Problem:**
    * Call `getSolutions()` to find all valid assignments.
    * Extract the unique solution from the list (the problem has one solution).

5.  **Determine Correct Answer:**
    * The question asks which bird is third from the left → position 3.

    * Iterate through the choices; for each, check if the corresponding bird's position in the solution equals 3.
