   * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.

3. **Add AllDifferentConstraint:**  
   * Enforce that all books occupy distinct positions using `AllDifferentConstraint()`.

4. **Translate Each Statement into Formal Constraints Using Lambda Functions:**

   * "The gray book is to the left of the orange book" → `gray < orange`

   * "The black book is the fourth from the left" → `black == 4`  
   * "The orange book is to the left of the white book" → `orange < white`

5. **Solve the Problem:**  
   * Call `getSolutions()` to retrieve all valid assignments.  
   * Given consistency and fixed order, expect exactly one solution.
