1. **Initialize the Problem Environment:**
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
   * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2. **Define Variables and Domain:**
   * Define the seven variables as strings representing the books: `"orange"`, `"green"`, `"red"`, `"gray"`, `"purple"`, `"blue"`, and `"brown"`.
   * Define the domain for positions as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.
   * Add all variables with their domain (1–7) to the `Problem` instance.

3. **Formulate and Add Constraints:**
   * Add an `AllDifferentConstraint` to enforce uniqueness of positions.
   * Add constraints using lambda functions for each statement:
     * "The purple book is the fourth from the left" → `purple == 4`
     * "The brown book is the third from the left" → `brown == 3`
     * "The green book is to the left of the blue book" → `green < blue`
     * "The red book is the leftmost" → `red == 1`
     * "The gray book is the third from the right" → since there are 7 positions, 3rd from the right = position 5 (7 − 2 = 5), so `gray == 5`
     * "The orange book is the rightmost" → `orange == 7`

4. **Solve for All Valid Arrangements:**
   * Call `getSolutions()` to retrieve all possible solutions.
   * Given the constraints, there should be exactly one valid assignment; extract it (e.g., `solutions[0]`).

5. **Determine Which Book Is Third From the Right:**
   * Recognize that "third from the right" corresponds to position 5 (as computed above).
   * Extract the book assigned to position 5 from the solution dictionary.
   * Compare that book against the choice options:
     - A) orange → check if `orange == 5`
     - B) green
     - C) red
     - D) gray → check if `gray == 5` (but we already know `gray == 5`, so this is necessarily true)
     - E) purple
     - F) blue
     - G) brown
   * Since the constraint explicitly sets `gray == 5`, choice D is guaranteed to be true.
   * Identify and output the correct choice letter ("D").
