    * Add all variables to the problem with this domain.

3.  **Formulate and Add Constraints:**  
    * Add an `AllDifferentConstraint` to ensure each golfer has a unique rank.  
    * Translate each statement into constraints using lambda functions:

        - "Eve finished below Rob" → `Rob < Eve`.  
        - "Amy finished second" → `Amy == 2`.  
        - "Rob finished below Dan" → `Dan < Rob`.  
        - "Ana finished second-to-last" → `Ana == 6` (since last is 7, second-to-last is 6).  
        - "Dan finished fourth" → `Dan == 4`.

4.  **Solve the Problem:**  
    * Call `getSolutions()` to compute all valid assignments.  
    * Extract the unique solution (the list will contain one dictionary mapping golfers to ranks).
