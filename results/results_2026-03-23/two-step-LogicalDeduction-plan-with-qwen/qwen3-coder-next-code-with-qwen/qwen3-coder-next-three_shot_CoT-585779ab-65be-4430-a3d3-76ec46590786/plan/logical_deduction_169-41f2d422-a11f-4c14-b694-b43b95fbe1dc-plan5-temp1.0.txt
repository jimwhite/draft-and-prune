1.  **Initialize the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Create an instance of the `Problem` class.

2.  **Define Variables and Domain:**
    * Define the seven golfers as variables: `"Joe"`, `"Dan"`, `"Ana"`, `"Mel"`, `"Ada"`, `"Eve"`, and `"Amy"`.
    * Define the domain as integers from 1 to 7, where **1 = highest rank (first place)** and **7 = lowest rank (last place)**.
    * Add all variables with domain {1, 2, ..., 7} to the `Problem`.

3.  **Add All-Different Constraint:**
    * Add an `AllDifferentConstraint` to ensure each golfer has a unique rank.

4.  **Translate Statements into Constraints:**
    * "Eve finished above Amy" → Eve's rank is smaller than Amy's (`Eve < Amy`).
    * "Dan finished second" → Dan's rank is exactly 2.
    * "Ada finished below Ana" → Ada's rank is greater than Ana's (`Ana < Ada`).
    * "Ana finished third-to-last" → With 7 participants, third-to-last is position 5 (positions from top: 1st, 2nd, ..., 5th = third-to-last), so Ana's rank is 5.
    * "Mel finished last" → Mel's rank is exactly 7.
    * "Amy finished third" → Amy's rank is exactly 3.

5.  **Solve the Problem:**
    * Call `getSolutions()` to obtain all valid rank assignments.
    * Extract the unique solution.

6.  **Identify Who Finished Second:**
    * Iterate through the solved mapping of golfers to ranks.
    * Find which golfer has rank 2.
    * Map the identified golfer to the corresponding choice letter from the options (A: Joe, B: Dan, C: Ana, D: Mel, E: Ada, F: Eve, G: Amy).
    * Return the correct choice letter.
