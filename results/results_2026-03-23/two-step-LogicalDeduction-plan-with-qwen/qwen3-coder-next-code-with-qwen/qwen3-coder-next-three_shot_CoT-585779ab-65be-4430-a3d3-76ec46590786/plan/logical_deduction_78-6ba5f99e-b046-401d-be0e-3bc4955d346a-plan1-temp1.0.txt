1. **Initialize the Problem Environment:**
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
   * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2. **Define Variables and Domain:**
   * Define the variables as the five birds: `"bluejay"`, `"raven"`, `"crow"`, `"falcon"`, and `"quail"` (using lowercase concatenated names to avoid spaces).
   * Define the domain as integer positions from 1 to 5, where **1 = leftmost** and **5 = rightmost**.
   * Add all variables to the problem with the domain `{1, 2, 3, 4, 5}`.

3. **Add Constraints:**
   * Add an `AllDifferentConstraint()` to enforce that each bird occupies a unique position.
   * Translate each natural language statement into a constraint:
     * "The crow is to the left of the quail" → `crow < quail`
     * "The falcon is the leftmost" → `falcon == 1`
     * "The blue jay is to the right of the quail" → `bluejay > quail`
     * "The raven is the second from the left" → `raven == 2`

4. **Solve the Problem:**
   * Call `getSolutions()` to obtain all valid assignments of positions to birds.
   * Extract the sole (or first) solution since the problem is constrained enough for uniqueness.

5. **Determine the Correct Choice:**
   * Identify which bird occupies position 5 (rightmost) using the solved solution.
   * Create a mapping from choice letters to birds:
     - `"A"` → `"bluejay"`
     - `"B"` → `"raven"`
     - `"C"` → `"crow"`
     - `"D"` → `"falcon"`
     - `"E"` → `"quail"`
   * Find the choice letter corresponding to the bird at position 5.
   * Output (or store) that letter as the answer.
