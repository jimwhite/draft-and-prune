1. **Set Up the Problem Environment:**  
   * Import `Problem` and `AllDifferentConstraint` from the `constraint` library.  
   * Instantiate a `Problem` object to hold the CSP.

2. **Define Variables and Domain:**  
   * Define the seven birds as string variables: `"quail"`, `"raven"`, `"hummingbird"`, `"robin"`, `"falcon"`, `"owl"`, `"bluejay"` (note: concatenate "blue jay" into `"bluejay"` to avoid space in variable name).  
   * Define the domain as integers from 1 to 7, where **1 = leftmost**, **7 = rightmost**.  
   * Add all seven variables with domain `{1,2,3,4,5,6,7}` to the problem.

3. **Add Constraints from Statements:**  
   * Add `AllDifferentConstraint()` to enforce uniqueness of positions.  
   * Translate each statement:  
     - *"The blue jay is to the left of the falcon."* → `bluejay < falcon`  
     - *"The blue jay is the second from the right."* → `bluejay == 6` (since position 7 is rightmost, 6 is second from right)  
     - *"The raven is to the left of the robin."* → `raven < robin`  
     - *"The owl is the third from the right."* → `owl == 5` (positions: 7=rightmost, 6=second right, so 5=third right)  
     - *"The hummingbird is to the left of the quail."* → `hummingbird < quail`  
     - *"The raven is the third from the left."* → `raven == 3`

4. **Solve the Constraint Satisfaction Problem:**  
   * Call `getSolutions()` to retrieve all valid assignments.  
   * Extract the unique solution (a dictionary mapping bird names to positions).

5. **Determine Which Statement is True:**  
   * The question asks: *"Which bird is the fourth from the left?"* → i.e., which bird has position **4**.  
   * Create a mapping: `"A" → "quail"`, `"B" → "raven"`, `"C" → "hummingbird"`, `"D" → "robin"`, `"E" → "falcon"`, `"F" → "owl"`, `"G" → "bluejay"`.  
   * Iterate through the solution dictionary to find which bird has value `4`.  
   * Return the corresponding letter (A–G) as the answer.
