1. **Initialize the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2. **Define Variables and Domain:**  
   * The variables are the seven books: `"brown"`, `"yellow"`, `"black"`, `"white"`, `"green"`, `"orange"`, and `"purple"`.  
   * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.  
   * Add all variables with domain `{1, 2, 3, 4, 5, 6, 7}` to the `Problem` instance.

3. **Formulate and Add Constraints:**  
   * Add an `AllDifferentConstraint` to enforce uniqueness of positions.  
   * Translate each statement into a constraint:  
     - "The purple book is the rightmost" → `purple == 7`  
     - "The yellow book is the leftmost" → `yellow == 1`  
     - "The orange book is the second from the right" → `orange == 6`  
     - "The brown book is to the left of the green book" → `brown < green`  
     - "The brown book is to the right of the black book" → `black < brown`  
     - "The white book is the fourth from the left" → `white == 4`  

4. **Solve for the Unique Arrangement:**  
   * Call `getSolutions()` to obtain all valid assignments. Given the constraints, there will be exactly one solution.  
   * Extract the single solution dictionary from the list of solutions.

5. **Determine Which Statement Is True:**  
   * The question asks which book is third from the left (i.e., position 3).  
   * Create a mapping from choice letters to book names:  
     `'A' -> "brown"`, `'B' -> "yellow"`, `'C' -> "black"`, `'D' -> "white"`, `'E' -> "green"`, `'F' -> "orange"`, `'G' -> "purple"`  
   * In the solved solution, find the book with position value 3.  
   * Return (or record) the letter corresponding to that book as the correct answer.
