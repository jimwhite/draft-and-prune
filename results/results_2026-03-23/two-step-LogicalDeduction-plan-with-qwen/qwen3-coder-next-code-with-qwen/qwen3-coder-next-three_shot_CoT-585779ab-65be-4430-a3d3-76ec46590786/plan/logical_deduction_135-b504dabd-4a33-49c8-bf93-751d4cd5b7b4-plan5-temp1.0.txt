1.  **Initialize the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.

2.  **Define Variables and Domain:**
    * Define the seven fruits as variables: `"plums"`, `"kiwis"`, `"pears"`, `"mangoes"`, `"apples"`, `"oranges"`, and `"loquats"`.
    * Define the domain as integers from 1 to 7, where **1 represents the least expensive** and **7 represents the most expensive**.
    * Add all seven fruit variables to the problem with domain {1, 2, ..., 7}.

3.  **Add AllDifferent Constraint:**
    * Enforce that all fruits have distinct price ranks using `AllDifferentConstraint`.

4.  **Translate Each Statement into a Constraint:**
    * "The pears are less expensive than the oranges" → `pears < oranges`
    * "The mangoes are less expensive than the kiwis" → `mangoes < kiwis`
    * "The plums are the second-most expensive" → `plums == 6` (since 7 is most expensive)
    * "The loquats are more expensive than the apples" → `loquats > apples`
    * "The kiwis are less expensive than the apples" → `kiwis < apples`
    * "The loquats are the fourth-most expensive" → `loquats == 4`

5.  **Solve the Problem:**
    * Use `getSolutions()` to find all valid assignments.
    * Since the problem is constrained enough, expect a unique solution; retrieve the first (and only) solution.

6.  **Identify the Most Expensive Fruit:**
    * The question asks which fruit is the most expensive, i.e., has rank **7**.
    * Create a mapping from choice letters ("A" to "G") to the corresponding fruit names in the order listed:  
        `{"A": "plums", "B": "kiwis", "C": "pears", "D": "mangoes", "E": "apples", "F": "oranges", "G": "loquats"}`
    * Iterate through the choices; for each choice letter, check if the fruit in the solution has value 7.
