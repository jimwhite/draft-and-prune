1. **Set Up the Problem Environment:**

2. **Define Variables and Domain:**  
   * Define the seven fruit variables: `"loquats"`, `"peaches"`, `"watermelons"`, `"plums"`, `"kiwis"`, `"mangoes"`, and `"pears"`.  
   * Define the domain as integers from 1 to 7, where **1 = cheapest** and **7 = most expensive**.  
   * Add all variables to the problem with this domain.

3. **Translate Statements into Constraints:**  
   * Add an `AllDifferentConstraint` to ensure each fruit has a unique price rank.  
   * Convert each statement into a lambda-based constraint:  
     - "The pears are more expensive than the kiwis" → `kiwis < pears`  
     - "The watermelons are less expensive than the peaches" → `watermelons < peaches`  
     - "The mangoes are the third-cheapest" → `mangoes == 3`  
     - "The watermelons are the third-most expensive" → Since there are 7 items, third-most expensive = rank 5 (because most=7, second=6, third=5), so `watermelons == 5`  
     - "The plums are the second-most expensive" → `plums == 6`  
     - "The loquats are the second-cheapest" → `loquats == 2`

4. **Solve the Problem:**  
   * Call `getSolutions()` to obtain all valid assignments.  
   * Extract the unique solution (since the problem is fully constrained, there should be exactly one).

5. **Determine the Most Expensive Fruit:**

   * Build a mapping from choice letters to fruit names based on the options:  
     A → "loquats", B → "peaches", C → "watermelons", D → "plums", E → "kiwis", F → "mangoes", G → "pears"
