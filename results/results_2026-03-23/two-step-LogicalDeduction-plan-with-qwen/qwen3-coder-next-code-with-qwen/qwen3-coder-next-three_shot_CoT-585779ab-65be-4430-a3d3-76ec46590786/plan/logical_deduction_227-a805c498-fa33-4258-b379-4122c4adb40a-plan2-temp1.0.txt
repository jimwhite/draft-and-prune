1. **Initialize the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Instantiate a `Problem` object to model the constraint satisfaction problem.

2. **Define Variables and Domain:**  
   * List the seven books as string variables: `"green"`, `"brown"`, `"white"`, `"black"`, `"orange"`, `"purple"`, and `"yellow"`.  
   * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.  
   * Add all variables with domain `{1, 2, 3, 4, 5, 6, 7}` to the `Problem` instance.

3. **Add AllDifferent Constraint:**  
   * Enforce that all books occupy distinct positions using `AllDifferentConstraint`.

4. **Translate Each Rule into Constraints:**  
   * "The purple book is to the left of the yellow book" → `purple < yellow`.  
   * "The green book is to the left of the white book" → `green < white`.  
   * "The brown book is to the right of the yellow book" → `yellow < brown`.  
   * "The white book is the fourth from the left" → `white == 4`.  
   * "The green book is to the right of the orange book" → `orange < green`.  
   * "The black book is the second from the left" → `black == 2`.

5. **Solve the Constraint Satisfaction Problem:**  
   * Call `getSolutions()` to find all valid assignments.  
   * Extract the unique solution (since the problem is deterministic and consistent).

6. **Determine the "third from the right" Position:**  
   * Note: In a 7-position sequence, "third from the right" corresponds to position `7 - 2 = 5` (since positions: left→right = 1,2,3,4,5,6,7; rightmost=7, second-right=6, third-right=5).

7. **Match the Solution to the Choices:**  
   * For each choice letter in `['A','B','C','D','E','F','G']`, map to its corresponding book:  
     - A → "green", B → "brown", C → "white", D → "black", E → "orange", F → "purple", G → "yellow".  
   * In the solved assignment, find which book has position `5`.  
   * Return the letter of the choice whose associated book is in position 5.
