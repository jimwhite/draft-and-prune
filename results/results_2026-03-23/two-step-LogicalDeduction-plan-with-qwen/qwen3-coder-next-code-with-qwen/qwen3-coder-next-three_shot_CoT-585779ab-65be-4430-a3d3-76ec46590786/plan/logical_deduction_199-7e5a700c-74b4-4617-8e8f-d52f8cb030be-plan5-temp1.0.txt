1. **Set Up the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Create an instance of the `Problem` class.

2. **Define Variables and Domain:**  
   * Define the variables as the seven books: `"red"`, `"purple"`, `"green"`, `"white"`, `"orange"`, `"blue"`, `"gray"`.  
   * Define the domain for positions as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.  
   * Add all variables with this domain to the `Problem` instance.

3. **Formulate and Add Constraints:**  
   * Add an `AllDifferentConstraint` to ensure all books occupy distinct positions.  
   * Add the following constraints using `lambda` functions:  
     - `"The green book is to the left of the white book"` → `green < white`  
     - `"The red book is to the left of the purple book"` → `red < purple`  
     - `"The red book is to the right of the orange book"` → `orange < red`  
     - `"The gray book is the second from the left"` → `gray == 2`  
     - `"The purple book is to the left of the green book"` → `purple < green`  
     - `"The blue book is the fourth from the left"` → `blue == 4`  

4. **Solve for Valid Arrangements:**  
   * Use `getSolutions()` to compute all satisfying assignments.  
   * Extract the (unique) solution from the returned list of solutions.

5. **Identify the Correct Answer:**  
   * The question asks: “Which of the following is true?” referring to which book is **second from the left** (i.e., position 2).  
   * Create a dictionary mapping choice letters `["A", "B", ..., "G"]` to the corresponding book names from the choices.  
   * In the solution, find the book with position value `2`.  
   * Return the choice letter associated with that book.
