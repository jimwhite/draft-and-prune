1.  **Set Up the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Instantiate a `Problem` object to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**  
    * Define the seven books as variables: `"orange"`, `"green"`, `"red"`, `"gray"`, `"purple"`, `"blue"`, `"brown"`.  
    * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost** (i.e., position numbers increase from left to right).  
    * Add all seven book variables with domain `{1, 2, 3, 4, 5, 6, 7}` to the `Problem` instance.

3.  **Formulate and Add Constraints:**  
    * Add an `AllDifferentConstraint` to enforce uniqueness of positions.  
    * Translate each statement into explicit constraints:  
        - "The purple book is the fourth from the left" → `purple == 4`  
        - "The brown book is the third from the left" → `brown == 3`  
        - "The green book is to the left of the blue book" → `green < blue`  
        - "The red book is the leftmost" → `red == 1`  
        - "The gray book is the third from the right" → Since there are 7 books, the third-from-right position is `7 - 3 + 1 = 5` → `gray == 5`  
        - "The orange book is the rightmost" → `orange == 7`

4.  **Solve for All Valid Arrangements:**  
    * Call `getSolutions()` to retrieve all solutions. Due to the constraints, there will be exactly one valid solution.

5.  **Interpret the Question and Match to Choices:**  
    * The question asks which book is the *third from the right*, i.e., position `5` (as established above).  
    * Create a mapping from choice letters to book names: `{'A': 'orange', 'B': 'green', 'C': 'red', 'D': 'gray', 'E': 'purple', 'F': 'blue', 'G': 'brown'}`.  
    * From the solved dictionary, find which book has position `5`.  
    * Return the corresponding choice letter (e.g., if `'gray'` is at position `5`, return `'D'`).
