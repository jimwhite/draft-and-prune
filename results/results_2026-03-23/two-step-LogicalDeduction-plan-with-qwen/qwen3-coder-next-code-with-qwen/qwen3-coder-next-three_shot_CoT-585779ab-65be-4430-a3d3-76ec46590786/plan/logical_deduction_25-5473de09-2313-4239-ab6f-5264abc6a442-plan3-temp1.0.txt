1.  **Set Up the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Instantiate a `Problem` object to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**
    * Define the five books as string variables: `"blue"`, `"purple"`, `"yellow"`, `"black"`, and `"green"`.
    * Define the domain as integer positions from 1 to 5, where 1 = leftmost and 5 = rightmost.
    * Add all variables with their domain to the `Problem` instance.

3.  **Add Constraints Based on Statements:**
    * Add an `AllDifferentConstraint` to ensure each book occupies a unique position.
    * Translate each statement into a constraint:
        * "The purple book is the third from the left" → `purple == 3`
        * "The yellow book is to the left of the black book" → `yellow < black`
        * "The green book is to the left of the purple book" → `green < purple`
        * "The blue book is to the left of the green book" → `blue < green`

4.  **Solve the Constraint Satisfaction Problem:**
    * Call `getSolutions()` to retrieve all valid assignments.
    * Extract the unique solution (since the constraints yield a single arrangement).

5.  **Determine Which Book Is Second from the Right:**
    * The second-from-right position corresponds to index 4 (since rightmost is 5).
    * Create a mapping from choice letters ("A"–"E") to the corresponding book names in the choices.
    * Iterate through the solution dictionary to find which book has position 4.
    * Return the choice letter associated with that book as the correct answer.
