    * Define a domain of integers from 1 to 5, where **1 = oldest** and **5 = newest**.
    * Add all vehicle variables with this domain to the problem.

3.  **Translate Statements into Constraints:**
    * Add an `AllDifferentConstraint` to enforce unique positions for each vehicle.

        * "The tractor is older than the hatchback" → `tractor < hatchback`

        * "The station wagon is the second-newest" → second-newest = position 4 → `station_wagon == 4`

4.  **Solve the Constraint Satisfaction Problem:**
    * Call `getSolutions()` to find all valid assignments.
    * Extract the unique solution (as there is only one consistent arrangement).
