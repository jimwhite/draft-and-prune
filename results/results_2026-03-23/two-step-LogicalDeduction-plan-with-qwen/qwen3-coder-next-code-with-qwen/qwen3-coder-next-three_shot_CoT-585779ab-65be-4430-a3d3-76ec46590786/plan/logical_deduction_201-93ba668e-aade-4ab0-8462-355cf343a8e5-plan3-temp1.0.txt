1.  **Initialize the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Create an instance of the `Problem` class to hold variables and constraints.

2.  **Define Variables and Domain:**
    * List the seven books as string variables: `"purple"`, `"brown"`, `"red"`, `"blue"`, `"gray"`, `"black"`, and `"green"`.
    * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.
    * Add all variables with domain {1,2,3,4,5,6,7} to the `Problem` instance.

3.  **Formulate and Add Constraints:**
    * Add an `AllDifferentConstraint` to ensure each book occupies a unique position.
    * Translate each statement into constraints using `lambda` functions:
        - "The brown book is to the left of the green book" → `brown < green`
        - "The gray book is the second from the left" → `gray == 2`
        - "The black book is to the left of the gray book" → `black < gray`
        - "The blue book is to the left of the red book" → `blue < red`
        - "The blue book is the second from the right" → `blue == 6` (since position 7 is rightmost)
        - "The green book is to the left of the purple book" → `green < purple`

4.  **Solve for All Valid Arrangements:**
    * Use `getSolutions()` to find all solutions satisfying the constraints.
    * Extract the unique solution (or one of them, as there should be exactly one).

5.  **Determine the Fourth Position Book:**
    * Identify which book has position 4 (i.e., fourth from the left) in the solution.
    * Map each choice letter ("A" through "G") to its corresponding book name:
        - A → "purple", B → "brown", C → "red", D → "blue", E → "gray", F → "black", G → "green"
    * Iterate over choices; for each, check if the book at position 4 matches the choice's book.
    * Output the letter of the choice whose book is fourth from the left.
