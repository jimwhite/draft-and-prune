1.  **Initialize the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**  
    * Identify the variables: the three books — `"white"`, `"black"`, and `"purple"`.  
    * Define the domain as integer positions from 1 to 3, where **1 = leftmost**, **2 = middle**, and **3 = rightmost**.  
    * Add each variable with domain {1, 2, 3} to the problem.

3.  **Formulate and Add Constraints:**  
    * Add an `AllDifferentConstraint` to ensure all books occupy distinct positions.  
    * Translate "The black book is to the left of the purple book" into a constraint: `black < purple`.  
    * Translate "The purple book is to the left of the white book" into a constraint: `purple < white`.  
    * These two constraints together imply the strict ordering: black → purple → white.

4.  **Solve for the Arrangement:**  
    * Use `getSolutions()` to find all valid assignments of positions.  
    * Since the constraints enforce a unique total order, there will be exactly one solution.

5.  **Determine the Correct Answer:**  
    * Examine the question: "Which of the following is true?" — specifically, which book is rightmost (position 3).  
    * Build a mapping from choice letters to books: "A" → "white", "B" → "black", "C" → "purple".  
    * Locate the book with position value 3 in the solution.  
    * Return the letter corresponding to that book as the answer.
