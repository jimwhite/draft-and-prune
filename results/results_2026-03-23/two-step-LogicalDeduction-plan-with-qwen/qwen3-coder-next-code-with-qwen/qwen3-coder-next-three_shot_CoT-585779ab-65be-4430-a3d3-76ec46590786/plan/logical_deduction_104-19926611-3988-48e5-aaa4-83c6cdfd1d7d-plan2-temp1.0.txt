1.  **Initialize the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**
    * Define the seven bird variables as strings: `"hawk"`, `"hummingbird"`, `"falcon"`, `"cardinal"`, `"owl"`, `"robin"`, and `"blue jay"`.
    * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.
    * Add all seven variables with domain {1, 2, 3, 4, 5, 6, 7} to the `Problem` instance.

3.  **Add Constraints Based on Statements:**
    * Add an `AllDifferentConstraint` to ensure all birds occupy distinct positions.
    * Translate each statement into a constraint:
        * "The hummingbird is to the left of the owl" → `hummingbird < owl`
        * "The robin is the rightmost" → `robin == 7`
        * "The blue jay is to the left of the hawk" → `blue jay < hawk`
        * "The blue jay is the third from the left" → `blue jay == 3`
        * "The falcon is the fourth from the left" → `falcon == 4`
        * "The cardinal is the second from the right" → `cardinal == 6`

4.  **Solve the Problem:**
    * Call `getSolutions()` to obtain all valid assignments of positions to birds.
    * Extract the unique solution (since the constraints fully determine the arrangement).

5.  **Determine the Leftmost Bird:**
    * Identify the bird assigned position 1 (leftmost) from the solution dictionary.
    * Map this bird to the corresponding choice letter:
        * hawk → A, hummingbird → B, falcon → C, cardinal → D, owl → E, robin → F, blue jay → G.
    * Output the correct choice letter.
