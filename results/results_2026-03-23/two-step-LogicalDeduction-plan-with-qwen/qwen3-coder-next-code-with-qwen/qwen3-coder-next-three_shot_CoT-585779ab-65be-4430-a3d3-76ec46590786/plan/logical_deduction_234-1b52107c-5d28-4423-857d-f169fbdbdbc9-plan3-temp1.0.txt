1. **Initialize the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2. **Define Variables and Domain:**  
   * Identify the seven bird variables: `"cardinal"`, `"crow"`, `"hummingbird"`, `"blue jay"`, `"owl"`, `"robin"`, and `"quail"`.  
   * Define the domain as integers from 1 to 7 (inclusive), where position 1 = leftmost, position 7 = rightmost.  
   * Add all seven variables with domain {1,2,3,4,5,6,7} to the `Problem` instance.

3. **Add Constraints from Statements:**  
   * Add an `AllDifferentConstraint` to enforce uniqueness of positions.  
   * Translate each natural-language statement into constraints:  
     - *"The cardinal is to the right of the crow"* → `crow < cardinal` (i.e., position(crow) < position(cardinal)).  
     - *"The quail is the third from the left"* → `quail == 3`.  
     - *"The owl is to the right of the robin"* → `robin < owl`.  
     - *"The hummingbird is to the right of the blue jay"* → `blue jay < hummingbird`.  
     - *"The cardinal is the second from the left"* → `cardinal == 2`.  
     - *"The owl is the third from the right"* → Since positions go left (1) to right (7), third from the right = position 5 → `owl == 5`.

4. **Solve the Problem:**  
   * Call `getSolutions()` to compute all valid assignments.  
   * Extract the solution (only one should exist due to consistency and uniqueness implied by problem structure).  
   * Optionally verify that all constraints are satisfied in the returned solution.

5. **Evaluate the Choices:**  
   * The question asks: *"Which of the following is true?"* where each choice asserts a specific bird is third from the right.  
   * Recall: third from the right in a 7-position sequence = position `7 - 3 + 1 = 5`. So check which bird is at position 5.  
   * Build a mapping from choice letters (`"A"` to `"G"`) to the corresponding bird names in order:  
     A → `"cardinal"`, B → `"crow"`, C → `"hummingbird"`, D → `"blue jay"`, E → `"owl"`, F → `"robin"`, G → `"quail"`.  
   * From the solution, find which bird has position 5.  
   * Return the letter corresponding to that bird as the answer.
