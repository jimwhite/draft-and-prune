2.  **Define Variables and Domain:**
    * Define the five birds as variables: `"cardinal"`, `"hawk"`, `"hummingbird"`, `"raven"`, and `"owl"`.
    * Define the domain as integers from 1 to 5, where 1 = leftmost and 5 = rightmost.
    * Add these variables with domain {1,2,3,4,5} to the `Problem` instance.

3.  **Add Constraints from the Problem Statement:**
    * Add an `AllDifferentConstraint` to ensure each bird occupies a unique position.
    * Translate the statements into constraints:
        * "The raven is to the left of the hummingbird" → `raven < hummingbird`
        * "The hawk is to the left of the owl" → `hawk < owl`
        * "The cardinal is to the left of the hawk" → `cardinal < hawk`
        * "The raven is the second from the right" → `raven == 4` (since position 5 is rightmost, second from right = 4)

4.  **Solve the Problem:**
    * Call `getSolutions()` to find all valid assignments.
    * Extract the unique solution from the list of solutions.
