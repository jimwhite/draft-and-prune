1. **Initialize the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.

2. **Define Variables and Domain:**  
   * Define the variables as the seven fruits: `"kiwis"`, `"cantaloupes"`, `"oranges"`, `"loquats"`, `"pears"`, `"watermelons"`, and `"peaches"`.  
   * Define the domain as integers from 1 to 7, where **1 represents the least expensive (cheapest)** and **7 represents the most expensive**.  
   * Add all seven variables to the problem with domain {1, 2, ..., 7}.

3. **Add AllDifferent Constraint:**  
   * Enforce that all fruits have distinct price rankings by adding an `AllDifferentConstraint` over the seven variables.

4. **Translate Each Statement into a Constraint Using Lambda Functions:**  
   * "The loquats are less expensive than the peaches" → `loquats < peaches`  
   * "The pears are the third-cheapest" → `pears == 3`  
   * "The oranges are less expensive than the cantaloupes" → `oranges < cantaloupes`  
   * "The loquats are more expensive than the watermelons" → `loquats > watermelons`  
   * "The peaches are less expensive than the oranges" → `peaches < oranges`  
   * "The kiwis are the second-most expensive" → `kiwis == 6` (since 7 is most expensive)

5. **Solve the Problem:**  
   * Call `getSolutions()` to find all valid assignments.  
   * Extract the unique solution (as the problem is constrained enough to yield a single arrangement).

   * Create a mapping from choice letters to fruit names:
