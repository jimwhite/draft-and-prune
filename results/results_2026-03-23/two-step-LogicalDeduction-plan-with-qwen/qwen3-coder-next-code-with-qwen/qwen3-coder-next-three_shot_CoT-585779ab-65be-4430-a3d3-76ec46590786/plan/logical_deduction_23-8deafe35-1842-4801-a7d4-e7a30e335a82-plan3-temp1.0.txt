1. **Set Up the Problem Environment:**
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
   * Instantiate a `Problem` object to model the constraint satisfaction problem.

2. **Define Variables and Domain:**
   * Define the variables as the five books: `"green"`, `"blue"`, `"white"`, `"purple"`, and `"yellow"`.
   * Define the domain for positions as integers from 1 to 5, where **1 = leftmost** and **5 = rightmost**.
   * Add all five variables to the problem with their domain using `addVariable()`.

3. **Formulate and Add Constraints:**
   * Add an `AllDifferentConstraint` to ensure all books occupy distinct positions.
   * Translate each statement into a constraint:
     - "The blue book is to the right of the yellow book" → `blue > yellow`
     - "The white book is to the left of the yellow book" → `white < yellow`
     - "The blue book is the second from the right" → `blue == 4` (since position 5 is rightmost, 4 is second from right)
     - "The purple book is the second from the left" → `purple == 2`

4. **Solve for Valid Arrangement:**
   * Use `getSolutions()` to find all solutions that satisfy the constraints.
   * Extract the single (or primary) solution since the problem is well-defined and consistent.

5. **Determine the Leftmost Book:**
   * Identify which book has position 1 (leftmost) in the solution.
   * Map the five answer choices to their respective books:
     - A → "green"
     - B → "blue"
     - C → "white"
     - D → "purple"
     - E → "yellow"
   * Check which choice corresponds to the book found at position 1.
   * Output the corresponding letter (A–E) as the answer.
