2. **Define Variables and Domain:**  
   * Define the seven books as variables: `"black"`, `"yellow"`, `"white"`, `"gray"`, `"purple"`, `"orange"`, and `"green"`.  
   * Define the domain as integers from 1 to 7 (inclusive), where **1 = leftmost** and **7 = rightmost** position.  
   * Add all seven variables to the problem with this domain.

3. **Formulate and Add Constraints:**  
   * Add an `AllDifferentConstraint` to enforce that each book occupies a unique position.  
   * Translate each textual statement into a constraint using `lambda` functions or direct value assignments:  
        - "The green book is to the left of the gray book" → `green < gray`  
        - "The gray book is the third from the right" → in a 1-to-7 left-right scale, third from the right is position **5** (since 7−3+1=5), so `gray == 5`  
        - "The white book is the rightmost" → `white == 7`  
        - "The orange book is the second from the left" → `orange == 2`  
        - "The black book is to the right of the yellow book" → `yellow < black`  
        - "The black book is the third from the left" → `black == 3`  

4. **Solve for Valid Arrangements:**  
   * Use `getSolutions()` to find all satisfying assignments. Given the problem's constraints, exactly one solution will exist.  
   * Extract the unique solution dictionary.

5. **Determine the Fourth-from-Left Book:**

   * Iterate through the solution dictionary's key-value pairs to identify which book has value `4`.
