1.  **Set Up the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.

2.  **Define Variables and Domain for Seven Objects:**
    * Define the seven bird variables as strings: `"cardinal"`, `"crow"`, `"hummingbird"`, `"bluejay"`, `"owl"`, `"robin"`, and `"quail"`.
    * Define the domain as integers from 1 to 7 (inclusive), where position 1 = leftmost and position 7 = rightmost.
    * Add all variables with domain {1, 2, 3, 4, 5, 6, 7} to the problem.

3.  **Add All-Different Constraint:**
    * Enforce that each bird occupies a unique position using `AllDifferentConstraint`.

4.  **Translate Each Statement into Explicit Constraints:**
    * "The cardinal is to the right of the crow" → `cardinal > crow`
    * "The quail is the third from the left" → `quail == 3`
    * "The owl is to the right of the robin" → `owl > robin`
    * "The hummingbird is to the right of the blue jay" → `hummingbird > bluejay`
    * "The cardinal is the second from the left" → `cardinal == 2`
    * "The owl is the third from the right" → Since positions are 1 (leftmost) to 7 (rightmost), third from the right is position `7 - 3 + 1 = 5` → `owl == 5`

5.  **Solve the Constraint Satisfaction Problem:**
    * Call `getSolutions()` to find all valid assignments.
    * Extract the first (and only) solution from the resulting list.

6.  **Interpret the Question and Choices:**
    * The question asks which bird is third from the right → position 5 (as computed above).
    * Check which bird in the solution has position 5.
    * Map choice letters to birds:
        - A: cardinal
        - B: crow
        - C: hummingbird
        - D: bluejay
        - E: owl
        - F: robin
        - G: quail

7.  **Determine the Correct Answer:**
