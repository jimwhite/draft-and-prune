1.  **Initialize the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**  
    * Identify the five books as variables: `"brown"`, `"orange"`, `"red"`, `"purple"`, and `"black"`.  
    * Define the domain as integers 1 through 5, where **1 = leftmost position** and **5 = rightmost position**.  
    * Add all variables to the problem with this domain.

3.  **Add Constraints from Statements:**  
    * Add an `AllDifferentConstraint` to ensure all books occupy distinct positions.  
    * Translate each statement into a constraint:  
        * "The purple book is to the left of the black book" → `purple < black`  
        * "The red book is to the right of the brown book" → `brown < red`  
        * "The orange book is the second from the left" → `orange == 2`  
        * "The black book is the third from the left" → `black == 3`

4.  **Solve the Problem:**  
    * Call `getSolutions()` to find all valid assignments.  
    * Extract the unique solution (since constraints are consistent and sufficient).

5.  **Determine Which Book Is Second from the Right:**  
    * In our system, second from the right corresponds to position 4.  
    * Create a mapping from choice letters ('A'–'E') to book names:  
        A → 'brown', B → 'orange', C → 'red', D → 'purple', E → 'black'  
    * For each choice, check if the corresponding book's position in the solution equals 4.  
    * Return the letter of the first (and only) choice satisfying this condition as the answer.
