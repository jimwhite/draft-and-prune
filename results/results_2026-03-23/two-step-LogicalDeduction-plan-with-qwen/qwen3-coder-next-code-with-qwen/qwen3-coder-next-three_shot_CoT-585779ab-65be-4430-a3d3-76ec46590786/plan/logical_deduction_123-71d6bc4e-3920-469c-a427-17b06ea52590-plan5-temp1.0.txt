    * Define the seven book variables: `"brown"`, `"white"`, `"black"`, `"yellow"`, `"orange"`, `"blue"`, and `"green"`.
    * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.
    * Add all seven variables to the problem with the domain {1, 2, 3, 4, 5, 6, 7}.

3.  **Add All-Different Constraint:**
    * Add an `AllDifferentConstraint` to ensure each book occupies a unique position.

4.  **Translate Each Statement into Explicit Constraints:**
    * "The yellow book is the rightmost" → `yellow == 7`.
    * "The blue book is to the left of the orange book" → `blue < orange`.
    * "The green book is to the right of the white book" → `white < green`.
    * "The blue book is to the right of the green book" → `green < blue`.
    * "The black book is the fourth from the left" → `black == 4`.
    * "The brown book is the third from the right" → In a 7-position row, third from the right means position `7 - 3 + 1 = 5`, so `brown == 5`.

5.  **Solve the Constraint Satisfaction Problem:**
    * Call `getSolutions()` to find all valid assignments of positions to books.
    * Since the problem is deterministic and consistent, expect exactly one solution; retrieve it (e.g., `solutions[0]`).

    * Find the key (book name) whose value equals 1.
