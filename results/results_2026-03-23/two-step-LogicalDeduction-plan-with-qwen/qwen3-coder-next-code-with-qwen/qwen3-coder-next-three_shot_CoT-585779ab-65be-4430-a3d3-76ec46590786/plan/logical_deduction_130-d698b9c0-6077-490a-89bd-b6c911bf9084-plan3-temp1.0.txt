1.  **Initialize the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2.  **Define Variables and Their Domain:**
    * Define the seven variables as strings representing the fruits: `"watermelons"`, `"cantaloupes"`, `"pears"`, `"peaches"`, `"mangoes"`, `"kiwis"`, and `"oranges"`.
    * Define a domain of integers from 1 to 7, where **1 represents the cheapest** and **7 represents the most expensive**, to match standard ranking conventions for "more/less expensive".
    * Add all seven fruit variables with domain {1,2,3,4,5,6,7} to the problem.

3.  **Add All Different Constraint:**
    * Enforce that each fruit has a unique price rank by adding an `AllDifferentConstraint`.

4.  **Translate Each Statement into a Constraint:**
    * "The oranges are more expensive than the cantaloupes" → `oranges > cantaloupes`
    * "The pears are less expensive than the kiwis" → `pears < kiwis`
    * "The kiwis are the fourth-most expensive" → `kiwis == 4` (since 4th-most-expensive means rank 4 in ascending price ranking where 1=cheapest, 7=most expensive)
    * "The mangoes are less expensive than the pears" → `mangoes < pears`
    * "The peaches are the cheapest" → `peaches == 1`
    * "The cantaloupes are more expensive than the watermelons" → `cantaloupes > watermelons`

5.  **Solve the Constraint Satisfaction Problem:**
    * Call `getSolutions()` to find all assignments of ranks satisfying the constraints.
    * Extract the unique solution (the problem is designed to have a single consistent arrangement).

6.  **Identify the Most Expensive Fruit:**
    * The most expensive fruit corresponds to rank 7.
    * Create a mapping from choice letters to fruit names: `{'A': 'watermelons', 'B': 'cantaloupes', 'C': 'pears', 'D': 'peaches', 'E': 'mangoes', 'F': 'kiwis', 'G': 'oranges'}`.
    * For each choice, check if the fruit's assigned rank in the solution equals 7.
    * Return the letter of the first (and only) choice where this holds true.
