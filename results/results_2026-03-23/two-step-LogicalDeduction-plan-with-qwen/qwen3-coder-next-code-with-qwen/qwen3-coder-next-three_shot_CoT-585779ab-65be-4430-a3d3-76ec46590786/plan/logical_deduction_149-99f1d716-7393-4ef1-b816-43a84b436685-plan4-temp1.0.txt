1.  **Initialize the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Create an instance of the `Problem` class to define the constraint satisfaction problem.

2.  **Define Variables and Domain:**  
    * The variables are the seven golfers: `"Joe"`, `"Mel"`, `"Mya"`, `"Eve"`, `"Rob"`, `"Ada"`, and `"Dan"`.  
    * Define the domain as integers from 1 to 7, where **1 = first place (highest rank)** and **7 = last place (lowest rank)**.  
    * Add all variables with this domain to the `Problem` instance.

3.  **Formulate and Add Constraints:**  
    * Add an `AllDifferentConstraint` to ensure all golfers have distinct finishing positions.  
    * Translate each statement into a constraint using lambda functions:  
        - "Rob finished first" → Rob's position = 1.  
        - "Eve finished last" → Eve's position = 7.  
        - "Joe finished second-to-last" → Joe's position = 6 (since last is 7).  
        - "Mya finished third" → Mya's position = 3.  
        - "Dan finished above Ada" → Dan’s position number < Ada’s position number (since lower numbers mean earlier/faster finish).  
        - "Mel finished above Mya" → Mel’s position number < Mya’s position number (i.e., Mel < 3).

4.  **Solve for the Arrangement:**  
    * Call `getSolutions()` to find all valid solutions. Given the constraints, there should be a unique assignment (though we handle cases with multiple solutions by checking all).  
    * Extract the solution(s) and proceed.

5.  **Determine Third-to-Last Position and Match to Choices:**  
    * Compute the position number corresponding to "third-to-last" in a 7-person race:  
        - Last = 7 → second-to-last = 6 → third-to-last = **5**.  
    * For each solution, identify the golfer whose position is 5.  
    * Create a mapping from choice letters (A–G) to golfer names:  
        A → "Joe", B → "Mel", C → "Mya", D → "Eve", E → "Rob", F → "Ada", G → "Dan".  
    * For each solution, find which golfer is at position 5 and output the corresponding choice letter.  
    * Since constraints are consistent and likely yield a unique solution, the correct choice will be deterministic.
