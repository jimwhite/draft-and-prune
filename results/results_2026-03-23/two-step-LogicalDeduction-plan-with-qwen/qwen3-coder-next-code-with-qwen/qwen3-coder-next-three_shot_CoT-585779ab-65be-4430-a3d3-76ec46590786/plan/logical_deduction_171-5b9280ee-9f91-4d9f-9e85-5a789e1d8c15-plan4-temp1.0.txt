1.  **Set Up the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Instantiate the `Problem` class to hold variables and constraints for the seven golfers.

2.  **Define Variables and Domain:**
    * Create a list of strings for the seven golfers: `"Ana"`, `"Eli"`, `"Mya"`, `"Amy"`, `"Joe"`, `"Mel"`, and `"Ada"`. These are the variables.
    * Define a numerical domain from 1 to 7, where **1 represents the highest finish (top position)** and **7 represents the lowest finish (last position)**.
    * Add all seven golfer variables with domain {1, 2, 3, 4, 5, 6, 7} to the problem.

3.  **Formulate and Add Constraints:**
    * Add an `AllDifferentConstraint` to ensure each golfer has a unique finishing position.
    * Translate each statement into a constraint using lambda functions:
        * "Ada finished above Mel" → Ada's position < Mel's position (`lambda a, m: a < m` with arguments ("Ada", "Mel")).
        * "Ada finished third-to-last" → Ada's position = 5 (since positions: 1=1st, ..., 5=3rd-from-last in a 7-person field: 5th, 6th, 7th are last three; 5 = 7 − 3 + 1).
        * "Amy finished above Ana" → Amy's position < Ana's position (`lambda a, n: a < n` with ("Amy", "Ana")).
        * "Mya finished second-to-last" → Mya's position = 6 (positions: 6th in a 7-person field).
        * "Joe finished above Amy" → Joe's position < Amy's position (`lambda j, y: j < y` with ("Joe", "Amy")).
        * "Eli finished below Ana" → Eli's position > Ana's position (`lambda l, n: l > n` with ("Eli", "Ana")).

4.  **Solve the Problem:**
    * Call `getSolutions()` to find all valid assignments.
    * Extract the unique solution (should be exactly one) from the list of solutions.

5.  **Identify the Correct Answer:**
    * The question asks who finished third, i.e., which golfer has position = 3.
    * Create a dictionary mapping choice letters ("A" to "G") to the corresponding golfer names: "A" → "Ana", "B" → "Eli", ..., "G" → "Ada".
    * Iterate through the solution dictionary to find which golfer has value 3.
    * Return the choice letter associated with that golfer as the final answer.
