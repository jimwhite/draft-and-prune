2.  **Define Variables and Domain:**
    * Define the variables as the seven books: `"orange"`, `"red"`, `"brown"`, `"blue"`, `"black"`, `"gray"`, and `"white"`.
    * Define the domain as integer positions from 1 to 7, where **1 = leftmost** and **7 = rightmost**, in strict left-to-right order.
    * Add all variables to the problem with this domain.

3.  **Formulate and Add Constraints:**
    * Add an `AllDifferentConstraint` to ensure each book occupies a unique position.
    * Translate each statement into a constraint:
        * "The white book is the leftmost" → `white == 1`
        * "The red book is to the right of the blue book" → `blue < red`
        * "The orange book is the second from the right" → `orange == 6` (since position 7 is rightmost)
        * "The gray book is the fourth from the left" → `gray == 4`
        * "The black book is the rightmost" → `black == 7`
        * "The gray book is to the right of the red book" → `red < gray`

4.  **Solve for All Valid Arrangements:**
    * Use `getSolutions()` to find all possible assignments satisfying the constraints.
    * Given consistency, extract the unique solution (or any one, since uniqueness is guaranteed by problem statement).

5.  **Identify the Correct Answer:**
