1. **Set Up the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Instantiate a `Problem` object to model the constraint satisfaction problem.

2. **Define Variables and Domain:**  
   * Define the seven books as variables: `"orange"`, `"red"`, `"green"`, `"white"`, `"purple"`, `"brown"`, `"yellow"`.  
   * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**.  
   * Add all seven book variables to the problem with this domain.

3. **Add All-Different Constraint:**  
   * Add an `AllDifferentConstraint` to enforce that each book occupies a unique position.

4. **Translate Each Statement into Positional Constraints Using Lambda Functions:**  
   * "The green book is to the left of the purple book" → `green < purple`  
   * "The white book is to the right of the orange book" → `orange < white`  
   * "The green book is to the right of the brown book" → `brown < green`  
   * "The yellow book is to the right of the white book" → `white < yellow`  
   * "The red book is to the right of the yellow book" → `yellow < red`  
   * "The brown book is to the right of the red book" → `red < brown`  

5. **Solve the Constraint Satisfaction Problem:**  
   * Call `getSolutions()` to find all valid assignments of positions.  
   * Extract the unique solution (since the constraints fully determine a single ordering).

6. **Identify the Book in Position 2 (Second from Left):**  
   * In the solution dictionary, locate the key (book name) whose value is 2.  
   * Map this book to the corresponding choice letter:  
        - A) orange → "A"  
        - B) red → "B"  
        - C) green → "C"  
        - D) white → "D"
