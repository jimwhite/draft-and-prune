1. **Set Up the Problem Environment:**
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
   * Instantiate a `Problem` object to represent the constraint satisfaction problem.

2. **Define Variables and Domain:**
   * Identify the seven books as variables: `"green"`, `"brown"`, `"white"`, `"black"`, `"orange"`, `"purple"`, `"yellow"`.
   * Define the domain as integers from 1 to 7, where position 1 = leftmost and position 7 = rightmost.
   * Add all seven variables to the problem with domain `{1,2,3,4,5,6,7}`.

3. **Add All-Different Constraint:**
   * Enforce that all books occupy distinct positions using `AllDifferentConstraint`.

4. **Translate Each Statement into a Constraint:**
   * "The purple book is to the left of the yellow book" → `purple < yellow`
   * "The green book is to the left of the white book" → `green < white`
   * "The brown book is to the right of the yellow book" → `yellow < brown`
   * "The white book is the fourth from the left" → `white == 4`
   * "The green book is to the right of the orange book" → `orange < green`
   * "The black book is the second from the left" → `black == 2`

5. **Solve the Constraint Satisfaction Problem:**
   * Call `getSolutions()` to compute all valid assignments.
   * Extract the unique solution (since the problem is well-constrained and consistent).

6. **Interpret the Question:**
   * "Third from the right" in a 7-book shelf corresponds to position `7 - 3 + 1 = 5`.
   * Therefore, identify which book has position value **5** in the solution.

7. **Map Choice Letters to Books:**
   * Create a dictionary mapping each choice letter (`'A'` through `'G'`) to its respective book:
     - `'A'`: `"green"`
     - `'B'`: `"brown"`
     - `'C'`: `"white"`
     - `'D'`: `"black"`
     - `'E'`: `"orange"`
     - `'F'`: `"purple"`
     - `'G'`: `"yellow"`

8. **Find the Correct Answer:**
   * Iterate over the choice-letter-to-book mapping.
   * For each book, check if its position in the solution equals **5**.
   * Return (or print) the choice letter corresponding to that book.
