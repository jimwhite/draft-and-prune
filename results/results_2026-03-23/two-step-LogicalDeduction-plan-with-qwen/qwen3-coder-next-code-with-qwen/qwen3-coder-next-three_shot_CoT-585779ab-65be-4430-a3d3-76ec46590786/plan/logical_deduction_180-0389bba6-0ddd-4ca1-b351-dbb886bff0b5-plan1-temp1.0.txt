1.  **Initialize the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**  
    * Identify the seven books as variables: `"black"`, `"orange"`, `"yellow"`, `"white"`, `"blue"`, `"red"`, and `"green"`.  
    * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**, to represent positions on the shelf.  
    * Add all seven variables with domain {1, 2, 3, 4, 5, 6, 7} to the problem.

3.  **Formulate and Add Constraints:**  
    * Add an `AllDifferentConstraint` to enforce uniqueness of positions.  
    * Convert each statement into a constraint:  
        - "The red book is to the right of the yellow book" → `red > yellow`  
        - "The white book is the second from the right" → `white == 6`  
        - "The red book is to the left of the green book" → `red < green`  
        - "The blue book is to the right of the black book" → `blue > black`  
        - "The black book is the third from the right" → `black == 5`  
        - "The orange book is the leftmost" → `orange == 1`

4.  **Solve the Constraint Satisfaction Problem:**  
    * Use `getSolutions()` to find all valid assignments of positions to books satisfying all constraints.  
    * Extract the unique solution (since the problem is fully constrained, there should be exactly one).

5.  **Determine Which Choice Is True:**  
    * The question asks which book is the third from the right. In our 1–7 system, that corresponds to position **5** (since rightmost is 7 → second from right = 6, third from right = 5).  
    * Create a mapping from choice letters to book names: `{'A': 'black', 'B': 'orange', 'C': 'yellow', 'D': 'white', 'E': 'blue', 'F': 'red', 'G': 'green'}`.  
    * Iterate through the choices, check which book in the solution has position 5, and return its corresponding choice letter.
