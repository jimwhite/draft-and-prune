1.  **Initialize the Problem Environment:**  
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
    * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2.  **Define Variables and Their Domain:**  
    * Define the seven fruits as string variables: `"mangoes"`, `"kiwis"`, `"oranges"`, `"watermelons"`, `"apples"`, `"pears"`, and `"loquats"`.  
    * Define a domain of integers from 1 to 7, where **1 represents the cheapest** and **7 represents the most expensive** fruit.  
    * Add all variables with domain {1,2,3,4,5,6,7} to the `Problem` instance.

3.  **Translate Statements into Formal Constraints:**  
    * Add an `AllDifferentConstraint` to enforce uniqueness of price ranks.  
    * Add the following constraints using lambda functions:  
        - `"The loquats are less expensive than the oranges"` → `loquats < oranges`  
        - `"The oranges are the third-most expensive"` → `oranges == 5` (since most expensive = rank 7, third-most expensive = 7 - 3 + 1 = 5)  
        - `"The apples are the cheapest"` → `apples == 1`  
        - `"The kiwis are more expensive than the pears"` → `kiwis > pears`  
        - `"The mangoes are more expensive than the watermelons"` → `mangoes > watermelons`  
        - `"The loquats are more expensive than the kiwis"` → `loquats > kiwis`  

4.  **Solve the Problem:**  
    * Use `getSolutions()` to compute all valid assignments of ranks to fruits satisfying all constraints.  
    * Extract the unique solution (since the problem is well-constrained and consistent).

5.  **Determine the Fourth-Most Expensive Fruit:**  
    * The fourth-most expensive fruit corresponds to rank = 7 - 4 + 1 = **4**.  
    * Create a dictionary mapping choice letters ("A" to "G") to the corresponding fruit names:  
        `"A": "mangoes"`, `"B": "kiwis"`, `"C": "oranges"`, `"D": "watermelons"`, `"E": "apples"`, `"F": "pears"`, `"G": "loquats"`  
    * Iterate over the solution dictionary, find which fruit has rank **4**, and identify its letter from the mapping.  
    * Output that choice letter as the answer.
