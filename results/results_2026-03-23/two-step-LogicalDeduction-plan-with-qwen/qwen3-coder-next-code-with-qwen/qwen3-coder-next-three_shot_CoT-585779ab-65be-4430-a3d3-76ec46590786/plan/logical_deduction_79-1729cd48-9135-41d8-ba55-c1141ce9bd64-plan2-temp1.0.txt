1. **Initialize the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.

2. **Define Variables and Domain:**  
   * Identify the five birds as variables: `"cardinal"`, `"hawk"`, `"hummingbird"`, `"raven"`, and `"owl"`.  
   * Define the domain as integers 1 through 5, where **1 = leftmost** and **5 = rightmost**.  
   * Add all variables to the problem with this domain using `addVariable()`.

3. **Formulate and Add Constraints:**  
   * Add an `AllDifferentConstraint` to ensure each bird occupies a unique position.  
   * Translate each statement into a constraint using `addConstraint()` with lambda functions:  
     - "The raven is to the left of the hummingbird" → `lambda r, h: r < h`  
     - "The hawk is to the left of the owl" → `lambda h, o: h < o`  
     - "The cardinal is to the left of the hawk" → `lambda c, h: c < h`  
     - "The raven is the second from the right" → `raven == 4` (since position 5 is rightmost, second from right is 4).

4. **Solve the Problem:**  
   * Call `getSolutions()` to find all valid assignments.  
   * Extract the unique solution (a dictionary mapping birds to positions) from the list of solutions.

5. **Determine the Correct Answer:**  
   * The question asks which bird is the **second from the left**, i.e., position 2.  
   * Create a mapping from choice letters to bird names: `'A'→'cardinal'`, `'B'→'hawk'`, `'C'→'hummingbird'`, `'D'→'raven'`, `'E'→'owl'`.  
   * Iterate over choices; for each choice letter, check if the corresponding bird's position in the solution equals 2.  
   * Return (or record) the first matching choice letter as the answer.
