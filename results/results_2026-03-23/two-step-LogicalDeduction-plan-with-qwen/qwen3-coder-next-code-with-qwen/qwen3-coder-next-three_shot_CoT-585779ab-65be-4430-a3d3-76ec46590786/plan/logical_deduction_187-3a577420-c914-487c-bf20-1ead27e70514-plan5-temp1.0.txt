   * Define the domain as integers 1 through 7, where **1 = highest position (first place)** and **7 = lowest position (last place)**.  
   * Add all seven variables with this domain to the `Problem` instance.

3. **Formulate and Add Constraints:**  
   * Add an `AllDifferentConstraint` to ensure each golfer occupies a unique finishing position.  
   * Translate each statement into constraints using `lambda` functions:  
     - "Mya finished above Eli" → Mya’s position number is *less than* Eli’s (`mya < eli`).  
     - "Eve finished below Rob" → Eve’s position number is *greater than* Rob’s (`eve > rob`).  
     - "Amy finished second" → Amy’s position is exactly 2.  
     - "Rob finished below Dan" → Rob’s position number is *greater than* Dan’s (`rob > dan`).  
     - "Ana finished second-to-last" → Ana’s position is exactly 6 (since last is 7 in a 7-person race).  
     - "Dan finished fourth" → Dan’s position is exactly 4.  

4. **Solve the Problem:**  
   * Call `getSolutions()` to compute all valid position assignments.  
   * Extract the unique solution from the returned list (the problem has a single consistent arrangement).

5. **Determine Which Golfer Finished Last:**  
   * The question asks who finished last, i.e., the golfer with position 7.  
   * Create a mapping from choice letters (`'A'` through `'G'`) to the corresponding golfer name (e.g., `'A': 'Eve'`, `'B': 'Ana'`, ..., `'G': 'Mya'`).
