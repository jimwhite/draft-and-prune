2.  **Define Variables and Domain:**
    * Define the five book types as string variables: `"gray"`, `"red"`, `"yellow"`, `"blue"`, `"orange"`.
    * Define the domain as integers 1 to 5, where **1 = leftmost** and **5 = rightmost**.
    * Add all five variables with domain {1, 2, 3, 4, 5} to the problem.

3.  **Add AllDifferent Constraint:**
    * Add an `AllDifferentConstraint()` to ensure all books occupy distinct positions.

4.  **Translate Statements into Constraints:**
    * "The gray book is to the right of the yellow book" → `gray > yellow`
    * "The orange book is to the right of the red book" → `orange > red`
    * "The blue book is the rightmost" → `blue == 5`
    * "The gray book is to the left of the red book" → `gray < red`

5.  **Solve the Problem:**
    * Call `getSolutions()` to find all valid assignments.
    * Since the problem is well-constrained, expect a unique solution; extract it (e.g., `solutions[0]`).

6.  **Determine the Leftmost Book:**
    * Identify the book with position value = 1 in the solution.
