1.  **Initialize the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**
    * Define the seven books as string variables: `"orange"`, `"red"`, `"green"`, `"white"`, `"purple"`, `"brown"`, and `"yellow"`.
    * Define the domain as integers from 1 to 7, where **1 = leftmost** and **7 = rightmost**, matching the fixed linear order of the shelf.
    * Add all seven variables to the problem with this domain.

3.  **Add All-Different Constraint:**
    * Enforce that each book occupies a unique position by adding an `AllDifferentConstraint` over all seven variables.

4.  **Translate Each Statement into a Positional Constraint:**
    * "The green book is to the left of the purple book" → `green < purple`
    * "The white book is to the right of the orange book" → `orange < white`
    * "The green book is to the right of the brown book" → `brown < green`
    * "The yellow book is to the right of the white book" → `white < yellow`
    * "The red book is to the right of the yellow book" → `yellow < red`
    * "The brown book is to the right of the red book" → `red < brown`

5.  **Add All Constraints to the Problem:**
    * Add each of the six inequality constraints using `problem.addConstraint(lambda a, b: a < b, (var1, var2))` or equivalent, ensuring variable names match exactly.

6.  **Solve the Problem:**
    * Call `problem.getSolutions()` to obtain all valid assignments of positions to books.
    * Since the constraints form a strict total order (due to transitivity and uniqueness), there will be exactly one solution. Retrieve it (e.g., `solutions[0]`).

7.  **Analyze the Solution to Find the Second-from-Left Book:**
    * In our numbering (1 = leftmost), the second-from-left corresponds to position **2**.
    * Iterate through the solution dictionary (mapping book names to positions) and identify which book has position value 2.

8.  **Map the Result to the Correct Choice:**
    * Create a mapping from choice letters (A–G) to book names:  
        `{"A": "orange", "B": "red", "C": "green", "D": "white", "E": "purple", "F": "brown", "G": "yellow"}`
    * Find the choice letter whose associated book has position 2 in the solution.
