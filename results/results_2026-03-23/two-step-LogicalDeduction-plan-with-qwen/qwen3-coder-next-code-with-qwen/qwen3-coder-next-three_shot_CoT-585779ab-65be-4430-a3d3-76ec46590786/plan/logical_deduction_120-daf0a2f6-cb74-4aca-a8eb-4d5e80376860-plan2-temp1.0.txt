1. **Initialize the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2. **Define Variables and Their Domain:**  
   * Identify the seven fruits as variables: `"loquats"`, `"peaches"`, `"watermelons"`, `"plums"`, `"kiwis"`, `"mangoes"`, and `"pears"`.  
   * Define the domain as integers from **1 to 7**, where **1 = cheapest** and **7 = most expensive**.  
   * Add all variables to the problem with this domain.

3. **Translate Rules into Constraints:**  
   * Add an `AllDifferentConstraint` to enforce uniqueness of price rankings.  
   * Convert each statement into a constraint using `lambda` functions:  
     - "The pears are more expensive than the kiwis" → `pears > kiwis`  
     - "The watermelons are less expensive than the peaches" → `watermelons < peaches`  
     - "The mangoes are the third-cheapest" → `mangoes == 3`  
     - "The watermelons are the third-most expensive" → Since most-expensive ranking goes from 7 (most) to 1 (least), *third-most expensive* = position **5** → `watermelons == 5`  
     - "The plums are the second-most expensive" → position **6** (since 7 is most) → `plums == 6`  
     - "The loquats are the second-cheapest" → position **2** → `loquats == 2`

4. **Solve for the Arrangement:**  
   * Use `getSolutions()` to find all valid assignments satisfying all constraints.  
   * Extract the unique solution (or any one, as uniqueness is implied by consistency).

5. **Determine Which Option Is True:**  
   * Identify the target: "fourth-most expensive" corresponds to position **4** (since 7 = most, 6 = second-most, 5 = third-most, 4 = fourth-most).  
   * Map each choice letter (A–G) to its corresponding fruit:  
     A → "loquats", B → "peaches", C → "watermelons", D → "plums", E → "kiwis", F → "mangoes", G → "pears".  
   * In the solved solution, find which fruit has rank **4**.  
   * Return the choice letter (e.g., `'B'`) corresponding to that fruit.
