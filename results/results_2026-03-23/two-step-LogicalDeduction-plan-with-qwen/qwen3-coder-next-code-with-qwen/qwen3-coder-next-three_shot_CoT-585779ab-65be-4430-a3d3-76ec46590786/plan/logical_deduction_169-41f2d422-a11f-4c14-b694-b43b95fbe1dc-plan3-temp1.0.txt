   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.

2. **Define Variables and Domain:**  
   * Define the seven golfers as variables: `"Joe"`, `"Dan"`, `"Ana"`, `"Mel"`, `"Ada"`, `"Eve"`, and `"Amy"`.  
   * Define the domain as integers from 1 to 7, where **1 = first place (highest/best finish)** and **7 = last place (worst)** — i.e., smaller numbers mean better (earlier) finish.  
   * Add all seven variables to the problem with this domain.

3. **Formulate Constraints from Statements:**  
   * Add an `AllDifferentConstraint` to ensure all golfers have distinct finish positions.  
   * Translate each statement into a constraint:  
        - "Eve finished above Amy" → Eve’s position is numerically less than Amy’s (`eve < amy`).  
        - "Dan finished second" → Dan’s position is exactly 2.  
        - "Ada finished below Ana" → Ada’s position number is greater than Ana’s (`ada > ana`).  
        - "Ana finished third-to-last" → In a 7-golfer field, third-to-last means position `7 - 2 = 5` (positions: 1st, 2nd, ..., 5th = third-to-last, 6th = second-to-last, 7th = last). So `ana == 5`.  
        - "Mel finished last" → Mel’s position is exactly 7 (`mel == 7`).  
        - "Amy finished third" → Amy’s position is exactly 3 (`amy == 3`).  

4. **Solve the Problem:**  
   * Call `getSolutions()` to find all valid assignments of positions satisfying all constraints.  
   * Extract the unique solution (since the problem is well-constrained, there should be exactly one).

5. **Identify Who Finished Second:**  
   * Examine the solution dictionary to find which variable (golfer) has value 2.  
   * The question asks: “Which of the following is true?” with choices indicating who finished second.
