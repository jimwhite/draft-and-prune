    * Define the domain as integers from 1 to 7, where **1 = first place (best)** and **7 = last place (worst)**.  
    * Add all variables to the problem with this domain.

3.  **Formulate and Add Constraints:**  
    * Add an `AllDifferentConstraint` to enforce unique finishing positions.  
    * Translate each statement into a constraint using lambda functions:

        * "Joe finished below Dan" → `dan < joe`.  
        * "Dan finished below Ada" → `ada < dan`.  
        * "Mel finished third-to-last" → With 7 golfers, third-to-last is position 5 (since positions: 1=1st, ..., 5=3rd-to-last, 6=2nd-to-last, 7=last): `mel == 5`.  
        * "Amy finished third" → `amy == 3`.  
        * "Rob finished below Mya" → `mya < rob`.

4.  **Solve the Problem:**  
    * Call `getSolutions()` to obtain all valid assignments. Given consistency and uniqueness, expect a single solution.  
    * Retrieve the solution dictionary mapping golfers to positions.
