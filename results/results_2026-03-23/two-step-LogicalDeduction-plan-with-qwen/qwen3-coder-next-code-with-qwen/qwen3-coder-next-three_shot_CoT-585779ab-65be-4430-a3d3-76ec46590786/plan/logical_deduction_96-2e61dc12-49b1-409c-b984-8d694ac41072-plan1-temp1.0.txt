1.  **Initialize the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2.  **Define Variables and Their Domain:**
    * Define the variables as the five vehicles: `"tractor"`, `"truck"`, `"bus"`, `"minivan"`, and `"convertible"`.
    * Assign a numerical domain of integers from 1 to 5, where **1 = oldest** and **5 = newest**, to represent the age ranking of each vehicle.
    * Add all variables with their domain to the `Problem` instance.

3.  **Translate Rules into Constraints:**
    * Add an `AllDifferentConstraint` to enforce that each vehicle has a unique age rank.
    * Convert each statement into a constraint using `lambda` functions:
        * "The bus is newer than the tractor" → `bus > tractor`
        * "The convertible is older than the tractor" → `convertible < tractor`
        * "The truck is the second-newest" → `truck == 4` (since 5 is newest, second-newest is rank 4)
        * "The minivan is older than the convertible" → `minivan < convertible`

4.  **Solve for the Arrangement:**
    * Call `getSolutions()` to find all valid assignments of ranks.
    * Extract the unique solution from the list (the problem has exactly one solution).

5.  **Determine the Correct Answer:**
    * The question asks which vehicle is the oldest, i.e., has rank **1**.
    * Create a mapping from choice letters to vehicle names: `"A" → "tractor"`, `"B" → "truck"`, `"C" → "bus"`, `"D" → "minivan"`, `"E" → "convertible"`.
    * Find the vehicle in the solution dictionary whose rank is 1.
    * Return the corresponding choice letter for that vehicle.
