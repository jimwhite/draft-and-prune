1.  **Initialize the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2.  **Define Variables and Domain:**
    * List the seven books as string variables: `"brown"`, `"yellow"`, `"black"`, `"white"`, `"green"`, `"orange"`, and `"purple"`.
    * Define the domain as integers from 1 to 7, where 1 = leftmost position and 7 = rightmost.
    * Add all seven variables to the problem with this domain.

3.  **Add All-Different Constraint:**
    * Enforce that each book occupies a unique position by adding an `AllDifferentConstraint`.

4.  **Translate Each Statement into Constraints:**
    * "The purple book is the rightmost" → `purple == 7`
    * "The yellow book is the leftmost" → `yellow == 1`
    * "The orange book is the second from the right" → `orange == 6`
    * "The brown book is to the left of the green book" → `brown < green`
    * "The brown book is to the right of the black book" → `black < brown`
    * "The white book is the fourth from the left" → `white == 4`

5.  **Solve the Constraint Problem:**
    * Use `getSolutions()` to find all valid assignments.
    * Since the constraints uniquely determine positions, there will be exactly one solution; extract it.

6.  **Determine the Position of Each Book:**
    * After solving, inspect the solution dictionary to retrieve the position value (1–7) for each book.

7.  **Interpret “Third from the Right”:**
    * Since position numbering goes left (1) to right (7), "third from the right" corresponds to position 5 (because 7−2=5).

8.  **Map Choices to Books and Check Condition:**
    * Create a mapping from choice letters (`'A'` through `'G'`) to the corresponding book names:  
      `{'A': 'brown', 'B': 'yellow', 'C': 'black', 'D': 'white', 'E': 'green', 'F': 'orange', 'G': 'purple'}`
    * For each choice letter, check if the position of its associated book in the solution is 5.
