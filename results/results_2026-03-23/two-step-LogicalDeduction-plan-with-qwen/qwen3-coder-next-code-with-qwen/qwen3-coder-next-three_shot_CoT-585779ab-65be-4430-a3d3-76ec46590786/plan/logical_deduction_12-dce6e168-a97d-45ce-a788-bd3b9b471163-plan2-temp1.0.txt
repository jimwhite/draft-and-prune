1. **Initialize the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Create an instance of the `Problem` class to model the golf tournament ranking puzzle.

2. **Define Variables and Domain:**  
   * Define the variables as the five golfers: `"Eve"`, `"Rob"`, `"Ana"`, `"Eli"`, and `"Mya"`.  
   * Define the domain as integers from 1 to 5, where **1 = first place (highest/best rank)** and **5 = fifth place (lowest/worst rank)**.  
   * Add all variables with their domain to the `Problem` instance.

3. **Formulate and Add Constraints:**  
   * Add an `AllDifferentConstraint` to ensure each golfer has a unique finishing position.  
   * Translate each statement into constraints using `lambda` functions:  
     - "Eli finished below Mya" → Eli’s position number is **greater than** Mya’s (`Eli > Mya`).  
     - "Eve finished first" → Eve’s position is 1.  
     - "Ana finished below Eli" → Ana’s position number is **greater than** Eli’s (`Ana > Eli`).  
     - "Rob finished second" → Rob’s position is 2.

4. **Solve for the Unique Arrangement:**  
   * Use `getSolutions()` to compute all valid solutions.  
   * Extract the sole solution (the constraints uniquely determine the ordering).

5. **Determine Which Golfer Finished Third:**  
   * The question asks who finished **third**, i.e., whose position is 3.  
   * Create a mapping from choice letters (`"A"` → `"Eve"`, `"B"` → `"Rob"`, etc.).  
   * Iterate over the choices; for each choice, check if the referenced golfer’s position in the solution equals 3.  
   * Return (or print) the letter of the choice where this condition holds true.
