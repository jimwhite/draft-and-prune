1. **Initialize the Problem Environment:**
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
   * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2. **Define Variables and Domain:**
   * Identify the five books as variables: `"yellow"`, `"green"`, `"gray"`, `"blue"`, `"orange"`.
   * Define the domain as integers 1 through 5, where **1 = leftmost** and **5 = rightmost**.
   * Add all five variables to the problem with this domain.

3. **Formulate and Add Constraints:**
   * Add `AllDifferentConstraint()` to enforce that each book occupies a unique position.
   * Add constraint: `"gray" < "green"` (gray is to the left of green).
   * Add constraint: `"gray" == 4` (gray is second from the right → position 4).
   * Add constraint: `"orange" < "yellow"` (yellow is to the right of orange).
   * Add constraint: `"blue" == 2` (blue is second from the left → position 2).

4. **Solve the Problem:**
   * Call `getSolutions()` to find all valid assignments of positions to books.
   * Extract the unique solution (since the constraints fully determine the order).

5. **Determine Which Book is Rightmost:**
   * In the solution dictionary, identify which book has position value 5 (rightmost).
   * Map that book to the correct choice letter:
        - `"yellow"` → A
        - `"green"` → B
        - `"gray"` → C
        - `"blue"` → D
        - `"orange"` → E
   * Output the letter (e.g., print or return) corresponding to the rightmost book.
