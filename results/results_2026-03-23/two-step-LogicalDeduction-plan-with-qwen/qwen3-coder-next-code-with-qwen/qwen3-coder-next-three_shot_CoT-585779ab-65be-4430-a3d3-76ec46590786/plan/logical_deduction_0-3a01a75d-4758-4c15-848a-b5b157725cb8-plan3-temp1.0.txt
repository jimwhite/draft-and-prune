2.  **Define Variables and Domain:**
    * Define the five books as string variables: `"green"`, `"blue"`, `"white"`, `"purple"`, and `"yellow"`.
    * Define the domain as integers 1 to 5, where **1 = leftmost** and **5 = rightmost**.
    * Add all book variables to the problem with their domain [1, 2, 3, 4, 5].

3.  **Add Constraints:**
    * Add `AllDifferentConstraint` to ensure each book occupies a unique position.
    * Translate the statements into constraints:
        - "The blue book is to the right of the yellow book" → `blue > yellow`
        - "The white book is to the left of the yellow book" → `white < yellow`
        - "The blue book is the second from the right" → `blue == 4` (since positions are left-to-right: 1,2,3,4,5 → rightmost=5, second-from-right=4)
        - "The purple book is the second from the left" → `purple == 2`

4.  **Solve the Problem:**
    * Call `getSolutions()` to find all valid assignments.
    * Extract the unique solution (since the problem is deterministic and consistent).
