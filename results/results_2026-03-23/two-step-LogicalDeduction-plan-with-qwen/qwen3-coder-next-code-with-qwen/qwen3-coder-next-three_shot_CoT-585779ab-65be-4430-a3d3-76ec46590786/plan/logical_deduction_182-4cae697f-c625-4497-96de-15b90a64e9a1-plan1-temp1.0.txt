    * Define the domain as integers 1 through 7, where **1 = leftmost** and **7 = rightmost**.  
    * Add all seven variables to the problem with this domain using `addVariable`.  

3.  **Formulate and Add Constraints:**  
    * Add an `AllDifferentConstraint` to enforce uniqueness of positions.  
    * Translate each statement into a constraint:  
        - "The cardinal is the second from the right" → `cardinal == 6` (since position 7 is rightmost).  
        - "The hawk is the rightmost" → `hawk == 7`.  
        - "The owl is to the left of the hummingbird" → `owl < hummingbird`.  
        - "The robin is to the left of the quail" → `robin < quail`.  
        - "The owl is to the right of the crow" → `owl > crow`.  
        - "The robin is the fourth from the left" → `robin == 4`.  

4.  **Solve the Problem:**  
    * Call `getSolutions()` to compute all valid assignments.  
    * Extract the first (and presumably only) solution from the list, assuming uniqueness as stated.
