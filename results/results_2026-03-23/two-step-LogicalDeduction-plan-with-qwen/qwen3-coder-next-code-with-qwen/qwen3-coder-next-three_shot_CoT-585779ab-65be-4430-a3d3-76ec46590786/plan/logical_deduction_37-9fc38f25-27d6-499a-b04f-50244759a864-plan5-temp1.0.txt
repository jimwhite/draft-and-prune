1. **Initialize the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Create an instance of the `Problem` class to hold variables and constraints.

2. **Define Variables and Domain:**  
   * Define the variables as the five golfers: `"Joe"`, `"Ana"`, `"Amy"`, `"Mya"`, and `"Eve"`.  
   * Define the domain as integers from 1 to 5, where **1 = first place (best)** and **5 = last place (worst)**.  
   * Add these variables and domain to the `Problem` instance.

3. **Formulate Constraints from Statements:**  
   * Add an `AllDifferentConstraint` to ensure each golfer has a unique finishing position.  
   * Translate each statement into constraints:  
     - "Joe finished last" → Joe's position = 5.  
     - "Ana finished second" → Ana's position = 2.  
     - "Mya finished second-to-last" → Mya's position = 4 (since 5 is last, 4 is second-to-last).  
     - "Eve finished below Amy" → Eve's position number > Amy's position number (since higher number = worse rank, i.e., *below*).

4. **Solve for the Unique Arrangement:**  
   * Call `getSolutions()` to find all valid assignments.  
   * Extract the sole solution (the problem is well-constrained, so exactly one exists).

5. **Determine Who Finished First (Position 1):**  
   * Identify the golfer whose position value in the solution is **1**.  
   * Map this golfer to the correct multiple-choice option:  
     - A) Joe → check if Joe's position = 1? (But we know Joe = 5, so false)  
     - B) Ana → Ana = 2 (fixed), so false  
     - C) Amy → check if Amy's position = 1  
     - D) Mya → Mya = 4, false  
     - E) Eve → Eve must be below Amy, so if Amy = 1, Eve > 1; possible only if Amy = 1 and Eve ∈ {3} (since positions 2,4,5 taken by Ana=2, Mya=4, Joe=5)  
   * Print the letter (C or E) corresponding to the golfer assigned position 1 in the solution.
