1.  **Initialize the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Create an instance of the `Problem` class to represent the constraint satisfaction problem.

2.  **Define Variables and Their Domain:**
    * Define the variables as the seven golfers: `"Ana"`, `"Eli"`, `"Mya"`, `"Amy"`, `"Joe"`, `"Mel"`, and `"Ada"`.
    * Define the domain as integers from 1 to 7, where **1 = first (topmost/best rank)** and **7 = last (worst rank)**.
    * Add all variables with their domain to the problem instance.

3.  **Formulate and Add Constraints:**
    * Add an `AllDifferentConstraint` to ensure each golfer has a unique finishing position.
    * Translate each statement into a constraint using lambda functions:
        - "Ada finished above Mel" → `Ada < Mel` (lower rank number = better/earlier finishing).
        - "Ada finished third-to-last" → In a 7-golfer field, third-to-last means position 5 (since last=7, second-last=6, third-last=5).
        - "Amy finished above Ana" → `Amy < Ana`.
        - "Mya finished second-to-last" → position 6.
        - "Joe finished above Amy" → `Joe < Amy`.
        - "Eli finished below Ana" → `Eli > Ana`.

4.  **Solve the Problem:**
    * Use `getSolutions()` to compute all valid assignments of positions to golfers.
    * Extract the unique solution (since the problem is well-constrained, there should be exactly one).

5.  **Identify Who Finished Third:**
    * Examine the solution dictionary to find which golfer has position value 3.
    * Map the identified golfer name to the corresponding choice letter using a dictionary:
        - `"Ana" → "A"`, `"Eli" → "B"`, `"Mya" → "C"`, `"Amy" → "D"`, `"Joe" → "E"`, `"Mel" → "F"`, `"Ada" → "G"`
    * Return the choice letter corresponding to the golfer with rank 3.
