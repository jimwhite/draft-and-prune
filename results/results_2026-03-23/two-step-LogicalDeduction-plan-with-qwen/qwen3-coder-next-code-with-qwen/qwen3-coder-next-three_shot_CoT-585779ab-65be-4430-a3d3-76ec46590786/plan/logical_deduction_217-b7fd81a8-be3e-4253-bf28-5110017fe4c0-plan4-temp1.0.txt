1. **Initialize the Problem Environment:**  
   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.  
   * Create an instance of the `Problem` class to model the constraint satisfaction problem.

2. **Define Variables and Domain:**  
   * Define the seven variables as the fruits: `"loquats"`, `"peaches"`, `"watermelons"`, `"plums"`, `"kiwis"`, `"mangoes"`, and `"pears"`.  
   * Assign a numerical domain from 1 to 7, where **1 = cheapest** and **7 = most expensive**, reflecting increasing cost (i.e., higher rank number means more expensive).  
   * Add all seven variables to the `Problem`, each with domain `{1, 2, 3, 4, 5, 6, 7}`.

3. **Formulate and Add Constraints:**  
   * Add an `AllDifferentConstraint` to ensure all fruits have distinct price ranks.  
   * Translate each statement into a lambda-based constraint:  
     - "The pears are more expensive than the kiwis" → `pears > kiwis`  
     - "The watermelons are less expensive than the peaches" → `watermelons < peaches`  
     - "The mangoes are the third-cheapest" → `mangoes == 3`  
     - "The watermelons are the third-most expensive" → Since most expensive = 7, third-most expensive = 7 − 2 = **5**, so `watermelons == 5`  
     - "The plums are the second-most expensive" → second-most expensive = 7 − 1 = **6**, so `plums == 6`  
     - "The loquats are the second-cheapest" → `loquats == 2`  

4. **Solve for the Arrangement:**  
   * Call `getSolutions()` to find all valid assignments of ranks satisfying all constraints.  
   * Extract the unique solution (since the problem is well-constrained, exactly one solution is expected).  

5. **Identify the Correct Answer:**  
   * Determine which fruit has rank 7 (most expensive).  
   * Map the choice letters: `"A"` → `"loquats"`, `"B"` → `"peaches"`, `"C"` → `"watermelons"`, `"D"` → `"plums"`, `"E"` → `"kiwis"`, `"F"` → `"mangoes"`, `"G"` → `"pears"`.  
   * Find which variable in the solution dictionary equals 7, then return the corresponding letter.
