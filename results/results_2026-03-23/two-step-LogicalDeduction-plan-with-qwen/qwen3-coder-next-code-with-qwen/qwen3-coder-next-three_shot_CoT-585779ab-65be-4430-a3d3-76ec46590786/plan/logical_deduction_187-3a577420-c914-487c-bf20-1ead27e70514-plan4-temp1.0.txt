1.  **Set Up the Problem Environment:**
    * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.
    * Instantiate a `Problem` object to hold the variables and constraints.

2.  **Define Variables and Domain:**
    * Identify the seven golfers as variables: `"Eve"`, `"Ana"`, `"Amy"`, `"Dan"`, `"Eli"`, `"Rob"`, and `"Mya"`.
    * Define the domain as integers from 1 to 7, where **1 = first (highest/furthest up)** and **7 = last (lowest/furthest down)**. This reflects "finished above/below" semantics.
    * Add all seven golfers as variables with domain {1, 2, 3, 4, 5, 6, 7} to the `Problem` instance.

3.  **Formulate and Add Constraints:**
    * Add an `AllDifferentConstraint` to ensure each golfer has a unique finishing position.
    * Translate each statement into a constraint using `lambda` functions:
        - "Mya finished above Eli" → Mya’s position < Eli’s position (`lambda m, e: m < e`).
        - "Eve finished below Rob" → Eve’s position > Rob’s position (`lambda e, r: e > r`).
        - "Amy finished second" → Amy’s position = 2.
        - "Rob finished below Dan" → Rob’s position > Dan’s position (`lambda r, d: r > d`).
        - "Ana finished second-to-last" → Ana’s position = 6 (since last is 7).
        - "Dan finished fourth" → Dan’s position = 4.

4.  **Solve for the Final Arrangement:**
    * Use `getSolutions()` to find all valid assignments satisfying the constraints.
    * Since the problem is well-constrained, extract the single solution (or one of the solutions) from the result list.

5.  **Determine the Correct Answer:**
    * The question asks which golfer finished last, i.e., position 7.
    * Create a mapping from choice letters to golfer names:
        - A → `"Eve"`, B → `"Ana"`, C → `"Amy"`, D → `"Dan"`, E → `"Eli"`, F → `"Rob"`, G → `"Mya"`.
    * Iterate through the choices; for each, check if that golfer’s position in the solution equals 7.
    * Return (or print) the letter of the first/only choice where this condition holds.
