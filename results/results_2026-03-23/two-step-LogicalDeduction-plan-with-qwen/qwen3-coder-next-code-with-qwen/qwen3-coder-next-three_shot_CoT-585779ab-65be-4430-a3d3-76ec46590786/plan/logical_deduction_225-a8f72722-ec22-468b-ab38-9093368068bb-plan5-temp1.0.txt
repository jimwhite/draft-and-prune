3. **Add AllDifferentConstraint:**  
   * Enforce that all books occupy distinct positions using `AllDifferentConstraint()`.

4. **Translate Each Statement into Constraints:**  
   * "The brown book is to the left of the green book" → `brown < green`.  
   * "The gray book is the second from the left" → `gray == 2`.  
   * "The black book is to the left of the gray book" → `black < gray`.  
   * "The blue book is to the left of the red book" → `blue < red`.  
   * "The blue book is the second from the right" → `blue == 6` (since position 7 is rightmost).  
   * "The green book is to the left of the purple book" → `green < purple`.

5. **Solve the Problem:**

6. **Interpret the Question:**  
   * The question asks which book is "third from the right". In a 7-position line:  
     - Rightmost = position 7  
     - Second from right = position 6  
     - Third from right = **position 5**.  
   * So identify the book with position `5` in the solution.
