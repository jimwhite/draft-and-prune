2. **Define Variables and Their Domain:**  
   * Set up the five fruit variables: `"loquats"`, `"peaches"`, `"pears"`, `"plums"`, and `"watermelons"`.  
   * Define a domain of integers from 1 to 5, where **1 represents the cheapest** and **5 represents the most expensive**.  
   * Add all five fruit variables with this domain to the `Problem` instance.  

3. **Translate Rules into Constraints:**  
   * Add an `AllDifferentConstraint` to ensure no two fruits share the same price rank.  
   * Convert each statement into a constraint using `lambda` functions:  
     - "The watermelons are the most expensive" → `watermelons == 5`.  
     - "The peaches are more expensive than the loquats" → `peaches < loquats` (since lower rank number = cheaper, so if peaches are *more* expensive, their rank is *smaller*).  
     - "The plums are the second-cheapest" → `plums == 2` (cheapest = 1, second-cheapest = 2).  
     - "The pears are the third-most expensive" → `pears == 3` (most expensive = 5, so third-most expensive = rank 3).  

4. **Solve for the Arrangement:**  
   * Use `getSolutions()` to find all valid assignments of ranks to fruits.  
   * Extract the unique solution from the returned list (there should be exactly one).  

5. **Determine the Second-Most-Expensive Fruit:**  
   * The second-most-expensive fruit corresponds to rank **4** (since 5 = most expensive, 4 = second-most).  
   * Create a mapping from choice letters to fruit names: `{"A": "loquats", "B": "peaches", "C": "pears", "D": "plums", "E": "watermelons"}`.
