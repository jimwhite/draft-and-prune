   * Add all five variables with domain `{1, 2, 3, 4, 5}` to the `Problem` instance.

3. **Add Constraints:**  
   * Add an `AllDifferentConstraint` to enforce that each bird occupies a unique position.

     - "The crow is to the left of the quail" → `crow < quail` (i.e., position(crow) < position(quail)).  
     - "The falcon is the leftmost" → `falcon == 1`.  
     - "The blue jay is to the right of the quail" → `quail < blue jay` (i.e., position(quail) < position(blue jay)).  
     - "The raven is the second from the left" → `raven == 2`.

4. **Solve the Problem:**  
   * Call `getSolutions()` to retrieve all valid assignments.  
   * Since the constraints uniquely determine the arrangement, extract the single solution from the result list.
