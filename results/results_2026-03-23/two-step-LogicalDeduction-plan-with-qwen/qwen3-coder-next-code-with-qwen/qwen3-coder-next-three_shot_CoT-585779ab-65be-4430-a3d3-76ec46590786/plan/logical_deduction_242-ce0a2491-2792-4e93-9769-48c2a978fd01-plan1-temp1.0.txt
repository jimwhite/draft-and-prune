   * Import the `Problem` and `AllDifferentConstraint` classes from the `constraint` library.

2. **Define Variables and Their Domain:**  
   * Define the three vehicles as variables: `"minivan"`, `"bus"`, and `"sedan"`.  
   * Define the domain as integers from 1 to 3, where **1 = oldest**, **2 = middle**, and **3 = newest**.  
   * Add all variables to the problem with this domain.

3. **Translate Statements into Constraints:**  
   * Add an `AllDifferentConstraint` to enforce uniqueness of age ranks.  
   * "The minivan is newer than the sedan" → `minivan > sedan` (since higher rank number = newer).  
   * "The minivan is older than the bus" → `minivan < bus` (since lower rank number = older).  

4. **Solve the Problem:**  
   * Use `getSolutions()` to find all valid solutions.  
   * Extract the unique solution (since there is exactly one arrangement satisfying all constraints).  

5. **Identify the Oldest Vehicle and Match to Choice:**  
   * The oldest vehicle corresponds to rank **1**.  
   * Create a mapping from choice letters ("A", "B", "C") to vehicle names:
