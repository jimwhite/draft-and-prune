4. Add **Zone 1 constraint**: Exactly one of Parra or Tiao is in Zone 1 (exclusive OR).

8. Add **Zone size constraint**: number of representatives in Zone 3 > number in Zone 2.  
9. For each answer choice (a proposed assignment), parse the zone assignments and extract the zone index for each representative.  
10. For each answer choice, clone the base constraints and add hard equality constraints forcing each representative into the zone specified in the answer choice.  
11. Check satisfiability of each extended constraint set with Z3; collect the index (or directly record) of answer choices that yield SAT.  
12. Output the list of indices (or directly select) of valid answer choices.
