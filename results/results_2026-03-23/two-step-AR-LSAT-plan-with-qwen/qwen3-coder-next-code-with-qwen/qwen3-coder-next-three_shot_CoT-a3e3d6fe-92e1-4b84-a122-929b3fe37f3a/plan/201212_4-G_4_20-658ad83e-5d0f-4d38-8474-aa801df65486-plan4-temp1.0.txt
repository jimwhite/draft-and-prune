6. Add **S–Y ordering constraint**: pos_S < pos_Y.  
7. Add **J–G–R chaining constraint**: pos_J < pos_G < pos_R.  
8. Translate each answer choice into a concrete position assignment: e.g., "G is second" → pos_G == 2.  
9. For each answer choice:  
   - Clone the base constraints into a fresh solver.  
   - Assert the condition (e.g., pos_G == 2).  
   - Check satisfiability: if SAT, the choice *could* be true; record its index.
