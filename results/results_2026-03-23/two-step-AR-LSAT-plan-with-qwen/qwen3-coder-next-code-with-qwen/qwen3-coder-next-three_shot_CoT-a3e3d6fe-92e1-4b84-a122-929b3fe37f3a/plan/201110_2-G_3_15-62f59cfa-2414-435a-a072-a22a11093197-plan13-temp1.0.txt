1. Enumerate the four riders (Reynaldo, Seamus, Theresa, Yuki) and four bicycles (F, G, H, J), assigning integer indices 0–3 to each.  
2. Create Boolean variables for assignments: `r1[i][j]` = rider i tests bicycle j on day 1; `r2[i][j]` = rider i tests bicycle j on day 2.  
3. Add **day-1 assignment constraints**:  
   - Each rider tests exactly one bicycle on day 1: for each rider i, exactly one `r1[i][j]` is true.  
   - Each bicycle is tested by exactly one rider on day 1: for each bicycle j, exactly one `r1[i][j]` is true.  
4. Add **day-2 assignment constraints**:  
   - Each rider tests exactly one bicycle on day 2: for each rider i, exactly one `r2[i][j]` is true.  
   - Each bicycle is tested by exactly one rider on day 2: for each bicycle j, exactly one `r2[i][j]` is true.  
5. Add **prohibition constraints**:  
   - Reynaldo cannot test F: `~r1[0][0]` and `~r2[0][0]`.  
   - Yuki cannot test J: `~r1[3][3]` and `~r2[3][3]`.  
6. Add **Theresa-for-H constraint**: Theresa (index 2) must test H (index 2) on at least one day: `r1[2][2] ∨ r2[2][2]`.  
7. Add **Yuki–Seamus dependency**: The bicycle Yuki tests on day 1 must be tested by Seamus on day 2: for all j, `r1[3][j] → r2[1][j]`.  
8. Translate the five answer choices into logical assertions about the assignment variables:  
   - A: "Reynaldo tests J on day 1" → `r1[0][3]`  
   - B: "Reynaldo tests J on day 2" → `r2[0][3]`  
   - C: "Seamus tests H on day 1" → `r1[1][2]`  
   - D: "Yuki tests H on day 1" → `r1[3][2]`  
   - E: "Yuki tests H on day 2" → `r2[3][2]`  
9. Define `answer_index_list = []`. For each choice (index i from 0 to 4):  
   - Clone base constraints into a fresh solver.  
   - Assert the specific condition for that choice (e.g., assert `r1[0][3]` for i=0).  
   - Solve the solver. If UNSAT, then that choice **cannot** be true; append i to `answer_index_list`.  
10. Print the answer index list (the one with UNSAT is the correct "EXCEPT" choice).
