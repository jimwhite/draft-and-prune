3. Add **domain constraints**: `1 <= pos[i] <= 6` for all i, and add **all-different constraint**: all `pos[i]` are distinct.  
4. Add ordering constraints from the problem:  
   - Guitarist ≠ 4th solo: `pos[0] != 4`.  
   - Percussionist before keyboard player: `pos[2] < pos[1]`.  
   - Keyboard player after violinist and before guitarist: `pos[5] < pos[1]` and `pos[1] < pos[0]`.  
   - Saxophonist after *exactly one* of (percussionist, trumpeter): `(pos[3] > pos[2]) XOR (pos[3] > pos[4])`.  
5. Translate answer choices into role indices: [guitarist=0, keyboard player=1, saxophonist=3, trumpeter=4, violinist=5].  
6. Define `answer_index_list = []`. For each candidate role r in [0, 1, 3, 4, 5]:  
   - Clone base constraints into a fresh solver.  
   - Assert `pos[r] == 3`.  
   - If the model is UNSAT, then role r **cannot** be third; append r to `answer_index_list`.  
7. Print `answer_index_list`.
