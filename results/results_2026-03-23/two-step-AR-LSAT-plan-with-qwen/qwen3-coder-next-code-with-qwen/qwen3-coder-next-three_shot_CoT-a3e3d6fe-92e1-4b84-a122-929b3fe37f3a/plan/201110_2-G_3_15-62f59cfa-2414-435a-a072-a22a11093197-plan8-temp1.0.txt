3. Add **bijective constraints** for each day: all d1_r[i] distinct, all d2_r[i] distinct (each bicycle used exactly once per day).  
4. Add **fixed constraints**:  
   - Reynaldo ≠ F: `d1_r[0] != 0` and `d2_r[0] != 0`.

   - Choice 0: `d1_r[0] == 3` (Reynaldo tests J on first day).  
   - Choice 1: `d2_r[0] == 3` (Reynaldo tests J on second day).  
   - Choice 2: `d1_r[1] == 2` (Seamus tests H on first day).  
   - Choice 3: `d1_r[3] == 2` (Yuki tests H on first day).  
   - Choice 4: `d2_r[3] == 2` (Yuki tests H on second day).  
6. Define answer index list `answer_index_list = []`. For each choice index i (0 to 4):  
   - Clone base constraints into a fresh solver.  
   - Assert the condition for choice i.  
   - If UNSAT, then this choice **cannot** be true; append i to `answer_index_list`.  
7. Print `answer_index_list` (the EXCEPT choice is the one with UNSAT).
