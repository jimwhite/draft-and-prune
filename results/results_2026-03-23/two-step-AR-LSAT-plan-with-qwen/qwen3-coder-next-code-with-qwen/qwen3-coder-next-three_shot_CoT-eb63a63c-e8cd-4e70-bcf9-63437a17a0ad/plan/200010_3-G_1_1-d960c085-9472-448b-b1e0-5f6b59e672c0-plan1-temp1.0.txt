2. Represent the six report slots: Monday morning (MM), Monday afternoon (MA), Tuesday morning (TM), Tuesday afternoon (TA), Wednesday morning (WM), Wednesday afternoon (WA). Assign each slot a unique integer index from 0 to 5.  
3. Create an array of six variables `slot_student[i]` (i ∈ {0,...,5}), each representing which student is assigned to slot i.  
4. Add **domain constraints**: `slot_student[i]` must be one of the eight students, and exactly six distinct students are used (i.e., all `slot_student[i]` are distinct).  
5. Add **Tuesday-only constraint**: If George gives a report, it must be in Tuesday morning or afternoon (i.e., `slot_student[j] == George ⇒ j ∈ {2,3}`).  
6. Add **afternoon-restriction constraint**: Olivia and Robert cannot give afternoon reports → if `slot_student[j] == Olivia` or `Robert`, then j must be an even index (MM, TM, WM).  
7. Add **Nina conditional constraint**:  
   - If Nina gives a report on Monday (slot 0 or 1), then Helen and Irving must both give reports on Tuesday (slots 2 and 3), in some order.  
   - If Nina gives a report on Tuesday (slots 2 or 3), then Helen and Irving must both give reports on Wednesday (slots 4 and 5), in some order.  
   - If Nina gives a report on Wednesday (slots 4 or 5), no extra constraint is required.  
   - Nina cannot give a report unless Helen and Irving are scheduled accordingly (i.e., implication must hold).  
8. For each choice in the options:  
   - Parse the proposed schedule to extract student assignments per slot.  
   - Clone base constraints into a fresh solver.  
   - Assert the exact assignments from the choice (e.g., `slot_student[0] == Helen`, `slot_student[1] == Robert`, ..., `slot_student[5] == Kyle`).  
   - Check satisfiability: if SAT, the schedule is possible; record its index.  
9. Select and output the index of a choice that yields SAT (since only one is correct).
