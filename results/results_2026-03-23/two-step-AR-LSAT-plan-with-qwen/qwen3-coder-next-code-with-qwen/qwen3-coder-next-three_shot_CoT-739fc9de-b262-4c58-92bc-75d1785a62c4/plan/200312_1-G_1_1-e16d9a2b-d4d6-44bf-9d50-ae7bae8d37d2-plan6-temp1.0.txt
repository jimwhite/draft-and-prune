10. Translate each answer choice into a selection pattern: set sel[i] = True for scientists in the choice, False otherwise.  
11. For each answer choice, clone the base constraints into a fresh solver and assert the exact selection pattern (i.e., fix sel[i] to True/False per choice).  
12. Check satisfiability: if SAT and all constraints are satisfied, that choice is acceptable; record the index of the acceptable choice.
