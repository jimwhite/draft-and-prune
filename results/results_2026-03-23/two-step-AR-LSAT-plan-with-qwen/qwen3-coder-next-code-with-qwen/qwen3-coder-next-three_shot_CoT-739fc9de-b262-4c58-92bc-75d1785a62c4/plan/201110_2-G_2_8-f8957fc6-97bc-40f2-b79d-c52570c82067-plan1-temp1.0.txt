3. Add **exactly-one-assignment constraints**: each candidate is assigned to at most one country: for all i, exactly one of `assigned[i][0]`, `assigned[i][1]`, `assigned[i][2]` is true.  
4. Add **exactly-three-ambassadors constraint**: exactly three candidates are assigned (one per country), i.e., for all countries c, sum_i `assigned[i][c]` = 1.  
5. Add **constraint A**: Either Kayne or Novetzke, but not both, is assigned to *some* ambassadorship (i.e., exactly one of Kayne or Novetzke gets an assignment): `(sum_c assigned[1][c]) == 1 XOR (sum_c assigned[3][c]) == 1`.  
6. Add **constraint B**: If Jaramillo is assigned, then Kayne is also assigned: `sum_c assigned[0][c] == 1 → sum_c assigned[1][c] == 1`.  
7. Add **constraint C**: If Ong is assigned to Venezuela, then Kayne is *not* assigned to Yemen: `assigned[4][0] → ¬assigned[1][1]`.  
8. Add **constraint D**: If Landon is assigned, it must be to Zambia: `sum_c assigned[2][c] == 1 → assigned[2][2] = true`.  
9. Translate each answer choice into the pair of unassigned candidates (i.e., those with zero total assignments), and denote them by candidate index pairs:

   - ['Kayne and Landon'] → (1,2)  
   - ['Kayne and Novetzke'] → (1,3)

    - If the model is SAT, this pair *could* be unassigned; append `idx` to `answer_index_list`.
